# Appwrite Data Provider fuer refine

`@refinedev/appwrite` stellt eine Integration fuer Appwrite-Projekte bereit. Damit kannst du Appwrite Collections als Datenquelle fuer Refine-Ressourcen verwenden und CRUD-Ablaeufe ueber die ueblichen Refine-Hooks steuern.

## Installation

```sh
npm install @refinedev/appwrite
```

## Verwendung

Das Paket passt zu Admin-Panels, Dashboards und internen Anwendungen, die Appwrite fuer Daten, Authentifizierung oder Backend-Services einsetzen. Behalte Appwrite-IDs, Collection-Namen, Environment-Variablen und API-Bezeichner unveraendert.

Weitere Informationen findest du in der [Appwrite-Provider-Dokumentation](https://refine.dev/docs/data/packages/appwrite/).
