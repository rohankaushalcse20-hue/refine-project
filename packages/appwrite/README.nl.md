# @refinedev/appwrite

`@refinedev/appwrite` verbindt Refine met Appwrite via providers voor data, authentication en realtime gedrag.

## Wat biedt het?

- Een Appwrite data provider voor collections en documents
- Helpers voor authentication met Appwrite-accounts
- Realtime ondersteuning voor updates uit Appwrite
- Integratie met het standaard providerpatroon van Refine

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer Appwrite je backend is en je een Refine-app wilt bouwen zonder zelf de Appwrite API naar `dataProvider`-methoden te vertalen.

Package name, import paths en Appwrite API-namen blijven ongewijzigd.
