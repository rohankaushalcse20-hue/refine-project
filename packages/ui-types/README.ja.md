# Refine UI types

`@refinedev/ui-types` は、refine の UI パッケージで使う TypeScript 型をまとめたパッケージです。UI integration 間で props、component contracts、型定義を一貫して共有しやすくします。

## インストール

```sh
npm install @refinedev/ui-types
```

## 何に使うか

- refine の UI components で共通の型を再利用する。
- 一貫した型付けで UI integration や拡張を作る。
- refine の UI パッケージ間で TypeScript support をそろえる。

このパッケージは、refine の UI components を拡張する開発者、独自 adapter を作る開発者、公式 UI パッケージに貢献する開発者に特に関係します。
