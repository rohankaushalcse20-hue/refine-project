# UI types для refine

`@refinedev/ui-types` содержит общие TypeScript-типы для UI integrations refine. Пакет помогает разным UI-пакетам использовать единые contracts для компонентов, layouts и provider-интеграций.

## Назначение

- Делить типы между UI packages.
- Уменьшать дублирование contracts в Ant Design, Material UI, Mantine и Chakra UI integrations.
- Поддерживать согласованность публичных API refine.

## Документация

- Общая документация refine доступна на [refine.dev/docs](https://refine.dev/docs/).
- Список UI integrations находится в [разделе UI libraries](https://refine.dev/docs/guides-concepts/ui-libraries/).
