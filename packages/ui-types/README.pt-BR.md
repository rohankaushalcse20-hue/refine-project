# Refine UI types

`@refinedev/ui-types` reune tipos TypeScript usados pelos pacotes de UI do Refine. Ele ajuda integracoes de interface a compartilhar props, contratos de componentes e definicoes de tipos de forma consistente.

## Instalacao

```sh
npm install @refinedev/ui-types
```

## Para que serve

- Reutilizar tipos comuns de componentes de UI do Refine.
- Criar integracoes ou extensoes de UI com tipagem consistente.
- Manter suporte TypeScript alinhado entre pacotes de UI do Refine.

Este pacote e mais relevante para desenvolvedores que estendem componentes de UI do Refine, escrevem adapters proprios ou contribuem com os pacotes oficiais de UI.
