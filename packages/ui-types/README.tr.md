# Refine UI types

`@refinedev/ui-types`, Refine UI package'ları arasında paylaşılan type tanımlarını içerir. Component, hook ve provider sözleşmelerinin ortak biçimde kullanılmasına yardımcı olur.

## Ne zaman kullanılır?

Bu package çoğunlukla Refine monorepo içindeki UI entegrasyonlarının bakımında kullanılır. Uygulama geliştirirken genellikle doğrudan kurmanız gerekmez; ilgili UI package'ları gerekli type katmanlarını beraberinde getirir.

## Refine hakkında

Refine, admin panels, dashboards ve internal tools gibi CRUD yoğun uygulamalar için headless React framework'tür. UI seçiminizi dayatmadan data, routing, authentication, authorization ve i18n workflow'larını bir araya getirir.

## Dokümantasyon

UI entegrasyonları ve provider sözleşmeleri için [Refine dokümantasyonunu](https://refine.dev/docs/) okuyun.
