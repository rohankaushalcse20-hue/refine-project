# Refine UI types

`@refinedev/ui-types` buendelt TypeScript-Typen fuer Refine UI packages. Es hilft UI-Integrationen dabei, gemeinsame Props, Komponentenvertraege und Typdefinitionen konsistent zu verwenden.

## Installation

```sh
npm install @refinedev/ui-types
```

## Wofuer es gedacht ist

- Gemeinsame Typen fuer Refine UI-Komponenten wiederverwenden.
- Eigene UI-Integrationen oder Erweiterungen typisiert aufbauen.
- Konsistente TypeScript-Unterstuetzung zwischen Refine UI packages sicherstellen.

Dieses package ist vor allem fuer Entwickler relevant, die Refine UI-Komponenten erweitern, eigene Adapter schreiben oder an den offiziellen UI packages mitarbeiten.
