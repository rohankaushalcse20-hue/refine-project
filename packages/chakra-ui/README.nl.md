# @refinedev/chakra-ui

`@refinedev/chakra-ui` biedt Chakra UI-componenten en hooks die zijn afgestemd op Refine-applicaties.

## Wat biedt het?

- CRUD-wrappers zoals `List`, `Create`, `Edit` en `Show`
- Form-, table- en field-hulpen voor Chakra UI
- Layoutcomponenten voor beheerpanelen
- Integratie met Refine resource-, navigation- en notificationgedrag

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je Chakra UI wilt gebruiken als visuele laag voor een Refine-app, maar de resource- en providerarchitectuur van Refine wilt behouden.

Package name, componentnamen en API-namen blijven ongewijzigd.
