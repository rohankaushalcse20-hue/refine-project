# Refine Devtools UI

`@refinedev/devtools-ui`, Refine Devtools arayüzünü oluşturan internal UI package'ıdır. Development sırasında resources, providers ve query davranışlarını görsel olarak inceleyen Devtools deneyiminin parçasıdır.

## Kurulum

Devtools'u uygulamanızda kullanmak için public package'ı kurun:

```sh
npm install @refinedev/devtools
```

## Ne zaman kullanılır?

Bu package doğrudan uygulama UI'ınıza eklenmek için değildir. Refine Devtools'un kendi arayüzünü geliştirmek veya monorepo içindeki Devtools parçalarını bağlamak için kullanılır.

## Dokümantasyon

Ayrıntılı bilgi için [Refine Devtools dokümantasyonunu](https://refine.dev/docs/packages/devtools) okuyun.
