# Refine Devtools UI

`@refinedev/devtools-ui` enthaelt die Oberflaeche, die Refine Devtools waehrend der Entwicklung anzeigt. Das Paket ist Teil von `@refinedev/devtools` und hilft dabei, das Verhalten einer Refine-Anwendung zu untersuchen.

## Ueber das Paket

Refine ist headless by design und trennt Daten, Authentifizierung, Autorisierung, routing, Benachrichtigungen und i18n ueber providers. Devtools nutzt diese Architektur, um resources, queries, mutations und App-Ereignisse in einer Diagnose-UI sichtbar zu machen.

## Installation

Du musst dieses Paket normalerweise nicht separat installieren. Installiere Devtools ueber das oeffentliche Paket:

```sh
npm install @refinedev/devtools
```
