# UI de Refine Devtools

`@refinedev/devtools-ui` contiene la interfaz que muestra Refine Devtools durante el desarrollo. Forma parte de `@refinedev/devtools` y ayuda a inspeccionar el comportamiento de una aplicacion Refine.

## Sobre el paquete

Refine es headless por diseno y separa datos, autenticacion, autorizacion, routing, notificaciones e i18n mediante providers. Devtools aprovecha esa arquitectura para mostrar recursos, queries, mutaciones y eventos de la aplicacion en una UI de diagnostico.

## Instalacion

Normalmente no necesitas instalar este paquete por separado. Instala Devtools desde el paquete publico:

```sh
npm install @refinedev/devtools
```

## Documentacion

Para informacion detallada y uso, consulta la [documentacion de Refine Devtools](https://refine.dev/docs/packages/devtools).
