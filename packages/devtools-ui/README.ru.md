# UI для Refine Devtools

`@refinedev/devtools-ui` содержит интерфейсную часть `@refinedev/devtools`. Пакет используется внутри devtools и помогает отображать инструменты разработки для refine-приложений.

## Установка

Для подключения devtools к приложению устанавливайте основной пакет:

```sh
npm install @refinedev/devtools
```

## Документация

- Инструкции по использованию смотрите в [документации refine devtools](https://refine.dev/docs/packages/devtools).
- Общая документация refine доступна на [refine.dev/docs](https://refine.dev/docs/).
