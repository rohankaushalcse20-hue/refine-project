# UI do Refine Devtools

`@refinedev/devtools-ui` contem a interface usada pelo Refine Devtools para inspecionar uma aplicacao durante o desenvolvimento. O pacote faz parte de `@refinedev/devtools` e normalmente nao precisa ser instalado de forma isolada.

## Sobre a interface

A UI do Devtools mostra informacoes sobre resources, providers, queries, mutations e estado de execucao. Ela ajuda a diagnosticar configuracoes e entender como os fluxos do Refine estao se comportando localmente.

## Instalacao

Use o pacote publico do Devtools no projeto:

```sh
npm install @refinedev/devtools
```

## Documentacao

Veja a [documentacao do Refine Devtools](https://refine.dev/docs/packages/devtools) para conhecer o setup recomendado e as opcoes disponiveis.
