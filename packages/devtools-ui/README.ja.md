# Refine Devtools UI

`@refinedev/devtools-ui` は、開発中の refine アプリケーションを調査するために Refine Devtools が表示する UI を含みます。`@refinedev/devtools` の一部であり、通常は単独でインストールする必要はありません。

## UI の役割

Devtools UI は resources、providers、queries、mutations、実行時の状態を表示します。設定の確認や、refine の各処理がローカル環境でどのように動いているかを理解する助けになります。

## インストール

プロジェクトでは公開 Devtools パッケージを使います。

```sh
npm install @refinedev/devtools
```

## ドキュメント

推奨 setup と利用できるオプションは、[Refine Devtools ドキュメント](https://refine.dev/docs/packages/devtools)を参照してください。
