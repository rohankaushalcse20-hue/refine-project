# @refinedev/react-hook-form

`@refinedev/react-hook-form` verbindt Refine-form workflows met React Hook Form.

## Wat biedt het?

- Hooks voor create-, edit- en clone-formulieren
- Integratie met Refine mutations en resourcecontext
- Ondersteuning voor validatie- en submitflows van React Hook Form
- Een headless formulierlaag die met elk UI-framework kan worden gecombineerd

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je React Hook Form wilt gebruiken voor formulierstate en validatie, terwijl Refine de resource- en mutationlogica beheert.

Package name, hooknamen en API-namen blijven ongewijzigd.
