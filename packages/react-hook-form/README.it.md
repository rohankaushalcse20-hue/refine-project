# Integrazione React Hook Form per refine

`@refinedev/react-hook-form` collega refine a [React Hook Form](https://react-hook-form.com/) per costruire form CRUD con validazione e gestione dello stato.

## Installazione

```sh
npm install @refinedev/react-hook-form react-hook-form
```

## Uso di base

Importa `useForm` dal pacchetto e usalo nelle pagine create o edit della tua resource.

```tsx
import { useForm } from "@refinedev/react-hook-form";
```

L'hook combina il ciclo di vita dei form refine con le API di React Hook Form, inclusi submit, valori iniziali e integrazione con mutation.

## Documentazione

- Consulta la [documentazione React Hook Form di refine](https://refine.dev/docs/packages/react-hook-form/use-form/).
- Per l'API della libreria, consulta la [documentazione React Hook Form](https://react-hook-form.com/get-started).
