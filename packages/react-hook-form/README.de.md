# React Hook Form Integration fuer refine

`@refinedev/react-hook-form` verbindet Refines Formular-Workflows mit React Hook Form. Dadurch kannst du Refine-Datenoperationen und Formularstatus mit den APIs von `react-hook-form` kombinieren.

## Installation

```sh
npm install @refinedev/react-hook-form
```

## Verwendung

Das Paket ist nuetzlich fuer Create- und Edit-Seiten, serverseitige Validierung, kontrollierte Eingaben und eigene Formularlayouts. Hook-Namen, Feldpfade, Validation Rules und Submit-Handler bleiben Code und werden nicht lokalisiert.

Weitere Informationen findest du in der [React-Hook-Form-Dokumentation](https://refine.dev/docs/packages/react-hook-form/use-form/).
