# @refinedev/ably

`@refinedev/ably` koppelt de realtime mogelijkheden van Ably aan het `liveProvider`-contract van Refine.

## Wat biedt het?

- Een `liveProvider` voor publish/subscribe-updates via Ably
- Hergebruik van een bestaande `Ably.Realtime` client
- Realtime events voor resources, lists en detailpagina's
- Integratie met Refine zonder je data provider te vervangen

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je Refine-app live updates nodig heeft, bijvoorbeeld voor dashboards, samenwerkingsschermen of records die door meerdere gebruikers tegelijk worden bekeken.

Package name, import paths en API-namen blijven ongewijzigd.
