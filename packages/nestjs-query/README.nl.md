# @refinedev/nestjs-query

`@refinedev/nestjs-query` is een data provider voor backends die met NestJS Query en GraphQL zijn opgebouwd.

## Wat biedt het?

- CRUD-methoden die aansluiten op NestJS Query GraphQL schemas
- Ondersteuning voor filters, sorting en pagination
- Mapping naar het Refine `dataProvider`-contract
- Een snellere start voor admin panels boven NestJS Query APIs

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je NestJS Query al als backendlaag gebruikt en Refine daar direct als frontend voor wilt inzetten.

Package name, import paths en NestJS Query-termen blijven ongewijzigd.
