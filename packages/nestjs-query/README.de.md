# NestJS Query Data Provider fuer refine

`@refinedev/nestjs-query` verbindet Refine mit APIs, die auf NestJS Query basieren. Das Paket uebersetzt Refine-Datenoperationen in die passenden GraphQL-Abfragen und Mutations.

## Installation

```sh
npm install @refinedev/nestjs-query
```

## Verwendung

Der Provider eignet sich fuer Anwendungen, deren Backend mit NestJS Query strukturierte CRUD-APIs bereitstellt. Schema-Namen, DTOs, Resolver, Query-Felder und Mutations bleiben API-Vertraege und werden nicht lokalisiert.

Weitere Details findest du in der [NestJS-Query-Provider-Dokumentation](https://refine.dev/docs/data/packages/nestjs-query/).
