# @refinedev/simple-rest

`@refinedev/simple-rest` is een lichte data provider om REST API's te verbinden met het `dataProvider`-contract van Refine.

## Wat biedt het?

- Basis-CRUD-methoden zoals `getList`, `getOne`, `create`, `update`, `deleteOne`
- Snelle integratie met REST-endpoints
- Startgedrag voor pagination, sorting en filtering

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je backend klassieke REST-endpoints aanbiedt en je data snel aan Refine wilt koppelen zonder meteen een eigen provider te schrijven. Als het API-formaat afwijkt, kun je het gedrag uitbreiden of je eigen `dataProvider` maken.

Package name en API-methoden blijven ongewijzigd voor technische compatibiliteit.
