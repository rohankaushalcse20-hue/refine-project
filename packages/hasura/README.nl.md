# @refinedev/hasura

`@refinedev/hasura` is een data provider voor Refine-apps die met Hasura GraphQL APIs werken.

## Wat biedt het?

- CRUD-methoden op basis van Hasura GraphQL
- Ondersteuning voor filtering, sorting en pagination
- Integratie met het Refine `dataProvider`-contract
- Een snellere start voor Hasura-backed admin panels en dashboards

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer Hasura je GraphQL-laag beheert en je die resources direct in Refine wilt gebruiken.

Package name, import paths en Hasura-termen blijven ongewijzigd.
