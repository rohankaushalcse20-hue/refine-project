# Hasura Data Provider fuer refine

`@refinedev/hasura` verbindet Refine mit Hasura-Backends. Das Paket nutzt Hasuras GraphQL-API, damit Refine-Hooks Daten lesen, filtern, sortieren und mutieren koennen.

## Installation

```sh
npm install @refinedev/hasura
```

## Verwendung

Der Provider eignet sich fuer Teams, die Hasura als GraphQL-Schicht vor relationalen Datenbanken verwenden. Tabellen, Rollen, Permissions, Query-Namen und Header bleiben technische Namen und sollten unveraendert bleiben.

Weitere Informationen findest du in der [Hasura-Provider-Dokumentation](https://refine.dev/docs/data/packages/hasura/).
