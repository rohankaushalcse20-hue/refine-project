# Airtable Data Provider fuer refine

`@refinedev/airtable` verbindet Refine-Anwendungen mit Airtable. Das Paket bildet Refines Data-Provider-Vertrag auf Airtable-Tabellen ab, damit CRUD-Aktionen ueber die bekannten Refine-Hooks genutzt werden koennen.

## Installation

```sh
npm install @refinedev/airtable
```

## Verwendung

Der Provider eignet sich fuer interne Tools, Redaktionsoberflaechen und schnelle Prototypen, bei denen Airtable die Datenquelle bleibt. Resource-Namen, Tabellen, API-Schluessel und Feldnamen werden in deiner Anwendung konfiguriert und sollten nicht uebersetzt werden.

Weitere Details findest du in der [Airtable-Provider-Dokumentation](https://refine.dev/docs/data/packages/airtable/).
