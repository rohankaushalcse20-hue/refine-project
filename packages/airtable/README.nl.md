# @refinedev/airtable

`@refinedev/airtable` is een data provider waarmee Refine resources kan lezen en wijzigen via de Airtable API.

## Wat biedt het?

- CRUD-methoden die aansluiten op het `dataProvider`-contract
- Ondersteuning voor Airtable bases, tabellen en records
- Afhandeling van pagination, sorting en filtering waar Airtable dit ondersteunt
- Een snelle route om Airtable als backend voor prototypes of interne tools te gebruiken

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je team data in Airtable beheert en die data in een Refine-app wilt tonen, bewerken of combineren met andere resources.

Package name, import paths en Airtable-termen blijven ongewijzigd.
