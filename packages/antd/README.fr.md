# Intégration Ant Design pour Refine

`@refinedev/antd` apporte les composants, hooks et helpers Ant Design prêts à l'emploi pour les applications Refine.

[Ant Design](https://ant.design/) est une bibliothèque UI React avec des composants adaptés aux interfaces d'administration, dashboards et outils internes. Refine reste headless par conception, mais cette intégration fournit une couche UI productive pour les listes, formulaires, layouts, notifications et écrans CRUD.

## Installation

```sh
npm install @refinedev/antd antd
```

## Démarrage rapide

```sh
npm create refine-app@latest my-refine-app
```

Choisissez Ant Design dans l'assistant pour créer un projet avec les dépendances et le layout déjà configurés.

## Ce que fournit le package

- Composants CRUD comme `List`, `Create`, `Edit` et `Show`.
- Hooks spécialisés comme `useTable`, `useForm`, `useSelect` et `useModal`.
- Intégration avec les composants Ant Design `Table`, `Form`, `Select`, `Drawer` et `Modal`.
- Layout thématique prêt pour les applications d'administration.

Consultez la [documentation Refine Ant Design](https://refine.dev/docs/ui-integrations/ant-design/introduction) pour les guides complets.
