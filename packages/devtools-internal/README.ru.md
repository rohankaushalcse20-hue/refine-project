# Внутренний пакет Refine Devtools

`@refinedev/devtools-internal` содержит общие внутренние части для `@refinedev/devtools`. Пакет не предназначен для прямого использования в приложениях, но помогает собирать devtools-интерфейс и связанные сервисы внутри monorepo.

## Установка

Обычно устанавливают основной пакет devtools:

```sh
npm install @refinedev/devtools
```

## Документация

- Подробности доступны в [документации refine devtools](https://refine.dev/docs/packages/devtools).
- Общая документация refine находится на [refine.dev/docs](https://refine.dev/docs/).
