# Pacote interno do Refine Devtools

`@refinedev/devtools-internal` contem utilitarios internos compartilhados pelos pacotes do Refine Devtools. Ele faz parte da implementacao de `@refinedev/devtools` e nao foi pensado como uma API publica para aplicacoes.

## Sobre o pacote

O Refine Devtools ajuda a inspecionar resources, providers, queries, mutations e eventos de uma aplicacao Refine durante o desenvolvimento. Este pacote agrupa pecas internas usadas pelos pacotes de Devtools para manter essa experiencia consistente.

## Instalacao

Normalmente voce nao precisa instalar este pacote diretamente. Instale o Devtools pelo pacote publico:

```sh
npm install @refinedev/devtools
```

## Documentacao

Consulte a [documentacao do Refine Devtools](https://refine.dev/docs/packages/devtools) para ver a configuracao e o fluxo de uso recomendados.
