# Refine Devtools internal

`@refinedev/devtools-internal`, `@refinedev/devtools` package'ının internal parçalarından biridir. Devtools deneyimini oluşturan ortak geliştirme araçları için kullanılır ve doğrudan uygulama koduna eklenmesi gereken public bir entegrasyon katmanı değildir.

## Kurulum

Devtools kullanmak için public package'ı kurun:

```sh
npm install @refinedev/devtools
```

## Ne zaman kullanılır?

Bu package, Refine Devtools bakımında ve monorepo içindeki internal bağlantılarda kullanılır. Uygulama geliştirirken Devtools'u CLI ve `@refinedev/devtools` üzerinden çalıştırmanız önerilir.

## Dokümantasyon

Ayrıntılı kullanım için [Refine Devtools dokümantasyonunu](https://refine.dev/docs/packages/devtools) okuyun.
