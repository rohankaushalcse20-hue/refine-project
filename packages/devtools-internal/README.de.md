# Refine Devtools Internal

`@refinedev/devtools-internal` enthaelt interne Bausteine, die Refine Devtools waehrend der Entwicklung nutzt. Das Paket gehoert zu `@refinedev/devtools` und ist nicht als direkte Abhaengigkeit fuer Endanwendungen gedacht.

## Ueber das Paket

Refine Devtools hilft beim Pruefen von resources, providers, queries, mutations und Laufzeitereignissen in einer Refine-Anwendung. Dieses interne Paket buendelt gemeinsame Logik, damit die oeffentliche Devtools-Integration stabil bleibt.

## Installation

In den meisten Projekten installierst du nur das oeffentliche Devtools-Paket:

```sh
npm install @refinedev/devtools
```

## Dokumentation

Weitere Hinweise zu Einrichtung und Nutzung findest du in der [Refine Devtools-Dokumentation](https://refine.dev/docs/packages/devtools).
