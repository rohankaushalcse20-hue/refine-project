# Paquete interno de Refine Devtools

`@refinedev/devtools-internal` contiene utilidades internas compartidas por los paquetes de Refine Devtools. Forma parte de la implementacion de `@refinedev/devtools` y no esta pensado como una API publica para aplicaciones.

## Sobre el paquete

Refine Devtools ayuda a inspeccionar recursos, providers, queries y eventos de una aplicacion Refine durante el desarrollo. Este paquete agrupa piezas internas que usan los paquetes de Devtools para mantener esa experiencia consistente.

## Instalacion

Normalmente no necesitas instalar este paquete de forma directa. Instala Devtools mediante el paquete publico:

```sh
npm install @refinedev/devtools
```

## Documentacion

Consulta la [documentacion de Refine Devtools](https://refine.dev/docs/packages/devtools) para conocer la configuracion y el flujo de uso recomendados.
