# @refinedev/medusa

`@refinedev/medusa` helpt Refine-apps verbinden met Medusa voor commerce- en admin-workflows.

## Wat biedt het?

- Providerhulpen voor Medusa-resources
- Integratie met Refine CRUD-patronen
- Een startpunt voor commerce dashboards, productbeheer en orderbeheer
- Minder handmatige vertaling tussen Medusa APIs en Refine resources

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je een beheerinterface rond Medusa bouwt en de standaard Refine-patronen voor data en schermen wilt gebruiken.

Package name, import paths en Medusa-termen blijven ongewijzigd.
