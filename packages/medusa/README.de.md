# Medusa Data Provider fuer refine

`@refinedev/medusa` stellt einen Data Provider fuer Medusa-basierte Commerce-Projekte bereit. Damit lassen sich Produkte, Bestellungen, Kunden und weitere Commerce-Ressourcen in Refine-Oberflaechen verwalten.

## Installation

```sh
npm install @refinedev/medusa
```

## Verwendung

Nutze dieses Paket fuer Admin-Panels und Backoffice-Tools, die mit einer Medusa-API arbeiten. API-Routen, Resource-Namen, Token und Commerce-spezifische Felder bleiben technische Bezeichner.

Weitere Informationen findest du in der [Medusa-Provider-Dokumentation](https://refine.dev/docs/data/packages/medusa/).
