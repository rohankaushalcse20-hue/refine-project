# Refine CORE

**Refine CORE** adalah React meta-framework untuk aplikasi yang padat CRUD. Package ini memberi fondasi headless bagi tim yang membangun internal tools, admin panels, dashboards, dan aplikasi B2B.

Refine CORE memisahkan logika bisnis, akses data, routing, authentication, authorization, notifications, state management, dan i18n dari lapisan tampilan. Karena itu, Anda dapat memakai UI framework apa pun yang sesuai dengan proyek.

## Mulai proyek baru

```sh
npm create refine-app@latest my-refine-app
```

## Mengapa memilihnya?

- Cocok dengan design system atau UI framework apa pun
- Menyediakan hooks dan providers untuk workflow aplikasi bisnis
- Terintegrasi dengan REST, GraphQL, dan berbagai backend services
- Mengurangi pekerjaan CRUD berulang tanpa memaksakan UI tertentu
