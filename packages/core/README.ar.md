# Refine CORE

**Refine CORE** هو React meta-framework للتطبيقات المكثفة في CRUD، ويمنح فرق العمل أساساً headless لبناء internal tools وadmin panels وdashboards وتطبيقات B2B.

يفصل Refine CORE بين منطق الأعمال والوصول إلى البيانات وrouting وauthentication وauthorization وnotifications وstate management وi18n عن طبقة العرض، لذلك يمكنك استخدام أي UI framework يناسب المشروع.

## ابدأ مشروعاً جديداً

```sh
npm create refine-app@latest my-refine-app
```

## لماذا قد تختاره؟

- متوافق مع أي design system أو UI framework
- يوفر hooks وproviders مناسبة لتدفقات العمل المؤسسية
- يتكامل مع REST وGraphQL وعدة backend services
- يقلل الأعمال المتكررة الخاصة بـ CRUD من دون فرض UI ثابت

## التوثيق

راجع التوثيق الرئيسي للحصول على الأدلة والدروس ومرجع الـ API.
