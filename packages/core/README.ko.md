# Refine CORE

**Refine CORE**는 CRUD 비중이 큰 웹 애플리케이션을 위한 React 메타 프레임워크입니다. 내부 도구, 관리자 패널, 대시보드, B2B 애플리케이션을 위한 탄탄한 기반을 제공합니다.

Refine CORE는 headless 아키텍처를 채택해 데이터 처리, routing, 인증, 인가, 알림, 상태 관리, i18n을 표시 계층과 분리합니다.

## 새 프로젝트 시작하기

```sh
npm create refine-app@latest my-refine-app
```

## 선택해야 하는 이유

- 어떤 design system이나 UI framework와도 조합 가능
- 엔터프라이즈 애플리케이션에서 반복되는 패턴을 hooks와 providers로 바로 활용 가능
- REST, GraphQL, 다양한 backend services와 통합 가능
- 고정 UI에 묶이지 않으면서 CRUD 반복 작업을 줄일 수 있음
