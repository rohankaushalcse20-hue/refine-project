# Refine CORE

**Refine CORE** ist ein React-Meta-Framework fuer Webanwendungen mit vielen CRUD-Ablaufen. Es dient als Grundlage fuer interne Tools, Admin-Panels, Dashboards und B2B-Anwendungen.

Refine CORE verfolgt eine Headless-Architektur: Datenlogik, Routing, Authentifizierung, Autorisierung, Benachrichtigungen, State und i18n bleiben von der Darstellung getrennt.

## Projekt starten

```sh
npm create refine-app@latest my-refine-app
```

## Warum es sich lohnt

- Du kannst jedes Design oder UI-Framework verwenden.
- Hooks und Provider fuer haeufige Enterprise-Muster sind bereits vorhanden.
- Refine funktioniert mit REST, GraphQL und mehreren Backend-Diensten.
- Wiederkehrende CRUD-Arbeit wird reduziert, ohne die Anwendung in eine feste UI zu zwingen.
