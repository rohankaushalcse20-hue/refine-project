# @refinedev/core

`@refinedev/core` is de headless core van Refine. Het pakket levert resources, providers, hooks en applicatiestate-gedrag zonder een specifiek UI-framework op te leggen.

## Wat biedt het?

- Root component `Refine`
- Contracten voor resources en providers
- Hooks voor data fetching en mutations
- Integratiepunten voor authentication, authorization, notification en i18n
- Helpers voor routing en navigation

## Wanneer gebruik je dit?

`@refinedev/core` is het startpakket wanneer je je eigen UI-laag of gekozen design system wilt gebruiken, terwijl je wel profiteert van de data-, routing- en providerarchitectuur van Refine.

Package name, import path en API-namen blijven ongewijzigd.
