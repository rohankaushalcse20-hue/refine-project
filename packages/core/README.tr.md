# Refine CORE

**Refine CORE**, CRUD yoğun uygulamalar için bir React meta-framework'tür. Bu package; internal tools, admin panels, dashboards ve B2B uygulamaları geliştiren ekiplere headless bir temel sağlar.

Refine CORE iş mantığını, veri erişimini, routing, authentication, authorization, notifications, state management ve i18n katmanlarını görünüm katmanından ayırır. Bu nedenle projeye en uygun UI framework'ü kullanabilirsiniz.

## Yeni proje başlatma

```sh
npm create refine-app@latest my-refine-app
```

## Neden seçilmeli?

- Herhangi bir design system veya UI framework ile uyumludur
- İş uygulaması workflow'ları için hooks ve providers sağlar
- REST, GraphQL ve farklı backend services ile entegre olur
- Belirli bir UI dayatmadan tekrarlayan CRUD işlerini azaltır
