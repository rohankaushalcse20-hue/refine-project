# Refine CORE

**Refine CORE** は、CRUD を多く含む Web アプリケーション向けの React メタフレームワークです。社内ツール、管理画面、ダッシュボード、B2B アプリケーションのような業務用途に向けた堅実な土台を提供します。

Refine CORE は headless アーキテクチャを採用しており、データ処理、routing、認証、認可、通知、状態管理、i18n を表示レイヤーから分離します。

## 新しいプロジェクトを作成する

```sh
npm create refine-app@latest my-refine-app
```

## 選ぶ理由

- どの design system や UI framework とも組み合わせられる
- enterprise 向けの一般的なパターンを hooks と providers で最初から利用できる
- REST、GraphQL、多様な backend services と統合できる
- 固定 UI に縛られず、CRUD の繰り返し作業を減らせる
