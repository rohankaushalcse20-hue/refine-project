# @refinedev/core

`@refinedev/core` è il core headless di Refine. Fornisce resources, providers, hooks e comportamenti di application state indipendenti dal framework UI.

## Cosa offre?

- Componente root `Refine`
- Contratti per resource e provider
- Hooks per data fetching e mutations
- Punti di integrazione per authentication, authorization, notification e i18n
- Helper per routing e navigation

## Quando usarlo?

`@refinedev/core` è il pacchetto di partenza quando vuoi usare il tuo livello UI o il design system scelto, sfruttando al tempo stesso l'architettura dati, routing e provider di Refine.

Nome del package, import path e nomi API sono mantenuti invariati.
