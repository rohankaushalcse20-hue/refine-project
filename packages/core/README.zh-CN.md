# Refine CORE

**Refine CORE** 是一个面向 CRUD 密集型 Web 应用的 React 元框架，可为内部工具、管理后台、仪表盘与 B2B 应用提供稳定基础。

Refine CORE 采用 headless 架构，将数据处理、routing、authentication、authorization、notifications、state management 与 i18n 从展示层中解耦出来。

## 开始新项目

```sh
npm create refine-app@latest my-refine-app
```

## 适合使用它的原因

- 可以与任意 design system 或 UI framework 组合
- 能直接复用企业应用中常见的 hooks 与 providers 模式
- 支持与 REST、GraphQL 及多种 backend services 集成
- 在不绑定固定 UI 的前提下减少重复 CRUD 工作
