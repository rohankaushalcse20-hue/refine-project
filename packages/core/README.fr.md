# Refine CORE

**Refine CORE** est un meta-framework React pour les applications web riches en CRUD. Il sert de base aux outils internes, panels d'administration, dashboards et applications B2B.

Refine CORE adopte une architecture headless : données, routing, auth, permissions, notifications, état et i18n restent séparés de la couche visuelle.

## Créer un projet

```sh
npm create refine-app@latest my-refine-app
```

## Pourquoi l'utiliser

- Compatible avec tout design ou framework UI.
- Hooks et providers pour les patterns d'entreprise courants.
- Fonctionne avec REST, GraphQL et de nombreux services backend.
- Réduit le travail répétitif sans imposer une UI fixe.

Consultez la documentation principale pour guides, tutoriels et référence API.
