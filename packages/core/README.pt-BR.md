# Refine CORE

**Refine CORE** é um meta-framework React para aplicações web com muitos fluxos de CRUD. Ele serve como base para ferramentas internas, painéis administrativos, dashboards e aplicações B2B.

O Refine CORE segue uma arquitetura headless: lógica de dados, routing, autenticação, autorização, notificações, estado e i18n ficam separados da apresentação.

## Começando um projeto

```sh
npm create refine-app@latest my-refine-app
```

## Por que vale a pena

- Você pode usar qualquer design ou framework de UI.
- Hooks e providers para padrões comuns de aplicações corporativas já vêm prontos.
- O Refine funciona com REST, GraphQL e vários serviços de backend.
- O trabalho repetitivo de CRUD diminui sem prender a aplicação a uma UI fixa.
