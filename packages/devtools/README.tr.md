# Refine Devtools

`@refinedev/devtools`, gelistirme sirasinda Refine uygulamalarini incelemeye yardim eder. Resource'lari, provider davranislarini, query durumlarini ve uygulama icindeki Refine akisini gormek icin kullanilir.

## Kullanim

Devtools'u projenizle birlikte baslatmak icin Refine CLI'yi kurabilir veya guncelleyebilirsiniz:

```sh
npm install @refinedev/cli@latest
```

Devtools gelistirme moduna yoneliktir; production bundle'a ek is yuk getirmeden uygulama davranisini anlamaya yardim eder.

## Ne zaman kullanilmali?

Data provider entegrasyonlarini debug ederken, resource durumlarini kontrol ederken veya Refine'in islemleri nasil cozumledigini anlamak istediginizde kullanin.

## Dokumantasyon

Kurulum ve ayrintili kullanim icin [Refine Devtools dokumantasyonunu](https://refine.dev/docs/guides-concepts/development/#refine-devtools) inceleyin.
