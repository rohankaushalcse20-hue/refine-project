# Refine Devtools

Package `@refinedev/devtools` membantu memeriksa aplikasi Refine selama development. Anda dapat meninjau resources, providers, queries, dan perilaku aplikasi tanpa menambahkan beban ke production bundle.

## Penggunaan

Instal atau jalankan Refine CLI untuk memulai Devtools bersama project Anda:

```sh
npm install @refinedev/cli@latest
```

Devtools ditujukan untuk mode development. Anda tidak memerlukan konfigurasi khusus untuk mengecualikannya dari production builds.

## Kapan digunakan?

Gunakan Devtools untuk mendiagnosis integrasi data provider, meninjau status resources, dan memahami bagaimana Refine menyelesaikan operasi di dalam aplikasi.

## Dokumentasi

Baca [dokumentasi Refine Devtools](https://refine.dev/docs/guides-concepts/development/#refine-devtools) untuk setup lengkap.
