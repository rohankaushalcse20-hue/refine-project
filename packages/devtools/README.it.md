# @refinedev/devtools

`@refinedev/devtools` aggiunge strumenti di sviluppo per osservare e debuggare applicazioni refine durante il lavoro locale.

## Installazione

```sh
npm install @refinedev/devtools
```

## Uso di base

Avvia Devtools con la CLI refine e collega il client all'applicazione in modalità sviluppo.

```sh
refine dev
```

Devtools funziona solo in sviluppo e non aggiunge overhead ai bundle di produzione. Non è necessario configurare esclusioni speciali per la build finale.

- Consulta la [documentazione Devtools](https://refine.dev/docs/packages/devtools/).
- Per installare la CLI, consulta la [documentazione di @refinedev/cli](https://refine.dev/docs/packages/cli/).
