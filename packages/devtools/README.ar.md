# Refine Devtools

تساعد حزمة `@refinedev/devtools` على فحص تطبيقات Refine أثناء التطوير. تتيح مراجعة resources وproviders وqueries وسلوك التطبيق من دون إضافة عبء إلى bundle الإنتاج.

## الاستخدام

ثبّت Refine CLI أو شغّله لبدء Devtools مع مشروعك:

```sh
npm install @refinedev/cli@latest
```

Devtools مخصصة لوضع التطوير. لا تحتاج إلى إعداد خاص لاستبعادها من builds الإنتاج.

## متى تستخدمها؟

استخدمها لتشخيص تكاملات data provider، ومراجعة حالات resources، وفهم كيف يحل Refine العمليات داخل التطبيق.

## التوثيق

راجع [توثيق Refine Devtools](https://refine.dev/docs/guides-concepts/development/#refine-devtools) للإعداد الكامل.
