# Refine Devtools

`@refinedev/devtools` ayuda a inspeccionar aplicaciones Refine durante el desarrollo. Permite revisar recursos, providers, queries y comportamiento de la aplicacion sin agregar sobrecarga al bundle de produccion.

## Uso

Instala o ejecuta la CLI de Refine para iniciar Devtools junto a tu proyecto:

```sh
npm install @refinedev/cli@latest
```

Devtools esta pensado para modo desarrollo. No necesitas configuracion especial para excluirlo de builds de produccion.

## Cuándo usarlo

Usalo para diagnosticar integraciones de data provider, revisar estados de recursos y entender como Refine esta resolviendo operaciones dentro de la aplicacion.

## Documentacion

Consulta la [documentacion de Refine Devtools](https://refine.dev/docs/guides-concepts/development/#refine-devtools) para la configuracion completa.
