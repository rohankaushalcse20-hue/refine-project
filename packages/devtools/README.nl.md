# @refinedev/devtools

`@refinedev/devtools` helpt je Refine-apps tijdens ontwikkeling te inspecteren en te debuggen.

## Wat biedt het?

- Hulpmiddelen voor het bekijken van queries en mutations
- Ondersteuning voor het testen van inferencer-output
- UI-hulpen voor package- en projectinformatie
- Ontwikkeltools zonder runtime-overhead in productiebuilds

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je tijdens ontwikkeling meer zicht nodig hebt op Refine-gedrag, dataflows en gegenereerde code.

Package name, commandos en Devtools-termen blijven ongewijzigd.
