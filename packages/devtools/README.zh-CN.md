# refine Devtools

`@refinedev/devtools` 在开发模式下帮助调试和开发 refine 应用。它可用于检查 queries 与 mutations、测试 Inferencer 生成的代码，并通过界面管理 refine 包。

## 用法

安装最新版 `@refinedev/cli`：

```bash
npm install @refinedev/cli@latest
```

使用 CLI 安装 `@refinedev/devtools`：

```bash
npm run refine devtools init
```

> 如果尚未安装 `@refinedev/cli`，请先按照[安装指南](https://refine.dev/docs/packages/cli/#how-to-add-to-an-existing-project)把它添加到项目中。

Devtools 只在开发模式下工作，不会给生产构建增加额外开销。
