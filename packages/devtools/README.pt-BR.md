# Devtools do refine

`@refinedev/devtools` ajuda a depurar e desenvolver aplicacoes refine durante o modo de desenvolvimento. A ferramenta foi criada para inspecionar queries e mutations, testar codigo gerado pelo Inferencer e gerenciar pacotes refine pela interface.

## Uso

Instale a versao mais recente de `@refinedev/cli`:

```bash
npm install @refinedev/cli@latest
```

Instale `@refinedev/devtools` com o CLI:

```bash
npm run refine devtools init
```

> Se `@refinedev/cli` ainda nao estiver instalado, siga o [guia de instalacao](https://refine.dev/docs/packages/cli/#how-to-add-to-an-existing-project) para adiciona-lo ao projeto.

O Devtools funciona apenas em modo de desenvolvimento e nao adiciona overhead aos builds de producao.
