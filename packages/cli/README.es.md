# CLI de Refine

`@refinedev/cli` reúne los comandos principales para crear, ampliar y mantener proyectos hechos con Refine. Ayuda a reducir código repetitivo al generar resources, providers y flujos de personalización habituales.

## Instalación

```sh
npm install @refinedev/cli
```

## Qué puedes hacer con ella

- Ejecutar asistentes para crear o extender una app.
- Añadir `resource`, `auth`, `data`, `live`, `notification`, `i18n` y otros providers.
- Usar comandos como `swizzle`, `dev`, `build` y `start` en los proyectos compatibles.

## Cuándo usarla

Úsala cuando quieras acelerar tareas repetitivas de desarrollo y mantener una estructura coherente en proyectos Refine.

## Más información

Consulta la documentación de la CLI para revisar los comandos disponibles y los flujos de trabajo recomendados.
