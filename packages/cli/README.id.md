# Refine CLI

Package `@refinedev/cli` mengumpulkan perintah utama untuk membuat, memperluas, dan memelihara project Refine. CLI membantu mengurangi kode berulang dengan membuat `resource`, providers, dan alur kustomisasi yang sering dipakai.

## Instalasi

```sh
npm install @refinedev/cli
```

## Apa yang bisa dilakukan?

- Menjalankan assistant untuk membuat app atau memperluas app yang ada.
- Menambahkan `resource`, `auth`, `data`, `live`, `notification`, `i18n`, dan provider lainnya.
- Memakai perintah seperti `swizzle`, `dev`, `build`, dan `start` pada project yang kompatibel.

## Kapan digunakan?

Gunakan package ini untuk mempercepat tugas pengembangan berulang dan menjaga struktur yang konsisten di project Refine.

## Selengkapnya

Baca dokumentasi CLI untuk daftar perintah dan workflow yang direkomendasikan.
