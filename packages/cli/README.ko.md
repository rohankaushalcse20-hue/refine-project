# Refine CLI

`@refinedev/cli`는 Refine projects를 위한 command-line tooling입니다. project maintenance, package checks, Refine-specific developer workflows를 terminal에서 실행할 수 있게 해 줍니다.

## 설치

```sh
npm install @refinedev/cli
```

## 사용

CLI는 Refine applications에서 반복되는 setup과 maintenance steps를 standardized commands로 관리하려는 teams에 적합합니다. framework의 package ecosystem과 함께 동작하므로 project scripts에 쉽게 연결할 수 있습니다.

자세한 내용은 [Refine documentation](https://refine.dev/docs/)과 [tutorials](https://refine.dev/docs/tutorial/introduction/index/)를 참고하세요.
