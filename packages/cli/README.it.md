# @refinedev/cli

`@refinedev/cli` fornisce comandi da terminale per sviluppare, aggiornare e ispezionare progetti refine.

## Installazione

```sh
npm install @refinedev/cli
```

## Uso di base

Usa la CLI per avviare strumenti di sviluppo, gestire Devtools e applicare utility supportate dal progetto.

```sh
refine dev
```

Il pacchetto è pensato per accompagnare il ciclo di sviluppo locale e mantenere i comandi refine disponibili senza modificare codice applicativo o API.
