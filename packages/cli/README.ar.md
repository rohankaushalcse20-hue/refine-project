# Refine CLI

تجمع حزمة `@refinedev/cli` الأوامر الأساسية لإنشاء مشاريع Refine وتوسيعها وصيانتها. تساعد على تقليل الكود المتكرر عبر توليد resources وproviders وتدفقات التخصيص الشائعة.

## التثبيت

```sh
npm install @refinedev/cli
```

## ما الذي يمكنك فعله بها؟

- تشغيل مساعدين لإنشاء app أو توسيعها.
- إضافة `resource` و`auth` و`data` و`live` و`notification` و`i18n` وproviders أخرى.
- استخدام أوامر مثل `swizzle` و`dev` و`build` و`start` في المشاريع المتوافقة.

## متى تستخدمها؟

استخدمها عندما تريد تسريع مهام التطوير المتكررة والحفاظ على بنية متسقة في مشاريع Refine.

## المزيد

راجع توثيق CLI لمعرفة الأوامر المتاحة وتدفقات العمل الموصى بها.
