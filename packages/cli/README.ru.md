# CLI для refine

`@refinedev/cli` предоставляет командные инструменты для проектов refine. CLI помогает запускать devtools, проверять проект, обновлять пакеты и выполнять служебные операции без ручной настройки каждого шага.

## Установка

```sh
npm install @refinedev/cli
```

## Базовое использование

После установки используйте команду `refine` из package scripts или через `npx`, в зависимости от настройки проекта.

```sh
npx refine --help
```

CLI особенно полезен при добавлении refine в существующее приложение, подключении devtools и поддержке зависимостей в актуальном состоянии.

## Документация

- Откройте [документацию CLI](https://refine.dev/docs/packages/cli/).
- Для создания нового проекта используйте [create refine app](https://refine.dev/docs/getting-started/quickstart/).
