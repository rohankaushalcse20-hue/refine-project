# Refine CLI

`@refinedev/cli`, Refine projelerini olusturmak, genisletmek ve gelistirme sirasinda bakim yapmak icin kullanilan komutlari bir araya getirir. Resource, provider ve yaygin proje islemlerini daha tutarli hale getirir.

## Kurulum

```sh
npm install @refinedev/cli
```

## Neler yapabilirsiniz?

- Yeni veya mevcut bir Refine uygulamasini yardimci komutlarla genisletebilirsiniz.
- `resource`, `auth`, `data`, `live`, `notification` ve `i18n` provider akislari ekleyebilirsiniz.
- Uyumlu projelerde `swizzle`, `dev`, `build` ve `start` gibi komutlari kullanabilirsiniz.

## Ne zaman kullanilmali?

Tekrarlayan gelistirme islerini hizlandirmak ve Refine projelerinde ortak bir yapiyi korumak istediginizde bu package'i kullanin.

## Daha fazla bilgi

Mevcut komutlar ve onerilen workflow'lar icin Refine CLI dokumantasyonunu inceleyin.
