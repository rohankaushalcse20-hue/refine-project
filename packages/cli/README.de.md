# Refine CLI

`@refinedev/cli` stellt Kommandozeilen-Werkzeuge fuer Refine-Projekte bereit. Damit kannst du Wartung, Paketpruefungen und Refine-spezifische Entwickler-Workflows direkt im Terminal ausfuehren.

## Installation

```sh
npm install @refinedev/cli
```

## Verwendung

Die CLI ist hilfreich fuer Teams, die wiederkehrende Setup- und Maintenance-Schritte in Refine-Anwendungen standardisieren moechten. Sie arbeitet mit dem Paket-Oekosystem von Refine zusammen und laesst sich in bestehende Project Scripts einbinden.

Mehr Informationen findest du in der [Refine-Dokumentation](https://refine.dev/docs/) und in den [Tutorials](https://refine.dev/docs/tutorial/introduction/index/).
