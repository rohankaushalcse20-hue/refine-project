# CLI do refine

`@refinedev/cli` reune comandos para criar, manter e automatizar tarefas em projetos refine. Ele ajuda a iniciar projetos, integrar ferramentas auxiliares e executar fluxos comuns sem configurar tudo manualmente.

## Instalacao

```sh
npm install @refinedev/cli
```

## Quando usar

- Adicionar utilitarios oficiais do refine a um projeto existente.
- Padronizar comandos de manutencao para ferramentas internas e dashboards.
- Trabalhar junto com pacotes como `@refinedev/devtools`.
