# Refine CLI

`@refinedev/cli` Refine projects के लिए command-line tooling देता है। इससे आप project maintenance, package checks और Refine-specific developer workflows को terminal से चला सकते हैं।

## Installation

```sh
npm install @refinedev/cli
```

## उपयोग

CLI उन teams के लिए उपयोगी है जो Refine applications में repetitive setup और maintenance steps को standardized commands से संभालना चाहते हैं। यह framework के package ecosystem के साथ काम करता है, इसलिए project scripts में इसे जोड़ना आसान रहता है।

अधिक जानकारी के लिए [Refine documentation](https://refine.dev/docs/) और [tutorials](https://refine.dev/docs/tutorial/introduction/index/) देखें।
