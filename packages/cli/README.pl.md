# CLI dla Refine

`@refinedev/cli` udostępnia narzędzia wiersza poleceń dla projektów Refine. CLI pomaga uruchamiać devtools, sprawdzać projekt, aktualizować pakiety i wykonywać zadania utrzymaniowe bez ręcznej konfiguracji każdego kroku.

## Instalacja

```sh
npm install @refinedev/cli
```

## Podstawowe użycie

Po instalacji użyj komendy `refine` ze skryptów pakietu albo przez `npx`, zależnie od konfiguracji projektu.

```sh
npx refine --help
```

CLI jest szczególnie przydatne przy dodawaniu Refine do istniejącej aplikacji, podłączaniu devtools i utrzymywaniu zależności w aktualnym stanie.

## Dokumentacja

- Otwórz [dokumentację CLI](https://refine.dev/docs/packages/cli/).
- Do utworzenia nowego projektu użyj [create refine app](https://refine.dev/docs/getting-started/quickstart/).
