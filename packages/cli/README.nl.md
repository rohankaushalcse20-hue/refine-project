# @refinedev/cli

`@refinedev/cli` bevat command-line hulpmiddelen voor het beheren, ontwikkelen en uitbreiden van Refine-projecten.

## Wat biedt het?

- Projectcommando's voor Refine-workflows
- Ondersteuning voor devtools-installatie
- Hulpmiddelen om package- en projectinformatie te inspecteren
- Integratie met bestaande npm-, pnpm- en yarn-projecten

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je Refine-taken vanuit de terminal wilt uitvoeren, zoals devtools initialiseren of projecthulpen starten tijdens ontwikkeling.

Package name, commandonamen en flags blijven ongewijzigd.
