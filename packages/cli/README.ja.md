# Refine CLI

`@refinedev/cli` は、Refine プロジェクトの作成、拡張、保守に使う主要なコマンドをまとめた CLI です。`resource` や provider、よく使うカスタマイズの雛形を生成し、CRUD アプリケーションで発生しやすい反復作業を減らします。

## インストール

```sh
npm install @refinedev/cli
```

## できること

- アプリケーションの作成や拡張のためのウィザードを実行する。
- `resource`、`auth`、`data`、`live`、`notification`、`i18n` などの provider を追加する。
- 対応プロジェクトで `swizzle`、`dev`、`build`、`start` などのコマンドを使う。

## 使いどころ

Refine プロジェクトで繰り返し発生する開発作業を短縮し、チーム内で一貫した構成を保ちたい場合に使います。

## 詳細

利用できるコマンドと推奨ワークフローは、Refine CLI のドキュメントを参照してください。
