# refine CLI

`@refinedev/cli` 汇集了用于创建、维护和自动化 refine 项目的命令。它可以帮助你初始化项目、接入辅助工具，并运行常见流程，而不必手动完成所有配置。

## 安装

```sh
npm install @refinedev/cli
```

## 适用场景

- 向现有项目添加 refine 官方工具。
- 为内部工具和仪表盘统一维护命令。
- 与 `@refinedev/devtools` 等包配合使用。
