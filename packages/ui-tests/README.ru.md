# UI tests для refine

`@refinedev/ui-tests` содержит вспомогательные материалы для проверки UI-пакетов refine. Пакет используется внутри monorepo, чтобы поддерживать согласованное поведение компонентов и интеграций.

## Назначение

- Проверять пользовательские flows для UI integrations.
- Поддерживать regression coverage для компонентов refine.
- Использоваться как внутренняя часть разработки пакетов, а не как runtime dependency приложения.

## Документация

Основные сведения о refine доступны в [документации](https://refine.dev/docs/), а примеры пользовательских flows собраны в [examples](https://refine.dev/docs/examples/).
