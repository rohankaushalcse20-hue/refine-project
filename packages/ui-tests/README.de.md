# Refine UI Tests

`@refinedev/ui-tests` enthaelt Testhilfen und Szenarien zum Validieren von UI-Ablaufen in Refine-Paketen und Integrationen. Das Paket hilft, coverage fuer components, providers und haeufige Verhaltensweisen von CRUD-Anwendungen stabil zu halten.

## Ueber Refine

Refine ist ein headless React-Framework fuer datenintensive Webanwendungen wie admin panels, dashboards, interne Tools und B2B-Anwendungen. Es reduziert wiederkehrende CRUD-Arbeit und bietet standardisierte Loesungen fuer kritische Bereiche wie **authentication**, **access control**, **routing**, **networking**, **state management** und **i18n**.

Durch den headless Ansatz stellt Refine hooks, components und providers bereit, die nicht an eine bestimmte UI-Bibliothek gebunden sind. Du kannst ein eigenes Design verwenden oder fertige Integrationen fuer [Ant Design](https://ant.design/), [Material UI](https://mui.com/material-ui/getting-started/overview/), [Mantine](https://mantine.dev/) und [Chakra UI](https://chakra-ui.com/) nutzen.

## Paketnutzung

Dieses Paket richtet sich an die interne Wartung des Monorepos. Es wird normalerweise nicht direkt in Endanwendungen installiert, sondern prueft, ob die UI-Integrationen von Refine konsistent funktionieren.
