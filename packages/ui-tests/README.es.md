# Pruebas de UI de Refine

`@refinedev/ui-tests` contiene utilidades y escenarios de prueba para validar flujos de interfaz en paquetes e integraciones de Refine. Ayuda a mantener cobertura sobre componentes, providers y comportamientos comunes usados por aplicaciones CRUD.

## Sobre Refine

Refine es un framework React headless para construir aplicaciones web con datos intensivos, como admin panels, dashboards, herramientas internas y aplicaciones B2B. Elimina tareas repetitivas de CRUD y ofrece soluciones estandar para partes criticas como **authentication**, **access control**, **routing**, **networking**, **state management** e **i18n**.

Al ser headless por diseno, Refine proporciona hooks, components y providers desacoplados de una biblioteca UI concreta. Puedes usar un diseno propio o integraciones listas para [Ant Design](https://ant.design/), [Material UI](https://mui.com/material-ui/getting-started/overview/), [Mantine](https://mantine.dev/) y [Chakra UI](https://chakra-ui.com/).

## Uso del paquete

Este paquete esta orientado al mantenimiento interno del monorepo. Normalmente no se instala directamente en aplicaciones finales; se usa para verificar que las integraciones de UI de Refine sigan funcionando de forma consistente.
