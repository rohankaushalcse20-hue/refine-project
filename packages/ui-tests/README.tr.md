# Refine UI tests

`@refinedev/ui-tests`, Refine UI package'ları ve entegrasyonları için test yardımcılarını barındırır. UI davranışını tutarlı şekilde doğrulamak ve ortak test setup'larını paylaşmak için kullanılır.

## Ne zaman kullanılır?

Bu package, monorepo içindeki UI component'leri ve integration package'ları test edilirken yararlıdır. Uygulama geliştirirken doğrudan public API olarak kullanılması beklenmez.

## Refine hakkında

Refine, CRUD yoğun web uygulamaları için headless React framework'tür. Authentication, access control, routing, networking, state management ve i18n gibi temel parçalar için provider tabanlı çözümler sağlar.

## Dokümantasyon

Refine kullanım senaryoları, örnekler ve testing yaklaşımları için [ana dokümantasyonu](https://refine.dev/docs/) inceleyin.
