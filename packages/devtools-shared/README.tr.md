# Refine Devtools shared

`@refinedev/devtools-shared`, Refine Devtools package'ları arasında paylaşılan internal tipleri ve yardımcıları barındırır. Devtools server, UI ve diğer internal parçaların aynı sözleşmelerle çalışmasına yardımcı olur.

## Kurulum

Devtools deneyimini kullanmak için public package'ı kurun:

```sh
npm install @refinedev/devtools
```

## Ne zaman kullanılır?

Bu package normal Refine uygulamalarında doğrudan import edilmek için değildir. Devtools geliştirme ve bakımında ortak veri yapıları gerektiğinde kullanılır.

## Dokümantasyon

Devtools kurulumu ve kullanım akışı için [Refine Devtools dokümantasyonunu](https://refine.dev/docs/packages/devtools) okuyun.
