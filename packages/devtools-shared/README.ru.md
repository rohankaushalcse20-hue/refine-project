# Общие модули Refine Devtools

`@refinedev/devtools-shared` содержит shared utilities и типы для пакетов `@refinedev/devtools`. Он поддерживает согласованную работу UI, server и internal-частей devtools внутри refine.

## Установка

В обычном приложении используйте основной пакет:

```sh
npm install @refinedev/devtools
```
