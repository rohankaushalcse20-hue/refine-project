# Utilitarios compartilhados do Refine Devtools

`@refinedev/devtools-shared` contem tipos, constantes e utilitarios compartilhados entre os pacotes do Refine Devtools. Ele ajuda a manter a comunicacao entre a aplicacao, o servidor e a UI do Devtools alinhada.

## Quando usar

Este pacote e voltado principalmente para a implementacao interna do Devtools. Em aplicacoes Refine comuns, instale e configure o pacote publico:

```sh
npm install @refinedev/devtools
```

## Observacoes

- Nomes de eventos, payloads e contracts internos devem permanecer iguais ao codigo.
- O pacote acompanha a versao de `@refinedev/devtools`.
- APIs publicas de uso do Devtools devem ser consultadas na documentacao principal.

## Documentacao

Consulte a [documentacao do Refine Devtools](https://refine.dev/docs/packages/devtools) para detalhes de instalacao e uso.
