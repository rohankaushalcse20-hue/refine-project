# Utilidades compartidas de Refine Devtools

`@refinedev/devtools-shared` reune tipos y utilidades compartidas por los paquetes de Refine Devtools. Es una dependencia interna de la experiencia de Devtools y no suele usarse directamente en aplicaciones.

## Sobre el paquete

Refine Devtools permite inspeccionar recursos, providers y operaciones de datos durante el desarrollo. Este paquete mantiene contratos compartidos para que el servidor, la UI y otros paquetes internos de Devtools trabajen con los mismos datos.

## Instalacion

Para usar Devtools, instala el paquete publico:

```sh
npm install @refinedev/devtools
```

## Documentacion

Consulta la [documentacion de Refine Devtools](https://refine.dev/docs/packages/devtools) para ver la configuracion completa y ejemplos de uso.
