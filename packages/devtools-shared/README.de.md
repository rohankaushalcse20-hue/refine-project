# Refine Devtools Shared

`@refinedev/devtools-shared` enthaelt gemeinsame Typen und Hilfsfunktionen fuer Refine Devtools. Server, UI und interne Devtools-Pakete koennen dadurch dieselben contracts fuer Diagnoseinformationen verwenden.

## Ueber das Paket

Refine Devtools nutzt die headless Architektur von Refine, um resources, providers, queries, mutations und Ereignisse nachvollziehbar darzustellen. Dieses Paket haelt die gemeinsam genutzte Logik getrennt von der konkreten UI- oder Server-Implementierung.

## Installation

Endanwendungen installieren dieses Paket normalerweise nicht direkt. Verwende stattdessen:

```sh
npm install @refinedev/devtools
```
