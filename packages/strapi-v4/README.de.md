# Strapi v4 Data Provider fuer refine

`@refinedev/strapi-v4` verbindet Refine mit Strapi-v4-Projekten. Der Provider hilft dabei, Content Types, Collections und Eintraege ueber Refine-Resources zu verwalten.

## Installation

```sh
npm install @refinedev/strapi-v4
```

## Verwendung

Nutze dieses Paket fuer Content-Management-Oberflaechen, interne Redaktionswerkzeuge und Backoffice-Apps mit Strapi v4. Content-Type-UIDs, API-Routen, Rollen und Feldnamen bleiben Strapi-Konventionen und werden nicht lokalisiert.

Weitere Informationen findest du in der [Strapi-v4-Provider-Dokumentation](https://refine.dev/docs/data/packages/strapi-v4/).
