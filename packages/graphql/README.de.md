# GraphQL Data Provider fuer refine

`@refinedev/graphql` ergaenzt Refine um GraphQL-basierte Datenoperationen. Es hilft dabei, Refine-Resources, Queries und Mutations mit einer GraphQL-API zu verbinden.

## Installation

```sh
npm install @refinedev/graphql
```

## Verwendung

Nutze dieses Paket, wenn deine Anwendung GraphQL als Hauptschnittstelle fuer Listen, Detailansichten, Erstellen, Aktualisieren oder Loeschen verwendet. Query-Namen, Mutations, Fragmente und Schema-Felder bleiben Teil der API und werden nicht lokalisiert.

Weitere Details findest du in der [GraphQL-Provider-Dokumentation](https://refine.dev/docs/data/packages/graphql/).
