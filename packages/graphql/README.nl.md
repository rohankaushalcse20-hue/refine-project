# @refinedev/graphql

`@refinedev/graphql` biedt GraphQL-hulpen om Refine data providers met GraphQL APIs te bouwen.

## Wat biedt het?

- Utilities voor GraphQL-query's en mutations
- Integratiepunten voor het `dataProvider`-contract
- Ondersteuning voor resources, filters, sorting en paginationpatronen
- Een basis voor GraphQL-backends die niet door een kant-en-klare provider worden afgedekt

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je backend GraphQL spreekt en je Refine-resources wilt verbinden met queries en mutations die bij je schema passen.

Package name, import paths en GraphQL-termen blijven ongewijzigd.
