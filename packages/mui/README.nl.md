# @refinedev/mui

`@refinedev/mui` biedt Material UI-integraties voor Refine-apps.

## Wat biedt het?

- CRUD-componenten zoals `List`, `Create`, `Edit` en `Show`
- Hooks zoals `useDataGrid`, `useAutocomplete` en formhulpen
- Layout-, field- en notificationcomponenten voor Material UI
- Integratie met Refine resources, routing en providerstatus

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je Material UI als visuele laag gebruikt en Refine de applicatiestructuur, dataflows en resourceconfiguratie wilt laten beheren.

Package name, componentnamen en API-namen blijven ongewijzigd.
