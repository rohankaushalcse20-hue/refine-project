# @refinedev/nestjsx-crud

`@refinedev/nestjsx-crud` verbindt Refine met APIs die zijn gebouwd rond `@nestjsx/crud`.

## Wat biedt het?

- CRUD-methoden voor Nestjsx CRUD-endpoints
- Ondersteuning voor filtering, sorting en paginationpatronen
- Integratie met het Refine `dataProvider`-contract
- Een praktische brug tussen bestaande NestJS CRUD APIs en Refine-schermen

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je backend de Nestjsx CRUD-conventies volgt en je daar snel een Refine-adminlaag bovenop wilt bouwen.

Package name, import paths en API-namen blijven ongewijzigd.
