# Nestjsx CRUD Data Provider fuer refine

`@refinedev/nestjsx-crud` bindet Refine an Backends an, die mit `@nestjsx/crud` aufgebaut sind. So koennen Refine-Hooks die REST-Endpunkte fuer Listen, Details, Erstellen, Aktualisieren und Loeschen nutzen.

## Installation

```sh
npm install @refinedev/nestjsx-crud
```

## Verwendung

Das Paket passt zu bestehenden NestJS-CRUD-APIs und internen Tools, die diese Endpunkte verwalten. Endpunktpfade, Query-Parameter, Entity-Namen und Backend-Konventionen bleiben unveraendert.

Weitere Informationen findest du in der [Nestjsx-CRUD-Provider-Dokumentation](https://refine.dev/docs/data/packages/nestjsx-crud/).
