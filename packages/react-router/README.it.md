# @refinedev/react-router

`@refinedev/react-router` integra il routing di refine con [React Router](https://reactrouter.com/) per applicazioni React single-page.

## Installazione

```sh
npm install @refinedev/react-router react-router
```

## Uso di base

Importa il router provider e collegalo a `Refine` insieme alla configurazione delle routes dell'applicazione.

```tsx
import routerProvider from "@refinedev/react-router";
```

Il pacchetto permette agli hooks di navigazione di refine di usare la cronologia e le route definite con React Router.

## Documentazione

- Consulta la [documentazione del router provider](https://refine.dev/docs/routing/router-provider/).
- Per le route React, consulta la [documentazione React Router](https://reactrouter.com/).
