# React Router provider untuk Refine

Package `@refinedev/react-router` menghubungkan Refine dengan [React Router](https://reactrouter.com/). Package ini memungkinkan resources Refine terhubung ke routes, state tersinkronisasi dengan URL, dan navigasi tetap declarative.

## Tentang package

Refine tetap headless: router provider menangani navigasi, sedangkan data, authentication, authorization, dan notifications tetap berada di provider masing-masing.

Gunakan package ini saat aplikasi Refine berbasis React Router dan membutuhkan routes yang dapat diprediksi untuk list, create, edit, dan show.
