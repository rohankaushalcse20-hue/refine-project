# React Router provider for refine

`@refinedev/react-router` Refine applications को React Router के साथ जोड़ने के लिए router provider देता है। इससे resources, navigation, redirects और route-aware hooks React Router setup के साथ काम करते हैं।

## उपयोग

React Router based single-page applications में Refine का routing contract इस्तेमाल करना हो, तो इस package को configure करें। API names और route definitions project code में unchanged रहते हैं।

## Documentation

अधिक जानकारी और usage के लिए [Refine router provider documentation](https://refine.dev/docs/core/providers/router-provider/) देखें।
