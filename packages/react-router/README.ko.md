# React Router provider for refine

`@refinedev/react-router`는 Refine applications를 React Router와 연결하기 위한 router provider를 제공합니다. resources, navigation, redirects, route-aware hooks가 React Router setup과 함께 동작하도록 합니다.

## 사용

React Router 기반 single-page applications에서 Refine의 routing contract를 사용해야 할 때 이 package를 configure하세요. API names와 route definitions는 project code에서 그대로 유지됩니다.

## 문서

자세한 정보와 사용법은 [Refine router provider documentation](https://refine.dev/docs/core/providers/router-provider/)을 참고하세요.
