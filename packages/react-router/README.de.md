# React Router Provider fuer refine

`@refinedev/react-router` stellt die Routing-Integration fuer Refine-Anwendungen mit React Router bereit. Es verbindet Resources, Navigation und Router-Hooks mit den React-Router-Konventionen.

## Installation

```sh
npm install @refinedev/react-router
```

## Verwendung

Nutze dieses Paket fuer SPAs, interne Tools und Admin-Panels, die React Router als Routing-Schicht verwenden. Pfade, Route-Komponenten, Resource-Namen und Hook-Bezeichner bleiben technische Elemente.

Weitere Details findest du in der [Router-Provider-Dokumentation](https://refine.dev/docs/core/providers/router-provider/).
