# refine 的 React Router provider

`@refinedev/react-router` 将 refine 集成到 [React Router](https://reactrouter.com/)。它可以把 refine 资源映射到路由、与 URL 同步状态，并保持应用的声明式导航。

## 说明

refine 仍然保持 headless：router provider 负责导航，而数据、认证、授权和通知继续由各自的 providers 处理。

当 refine 应用基于 React Router，并且需要为列表、创建、编辑和详情保持可预测路由时，可以使用这个包。

## 文档

更多用法细节请查看 refine 的 [router provider 文档](https://refine.dev/docs/core/providers/router-provider/)。
