# Router provider React Router para Refine

`@refinedev/react-router` integra Refine con [React Router](https://reactrouter.com/). Permite mapear recursos de Refine a rutas, sincronizar estado con la URL y mantener una navegacion declarativa.

## Sobre el paquete

Refine sigue siendo headless: el router provider gestiona navegacion mientras datos, autenticacion, autorizacion y notificaciones permanecen en sus propios providers.

Usa este paquete cuando tu aplicacion Refine este basada en React Router y necesite rutas previsibles para listas, creacion, edicion y detalles.
