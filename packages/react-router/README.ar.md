# React Router provider لـ Refine

تدمج حزمة `@refinedev/react-router` بين Refine و[React Router](https://reactrouter.com/). تتيح ربط resources في Refine بالمسارات، ومزامنة الحالة مع URL، والحفاظ على تنقل declarative.

## حول الحزمة

يبقى Refine headless: يتولى router provider التنقل بينما تبقى البيانات وauthentication وauthorization وnotifications في providers الخاصة بها.

استخدم هذه الحزمة عندما يكون تطبيق Refine مبنياً على React Router ويحتاج إلى مسارات متوقعة للقوائم والإنشاء والتعديل والتفاصيل.

## التوثيق

لمزيد من التفاصيل، راجع [توثيق router provider في Refine](https://refine.dev/docs/core/providers/router-provider/).

ابدأ أيضاً من [دروس Refine](https://refine.dev/docs/tutorial/introduction/index/).
