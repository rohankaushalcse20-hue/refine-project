# Router provider React Router para refine

`@refinedev/react-router` integra o refine ao [React Router](https://reactrouter.com/). Ele permite mapear recursos refine para rotas, sincronizar estado com a URL e manter a navegacao declarativa da aplicacao.

## Sobre

O refine continua headless: o router provider cuida da navegacao enquanto dados, autenticacao, autorizacao e notificacoes permanecem em seus respectivos providers.

Use este pacote quando sua aplicacao refine for baseada em React Router e precisar de rotas previsiveis para listas, criacao, edicao e detalhes.

## Documentacao

Para mais detalhes de uso, consulte a [documentacao de router provider do refine](https://refine.dev/docs/core/providers/router-provider/).
