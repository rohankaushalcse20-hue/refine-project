# Refine için React Router provider

`@refinedev/react-router` package'ı, Refine'ı [React Router](https://reactrouter.com/) ile bağlar. Refine resources yapısının routes ile eşleşmesini, state'in URL ile senkron kalmasını ve navigasyonun declarative olmasını sağlar.

## Package hakkında

Refine headless kalır: router provider navigasyonu yönetirken data, authentication, authorization ve notifications kendi provider katmanlarında kalır.

Refine uygulamanız React Router tabanlıysa ve list, create, edit ile show sayfaları için öngörülebilir routes gerekiyorsa bu package'ı kullanın.

## Dokümantasyon

Ayrıntılar için [Refine router provider dokümantasyonunu](https://refine.dev/docs/core/providers/router-provider/) okuyun.

Ayrıca [Refine tutorial'ından](https://refine.dev/docs/tutorial/introduction/index/) başlayarak routing'i tam workflow içinde inceleyebilirsiniz.
