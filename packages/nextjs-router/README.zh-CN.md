# refine 的 Next.js router provider

`@refinedev/nextjs-router` 将 refine 的路由集成到 [Next.js](https://nextjs.org/) 项目中。它把资源、导航以及 URL 状态同步连接到 Next.js 的路由模型。

## 说明

refine 采用 headless 设计：你可以把 router provider 与任意视觉层组合使用，例如 Ant Design、Material UI、Mantine 或 Chakra UI。

当 refine 应用运行在 Next.js 中，并且需要保留该框架的导航约定时，可以使用这个包。

## 文档

更多用法细节请查看 refine 的 [router provider 文档](https://refine.dev/docs/core/providers/router-provider/)。

也建议跟随 [refine 教程](https://refine.dev/docs/tutorial/introduction/index/)，了解 routing 在完整流程中的应用方式。
