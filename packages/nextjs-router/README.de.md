# Next.js Router Provider fuer refine

`@refinedev/nextjs-router` integriert Refine-Routing in Next.js-Anwendungen. Das Paket verbindet Resource-Routen und Refine-Router-Hooks mit dem Navigationsmodell von Next.js.

## Installation

```sh
npm install @refinedev/nextjs-router
```

## Verwendung

Nutze dieses Paket, wenn du Admin-Panels, Dashboards oder B2B-Anwendungen mit Refine und Next.js baust. Route-Dateien, Commands, API-Bezeichner und Framework-Konventionen bleiben technische Namen und sollten unveraendert bleiben.

Weitere Details findest du in der [Router-Provider-Dokumentation](https://refine.dev/docs/core/providers/router-provider/).
