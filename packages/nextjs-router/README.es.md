# Router provider Next.js para Refine

`@refinedev/nextjs-router` integra el enrutamiento de Refine con proyectos [Next.js](https://nextjs.org/). Conecta recursos, navegacion y sincronizacion de estado con URL al modelo de rutas de Next.js.

## Sobre el paquete

Refine es headless por diseno: puedes combinar este router provider con cualquier capa visual, como Ant Design, Material UI, Mantine o Chakra UI.

Usa este paquete cuando tu aplicacion Refine se ejecute sobre Next.js y necesite mantener las convenciones de navegacion del framework.

## Documentacion

Para mas detalles, consulta la [documentacion del router provider de Refine](https://refine.dev/docs/core/providers/router-provider/).

Tambien puedes seguir los [tutoriales de Refine](https://refine.dev/docs/tutorial/introduction/index/) para ver routing aplicado en flujos completos.
