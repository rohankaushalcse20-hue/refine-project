# Next.js router provider لـ Refine

تدمج حزمة `@refinedev/nextjs-router` نظام routing في Refine مع مشاريع [Next.js](https://nextjs.org/). تربط resources والتنقل ومزامنة الحالة مع URL بنموذج routes في Next.js.

## حول الحزمة

يبقى Refine headless: يمكنك الجمع بين هذا router provider وأي طبقة عرض مثل Ant Design أو Material UI أو Mantine أو Chakra UI.

استخدم هذه الحزمة عندما يعمل تطبيق Refine فوق Next.js ويحتاج إلى الحفاظ على conventions التنقل في framework.

## التوثيق

لمزيد من التفاصيل، راجع [توثيق router provider في Refine](https://refine.dev/docs/core/providers/router-provider/).

يمكنك أيضاً اتباع [دروس Refine](https://refine.dev/docs/tutorial/introduction/index/) لرؤية routing داخل تدفقات كاملة.
