# Router provider Next.js para refine

`@refinedev/nextjs-router` integra o roteamento do refine a projetos [Next.js](https://nextjs.org/). Ele conecta recursos, navegacao e sincronizacao de estado com URL ao modelo de rotas do Next.js.

## Sobre

O refine e headless por design: voce pode combinar o provider de roteamento com qualquer camada visual, como Ant Design, Material UI, Mantine ou Chakra UI.

Use este pacote quando sua aplicacao refine rodar em Next.js e precisar manter as convencoes de navegacao do framework.

## Documentacao

Para mais detalhes de uso, consulte a [documentacao de router provider do refine](https://refine.dev/docs/core/providers/router-provider/).

Tambem vale seguir os [tutoriais do refine](https://refine.dev/docs/tutorial/introduction/index/) para ver routing aplicado em fluxos completos.
