# Next.js Router provider for refine

`@refinedev/nextjs-router` Next.js applications में Refine routing को integrate करने के लिए router provider देता है। यह Next.js navigation model के साथ resource routes और Refine router hooks को align करता है।

## उपयोग

Next.js पर admin panels, dashboards या B2B applications बनाते समय यह package Refine resources को framework routing से जोड़ता है। Commands, route files और API identifiers project conventions के अनुसार unchanged रहने चाहिए।

## Documentation

अधिक जानकारी और usage के लिए [Refine router provider documentation](https://refine.dev/docs/core/providers/router-provider/) देखें।
