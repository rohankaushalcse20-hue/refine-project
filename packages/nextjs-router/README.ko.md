# Next.js Router provider for refine

`@refinedev/nextjs-router`는 Next.js applications에서 Refine routing을 통합하기 위한 router provider를 제공합니다. Next.js navigation model에 맞춰 resource routes와 Refine router hooks를 연결합니다.

## 사용

Next.js로 admin panels, dashboards, B2B applications를 만들 때 이 package를 사용해 Refine resources를 framework routing과 연결하세요. commands, route files, API identifiers는 project conventions에 맞춰 그대로 유지해야 합니다.

## 문서

자세한 정보와 사용법은 [Refine router provider documentation](https://refine.dev/docs/core/providers/router-provider/)을 참고하세요.
