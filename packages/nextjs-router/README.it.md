# @refinedev/nextjs-router

`@refinedev/nextjs-router` integra il routing di refine con applicazioni [Next.js](https://nextjs.org/), mantenendo navigazione e resources sincronizzate.

## Installazione

```sh
npm install @refinedev/nextjs-router
```

## Uso di base

Importa il router provider del pacchetto e passalo al componente `Refine` nella configurazione dell'app Next.js.

```tsx
import routerProvider from "@refinedev/nextjs-router";
```

Il provider consente agli hooks di navigazione di refine di lavorare con URL, route e transizioni gestite da Next.js.

## Documentazione

- Consulta la [documentazione del router provider](https://refine.dev/docs/routing/router-provider/).
- Per il framework, consulta la [documentazione Next.js](https://nextjs.org/docs).
