# Next.js router provider untuk Refine

Package `@refinedev/nextjs-router` menghubungkan sistem routing Refine dengan project [Next.js](https://nextjs.org/). Package ini menyambungkan resources, navigasi, dan sinkronisasi state dengan URL ke model routes di Next.js.

## Tentang package

Refine tetap headless: Anda dapat menggabungkan router provider ini dengan lapisan UI seperti Ant Design, Material UI, Mantine, atau Chakra UI.

Gunakan package ini saat aplikasi Refine berjalan di atas Next.js dan perlu mempertahankan conventions navigasi framework tersebut.

## Dokumentasi

Untuk detail lebih lanjut, baca [dokumentasi router provider Refine](https://refine.dev/docs/core/providers/router-provider/).

Anda juga dapat mengikuti [tutorial Refine](https://refine.dev/docs/tutorial/introduction/index/) untuk melihat routing dalam workflow lengkap.
