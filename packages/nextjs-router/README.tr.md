# Refine icin Next.js router provider

`@refinedev/nextjs-router`, Refine routing davranisini [Next.js](https://nextjs.org/) projeleriyle entegre eder. Resource tabanli navigation, URL senkronizasyonu ve route yardimcilarini Next.js route modeliyle birlikte kullanmanizi saglar.

## Paket hakkinda

Refine tasarim olarak headless'tir; bu router provider'i Ant Design, Material UI, Mantine, Chakra UI veya kendi UI katmaninizla birlikte kullanabilirsiniz.

Refine uygulamaniz Next.js uzerinde calisiyorsa ve framework'ün navigation kurallarini korumak istiyorsaniz bu package'i tercih edin.

## Dokumantasyon

Daha fazla ayrinti icin [Refine Next.js routing dokumantasyonunu](https://refine.dev/docs/routing/integrations/next-js/) inceleyin.

Routing'in tam uygulama akislari icindeki yerini gormek icin [Refine tutorial'lerini](https://refine.dev/docs/tutorial/introduction/index/) takip edebilirsiniz.
