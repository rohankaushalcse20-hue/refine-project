# REST data provider для refine

`@refinedev/rest` предоставляет data provider для REST API. Пакет помогает подключить CRUD-хуки refine к backend endpoint без написания повторяющейся логики запросов.

## Установка

```sh
npm install @refinedev/rest
```

## Документация

- Начните с [документации data provider](https://refine.dev/docs/core/providers/data-provider).
- Дополнительные сведения доступны в [документации REST package](https://refine.dev/docs/packages/documentation/data-providers/rest/).
- Общие tutorials refine находятся в [разделе tutorial](https://refine.dev/docs/tutorial/introduction/index/).
