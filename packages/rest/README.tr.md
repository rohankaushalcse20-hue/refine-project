# Refine REST data provider

`@refinedev/rest`, Refine uygulamalarını REST backend'lere bağlamak için kullanılan data provider package'ıdır. CRUD kaynaklarını HTTP endpoint'leriyle eşleştirmeniz gereken projelerde esnek bir temel sağlar.

## Kurulum

```sh
npm install @refinedev/rest
```

## Ne zaman kullanılır?

Backend'iniz REST API sunuyorsa ve Refine'ın `dataProvider` sözleşmesine uygun şekilde list, create, update, delete ve show işlemlerini yönetmek istiyorsanız bu package'ı kullanın.

## Dokümantasyon

- [Refine data provider dokümantasyonunu](https://refine.dev/docs/core/providers/data-provider) okuyun.
- [`@refinedev/rest` dokümantasyonunu](https://refine.dev/docs/packages/documentation/data-providers/rest/) inceleyin.
