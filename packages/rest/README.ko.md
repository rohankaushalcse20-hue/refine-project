# Refine REST data provider

`@refinedev/rest`는 REST APIs를 위한 data provider package입니다. Refine resources를 HTTP endpoints에 연결하는 base integration을 제공해 CRUD operations를 Refine hooks와 components에서 실행할 수 있게 합니다.

## 설치

```sh
npm install @refinedev/rest
```

## 사용

backend가 REST endpoints를 expose하고 이를 Refine data provider contract와 연결해야 할 때 이 package를 선택하세요. API shape에 맞춘 request/response handling은 project 안에서 조정할 수 있습니다.

자세한 내용은 [data provider documentation](https://refine.dev/docs/core/providers/data-provider), [REST package docs](https://refine.dev/docs/packages/documentation/data-providers/rest/), [tutorials](https://refine.dev/docs/tutorial/introduction/index/)를 참고하세요.
