# REST Data Provider para refine

`@refinedev/rest` fornece um data provider para REST APIs. Ele permite conectar hooks do Refine a endpoints HTTP usados em fluxos comuns de CRUD.

## Instalacao

```sh
npm install @refinedev/rest
```

## Uso

Use este pacote em projetos com backends REST proprios ou camadas de API existentes. Paths de endpoint, metodos HTTP, headers, query parameters e nomes de resources continuam sendo contratos tecnicos e devem permanecer inalterados.
