# REST Data Provider fuer refine

`@refinedev/rest` stellt einen Data Provider fuer REST-APIs bereit. Damit koennen Refine-Hooks typische CRUD-Ablaeufe mit HTTP-Endpunkten verbinden.

## Installation

```sh
npm install @refinedev/rest
```

## Verwendung

Das Paket eignet sich fuer Projekte mit eigenen REST-Backends oder vorhandenen API-Schichten. Endpunktpfade, HTTP-Methoden, Header, Query-Parameter und Resource-Namen bleiben technische Vertraege und sollten unveraendert bleiben.

Weitere Details findest du in der [REST-Provider-Dokumentation](https://refine.dev/docs/data/packages/rest-data-provider/).
