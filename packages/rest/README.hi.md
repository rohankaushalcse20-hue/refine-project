# Refine REST data provider

`@refinedev/rest` REST APIs के लिए data provider package है। यह Refine resources को HTTP endpoints से जोड़ने के लिए base integration देता है, ताकि CRUD operations Refine hooks और components से चल सकें।

## Installation

```sh
npm install @refinedev/rest
```

## उपयोग

जब backend REST endpoints expose करता हो और आपको Refine के data provider contract के साथ उन्हें जोड़ना हो, तब इस package को चुनें। API shape के अनुसार request/response handling को project में adapt किया जा सकता है।

अधिक जानकारी के लिए [data provider documentation](https://refine.dev/docs/core/providers/data-provider), [REST package docs](https://refine.dev/docs/packages/documentation/data-providers/rest/) और [tutorials](https://refine.dev/docs/tutorial/introduction/index/) देखें।
