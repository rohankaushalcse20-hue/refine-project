# Supabase Data Provider fuer refine

`@refinedev/supabase` verbindet Refine-Anwendungen mit Supabase. Das Paket nutzt Supabase als Backend-as-a-Service fuer Datenzugriff und kann in Admin-Panels, Dashboards und internen Tools eingesetzt werden.

## Installation

```sh
npm install @refinedev/supabase
```

## Verwendung

Der Provider passt zu Projekten, die Supabase-Tabellen, Policies und Auth-Kontext in Refine-Oberflaechen nutzen. Tabellen, Spalten, Policies, Environment-Variablen und Client-Konfigurationen bleiben technische Bezeichner.

Weitere Informationen findest du in der [Supabase-Provider-Dokumentation](https://refine.dev/docs/data/packages/supabase/).
