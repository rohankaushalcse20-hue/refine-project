# Refine Live Previews

`@refinedev/live-previews` ist ein experimentelles Paket zum Rendern von Vorschauen fuer Refine-Anwendungen innerhalb der [Dokumentation](https://refine.dev/docs). Es ist fuer interaktive Beispiele und schnelle Validierungen waehrend der Dokumentationsentwicklung gedacht.

## Typische Nutzung

Das Paket gehoert zur Dokumentationsinfrastruktur von Refine. Wenn neue previews ergaenzt werden, sollten Beispielnamen, imports, URLs und technische Einstellungen aus dem Quellbeispiel unveraendert bleiben.
