# @refinedev/live-previews

`@refinedev/live-previews` bevat live preview-onderdelen die binnen de Refine-documentatie en voorbeelden worden gebruikt.

## Wat biedt het?

- Previewhulpen voor interactieve Refine-voorbeelden
- Ondersteuning voor het tonen van voorbeeldapps in documentatiecontexten
- Bouwstenen voor demonstraties die dicht bij echte code blijven

## Wanneer gebruik je dit?

Gebruik dit pakket vooral wanneer je aan Refine-documentatie, voorbeelden of preview-infrastructuur werkt.

Package name en interne API-namen blijven ongewijzigd.
