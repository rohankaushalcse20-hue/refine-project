# Refine Live Previews

`@refinedev/live-previews` は、[documentation](https://refine.dev/docs) 内で refine アプリケーションの preview を描画するための実験的なパッケージです。インタラクティブな例や、ドキュメント開発中の軽い検証で使われます。

## 想定される使い方

`@refinedev/live-previews` は refine のドキュメント基盤向けです。新しい preview を追加するときは、example 名、imports、URLs、技術的な設定を元ファイルと同じまま保ってください。
