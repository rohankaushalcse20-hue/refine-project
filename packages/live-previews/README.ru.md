# Refine Live Previews

`@refinedev/live-previews` — экспериментальный пакет для рендеринга интерактивных previews refine-приложений в [документации](https://refine.dev/docs).

Пакет предназначен для документационного окружения и помогает показывать живые примеры без дублирования логики приложения.
