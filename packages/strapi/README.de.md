# Strapi Data Provider fuer refine

`@refinedev/strapi` stellt eine Integration fuer Strapi-basierte Backends bereit. Damit kannst du Strapi-Inhalte ueber Refine-Listen, Detailseiten, Create- und Edit-Ansichten verwalten.

## Installation

```sh
npm install @refinedev/strapi
```

## Verwendung

Das Paket eignet sich fuer Projekte, die eine bestehende Strapi-API mit Refine-Oberflaechen ergaenzen. Collection-Namen, API-Pfade, Rollen, Permissions und Feldbezeichner bleiben technische Namen.

Weitere Details findest du in der [Strapi-Provider-Dokumentation](https://refine.dev/docs/data/packages/strapi/).
