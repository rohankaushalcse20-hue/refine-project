# Refine için Remix router provider

`@refinedev/remix-router` package'ı, Refine routing sözleşmesini Remix projeleriyle bağlar. Resources, navigation ve URL state yönetimini Remix route yapısıyla birlikte kullanmanıza yardımcı olur.

## Kurulum

```sh
npm install @refinedev/remix-router
```

## Package hakkında

Refine headless kalır: router provider navigasyonu çözerken data provider, authentication, authorization ve notifications bağımsız kalır.

Remix üzerinde admin panel, internal tool veya dashboard geliştirirken framework'ün routing modelini korumak istiyorsanız bu package uygundur.

## Dokümantasyon

Ayrıntılar için [Refine router provider dokümantasyonunu](https://refine.dev/docs/core/providers/router-provider/) okuyun.
