# Router provider Remix para refine

`@refinedev/remix-router` fornece integracao de roteamento entre o Refine e aplicacoes Remix. Ele permite que resources do Refine usem rotas, navegacao e redirecionamentos alinhados ao router da aplicacao.

## Instalacao

```sh
npm install @refinedev/remix-router
```

## Uso

Use este provider quando sua aplicacao Refine roda sobre Remix e precisa manter rotas de listagem, criacao, edicao e detalhes sincronizadas com os resources. Paths, parametros de rota e nomes de resources devem permanecer iguais ao codigo.

## Documentacao

Para mais detalhes de configuracao e uso, consulte a [documentacao de router provider do refine](https://refine.dev/docs/core/providers/router-provider/).
