# Remix Router Provider fuer refine

`@refinedev/remix-router` integriert Refine in Remix-Anwendungen. Das Paket ordnet Refine-Resources und Router-Hooks den Routing- und Datenlade-Konventionen von Remix zu.

## Installation

```sh
npm install @refinedev/remix-router
```

## Verwendung

Der Provider eignet sich fuer Refine-Anwendungen, die Remix fuer Routing, Loader und Actions einsetzen. Datei-Routen, Loader-Namen, Actions, Resource-Keys und API-Bezeichner bleiben Teil des Codes und werden nicht uebersetzt.

Weitere Informationen findest du in der [Router-Provider-Dokumentation](https://refine.dev/docs/core/providers/router-provider/).
