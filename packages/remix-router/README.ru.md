# Remix router provider для refine

`@refinedev/remix-router` предоставляет router provider для приложений refine на Remix. Он помогает связать routing, navigation и ресурсы refine с маршрутизацией Remix.

## Установка

```sh
npm install @refinedev/remix-router
```

## Документация

- Подробности смотрите в [документации router provider](https://refine.dev/docs/core/providers/router-provider/).
- Для Remix-примеров refine откройте [раздел examples](https://refine.dev/docs/examples/remix/mui/).
