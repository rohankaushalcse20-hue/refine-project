# Router provider Remix para Refine

`@refinedev/remix-router` integra Refine con aplicaciones basadas en [Remix](https://remix.run/). Permite mapear resources de Refine a rutas, mantener navegacion declarativa y conectar las acciones de CRUD con el router de la aplicacion.

## Sobre el paquete

Refine sigue siendo headless: el router provider gestiona la navegacion mientras datos, autenticacion, autorizacion, notificaciones e i18n permanecen en sus propios providers. Usa este paquete cuando tu aplicacion Refine se ejecute sobre Remix y necesite rutas previsibles para listas, creacion, edicion y vistas de detalle.

## Instalacion

```sh
npm install @refinedev/remix-router
```

## Documentacion

Para mas detalles y uso, consulta la [documentacion del router provider de Refine](https://refine.dev/docs/core/providers/router-provider/).
