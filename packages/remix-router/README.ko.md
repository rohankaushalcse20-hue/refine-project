# Remix Router provider for refine

`@refinedev/remix-router`는 Remix applications에 Refine routing support를 추가합니다. Refine resources와 navigation helpers가 Remix route structure와 함께 동작하도록 연결합니다.

## 설치

```sh
npm install @refinedev/remix-router
```

## 사용

Remix-based Refine apps에서 list, create, edit, show routes를 framework routing에 연결하려면 이 provider를 사용하세요. existing route module names와 API identifiers는 code에서 그대로 유지합니다.

## 문서

자세한 정보와 사용법은 [Refine router provider documentation](https://refine.dev/docs/core/providers/router-provider/)을 참고하세요.
