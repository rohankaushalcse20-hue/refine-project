# Remix Router provider for refine

`@refinedev/remix-router` Remix applications में Refine routing support जोड़ता है। यह Refine resources और navigation helpers को Remix route structure के साथ काम करने देता है।

## Installation

```sh
npm install @refinedev/remix-router
```

## उपयोग

Remix-based Refine apps में list, create, edit और show routes को framework routing से जोड़ने के लिए यह provider इस्तेमाल करें। Existing route module names और API identifiers को code में unchanged रखें।

## Documentation

अधिक जानकारी और usage के लिए [Refine router provider documentation](https://refine.dev/docs/core/providers/router-provider/) देखें।
