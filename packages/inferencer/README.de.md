# Inferencer fuer refine

`@refinedev/inferencer` hilft beim schnellen Erzeugen von Refine-Ansichten auf Basis vorhandener Ressourcen und Datenstrukturen. Es kann Vorschlaege fuer Listen-, Anzeigen-, Erstellen- und Bearbeiten-Seiten ableiten.

## Installation

```sh
npm install @refinedev/inferencer
```

## Verwendung

Der Inferencer ist besonders nuetzlich beim Prototyping und beim Erkunden neuer Datenmodelle. Der erzeugte Code sollte anschliessend geprueft, angepasst und in die Projektkonventionen ueberfuehrt werden.

Weitere Details findest du in der [Inferencer-Dokumentation](https://refine.dev/docs/packages/documentation/inferencer/).
