# Refine Inferencer

`@refinedev/inferencer`, resource verilerinden hareketle Refine icin listeleme, gosterme, olusturma ve duzenleme ekranlari taslaklari uretir. Prototip cikarmak veya yeni bir resource icin baslangic kodu almak istediginizde hiz kazandirir.

## Kurulum

```sh
npm install @refinedev/inferencer
```

## Ne saglar?

- API cevaplarini okuyarak alanlari ve component secimlerini onerebilir.
- Ant Design, Material UI, Mantine ve Chakra UI entegrasyonlariyla kullanilabilir.
- Uretilen kodu uygulamaniza tasiyip ihtiyaciniza gore duzenleyebilirsiniz.

## Ne zaman kullanilmali?

Yeni bir data modelini hizli gormek, CRUD ekranlarini taslak olarak olusturmak veya ekip icinde UI kararlarini netlestirmek istediginizde kullanislidir.

## Dokumantasyon

Ornek kullanim icin ilgili UI entegrasyonundaki Inferencer dokumantasyonunu inceleyin.
