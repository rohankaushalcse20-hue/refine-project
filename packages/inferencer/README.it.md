# Inferencer per refine

`@refinedev/inferencer` genera viste iniziali per resources refine analizzando la struttura dei dati restituiti dall'API.

## Installazione

```sh
npm install @refinedev/inferencer
```

## Uso di base

Usa i componenti Inferencer per creare rapidamente pagine list, show, create o edit e poi personalizza il codice generato.

```tsx
import { AntdInferencer } from "@refinedev/inferencer/antd";
```

Inferencer riduce il tempo necessario per prototipare schermate CRUD, mantenendo modificabile il risultato finale.
