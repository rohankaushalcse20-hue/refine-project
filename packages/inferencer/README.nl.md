# @refinedev/inferencer

`@refinedev/inferencer` kan UI-code voorstellen op basis van resource-data en metadata uit je Refine-app.

## Wat biedt het?

- Inferencer-componenten voor snelle CRUD-prototypes
- Codevoorbeelden die je kunt kopieren naar eigen pagina's
- Ondersteuning voor verschillende UI-integraties
- Een manier om datavormen snel zichtbaar te maken tijdens ontwikkeling

## Wanneer gebruik je dit?

Gebruik dit pakket om sneller eerste list-, show-, create- en edit-schermen op te zetten. Behandel de gegenereerde code als startpunt en pas die daarna aan je productervaring aan.

Package name, componentnamen en API-namen blijven ongewijzigd.
