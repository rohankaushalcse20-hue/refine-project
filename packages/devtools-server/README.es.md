# Servidor de Refine Devtools

`@refinedev/devtools-server` contiene la capa de servidor que usa Refine Devtools durante el desarrollo. Permite comunicar la aplicacion Refine con la interfaz de Devtools sin exponer una API de produccion.

## Sobre el paquete

Refine Devtools sirve para revisar recursos, providers, consultas, mutaciones y estado de ejecucion mientras desarrollas. Este paquete forma parte de `@refinedev/devtools` y normalmente se ejecuta a traves de la CLI de Refine o de la integracion de Devtools.

## Instalacion

En la mayoria de proyectos basta con instalar el paquete publico de Devtools:

```sh
npm install @refinedev/devtools
```

## Documentacion

Para mas detalles de configuracion y uso, consulta la [documentacion de Refine Devtools](https://refine.dev/docs/packages/devtools).
