## About

[refine](https://refine.dev/) **headless by design** है और unlimited styling तथा customization options देता है। Convenience के लिए refine [Ant Design](https://ant.design/), [Material UI](https://mui.com/material-ui/getting-started/overview/), [Mantine](https://mantine.dev/), और [Chakra UI](https://chakra-ui.com/) के ready-made integrations के साथ आता है।

refine में REST API, [GraphQL](https://graphql.org/), और [Airtable](https://www.airtable.com/), [Strapi](https://strapi.io/), [Supabase](https://supabase.com/), [Firebase](https://firebase.google.com/), तथा [Directus](https://directus.io/) जैसी popular services सहित 15+ backend services के connectors हैं।

[refine tutorials शुरू करें &#8594](https://refine.dev/docs/tutorial/introduction/index/)
