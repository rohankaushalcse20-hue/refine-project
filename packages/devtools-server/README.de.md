# Refine Devtools Server

`@refinedev/devtools-server` enthaelt die Server-Schicht, die Refine Devtools waehrend der Entwicklung verwendet. Sie verbindet die Refine-Anwendung mit der Devtools-Oberflaeche, ohne eine Produktions-API freizulegen.

## Ueber das Paket

Refine Devtools macht resources, providers, queries, mutations und Laufzeitstatus leichter sichtbar. Dieses Paket ist Teil von `@refinedev/devtools` und wird normalerweise ueber die Refine CLI oder die Devtools-Integration gestartet.

## Installation

In den meisten Projekten reicht die Installation des oeffentlichen Devtools-Pakets:

```sh
npm install @refinedev/devtools
```

Weitere Details zur Konfiguration und Nutzung findest du in der [Refine Devtools-Dokumentation](https://refine.dev/docs/packages/devtools).
