# Servidor do Refine Devtools

`@refinedev/devtools-server` contem a camada de servidor usada pelo Refine Devtools durante o desenvolvimento. Ela conecta a aplicacao Refine com a interface do Devtools sem expor uma API de producao.

## Sobre o pacote

O Refine Devtools serve para revisar resources, providers, queries, mutations e estado de execucao enquanto voce desenvolve. Este pacote faz parte de `@refinedev/devtools` e normalmente e executado pela CLI do Refine ou pela integracao do Devtools.

## Instalacao

Na maioria dos projetos, basta instalar o pacote publico do Devtools:

```sh
npm install @refinedev/devtools
```

## Documentacao

Para mais detalhes de configuracao e uso, consulte a [documentacao do Refine Devtools](https://refine.dev/docs/packages/devtools).
