# Refine Devtools server

`@refinedev/devtools-server`, `@refinedev/devtools` package'ının internal server bileşenlerini içerir. Development sırasında Devtools ile uygulama arasında çalışan servis tarafı parçaları destekler.

## Kurulum

Uygulama içinde Devtools kullanmak için public package'ı kurun:

```sh
npm install @refinedev/devtools
```

## Ne zaman kullanılır?

Bu package doğrudan uygulama kodu için tasarlanmamıştır. Refine Devtools'un development workflow'unda resource, provider ve query davranışlarını incelemek için gereken internal altyapının parçasıdır.

## Dokümantasyon

Setup ve kullanım ayrıntıları için [Refine Devtools dokümantasyonunu](https://refine.dev/docs/packages/devtools) okuyun.
