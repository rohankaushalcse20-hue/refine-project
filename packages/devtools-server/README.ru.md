# Сервер Refine Devtools

`@refinedev/devtools-server` является внутренней серверной частью `@refinedev/devtools`. Он используется devtools-пакетом refine для обслуживания локальных возможностей разработки и не требует отдельной настройки в большинстве приложений.

## Установка

Для пользовательских проектов устанавливайте основной пакет:

```sh
npm install @refinedev/devtools
```

## Документация

- Смотрите [документацию refine devtools](https://refine.dev/docs/packages/devtools).
- Для общего знакомства с refine используйте [документацию](https://refine.dev/docs/).
