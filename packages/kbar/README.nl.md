# @refinedev/kbar

`@refinedev/kbar` integreert een command palette in Refine-apps met behulp van kbar.

## Wat biedt het?

- Command palette-acties op basis van Refine resources
- Navigatie naar list-, create-, edit- en show-routes
- Integratie met bestaande router- en resourceconfiguratie
- Een snelle bediening voor gebruikers die liever zoeken of toetsenbordnavigatie gebruiken

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je een productieve command palette-ervaring wilt toevoegen aan een admin panel, dashboard of interne tool.

Package name, import paths en kbar-termen blijven ongewijzigd.
