# Refine command palette

`@refinedev/kbar`, Refine uygulamalarina `cmd+k` veya `ctrl+k` ile acilan command palette deneyimi eklemek icin kullanilir. Navigation, resource aksiyonlari ve uygulama komutlarini klavye odakli hale getirir.

## Kurulum

```sh
npm install @refinedev/kbar
```

## Temel fikir

Command palette, Refine resource'larindan ve navigation yapisindan komutlar uretebilir. Boylece kullanicilar liste, create, edit veya custom aksiyonlara menuler arasinda dolasmadan ulasabilir.

## Ne zaman kullanilmali?

Operasyon ekiplerinin sik kullandigi ekranlara hizli gecis yapmasi gereken dashboard ve internal tool projelerinde kullanislidir.

## Dokumantasyon

Kurulum ve provider yapisi icin [Refine command palette dokumantasyonunu](https://refine.dev/docs/packages/command-palette/) inceleyin.
