# kbar-Integration fuer refine

`@refinedev/kbar` integriert eine Command-Palette in Refine-Anwendungen. Damit koennen Nutzer per `cmd+k` oder `ctrl+k` schneller navigieren und haeufige Aktionen ausfuehren.

## Installation

```sh
npm install @refinedev/kbar
```

## Verwendung

Das Paket passt zu Admin-Panels und internen Tools mit vielen Ressourcen, Routen oder Aktionen. Tastenkombinationen, Resource-Namen und technische Handler bleiben in der Anwendung definiert und sollten nicht uebersetzt werden.

Mehr Informationen findest du in der [kbar-Dokumentation](https://refine.dev/docs/packages/documentation/routers/kbar/).
