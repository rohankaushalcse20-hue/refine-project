# @refinedev/codemod

`@refinedev/codemod` è lo strumento di migrazione per progetti refine. Aiuta ad applicare trasformazioni automatiche quando cambiano API o pattern tra versioni principali.

## Installazione

```sh
npm install @refinedev/codemod
```

## Uso di base

Esegui il comando sul progetto da aggiornare e controlla il diff generato prima di completare la migrazione.

```sh
npx @refinedev/codemod
```

Lo strumento analizza il codice, applica trasformazioni mirate e riduce il lavoro manuale necessario per seguire breaking changes documentati.

## Documentazione

- Consulta la [documentazione dei pacchetti refine](https://refine.dev/docs/packages/list-of-packages/).
- Verifica sempre le note di rilascio del progetto prima di applicare migrazioni automatiche.
