# Codemod для refine

`@refinedev/codemod` помогает автоматизировать миграции кода между версиями refine с breaking changes. Инструмент анализирует исходный код проекта и применяет преобразования, которые иначе пришлось бы выполнять вручную.

## Установка и справка

Посмотреть доступные сценарии можно через `--help`.

```sh
npx @refinedev/codemod --help
```

## Базовое использование

Запускайте codemod из корня проекта, чтобы преобразования могли найти исходные файлы и настройки пакетов.

```sh
npx @refinedev/codemod
```

Перед запуском рекомендуется зафиксировать рабочее дерево в git, чтобы легко просмотреть изменения и откатить неподходящие правки.
