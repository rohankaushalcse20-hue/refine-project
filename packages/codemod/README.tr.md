# Refine codemod araclari

`@refinedev/codemod`, Refine projelerini surumler arasinda tasirken tekrar eden API degisikliklerini otomatiklestiren donusumler icerir. Import yollarini, package adlarini veya yaygin kaliplari toplu olarak guncellerken manuel isi azaltir.

## Kurulum ve kullanim

Codemod'u proje kokunden calistirin ve olusan diff'i commit etmeden once mutlaka inceleyin:

```sh
npx @refinedev/codemod
```

## Ne zaman kullanilmali?

Buyuk migration calismalarinda veya bir Refine surumu cok sayida dosyada mekanik degisiklik gerektirdiginde kullanislidir.

## Dokumantasyon

Paylasimli bir branch uzerinde donusum calistirmadan once [Refine dokumantasyonunu](https://refine.dev/docs/) ve ilgili migration notlarini kontrol edin.
