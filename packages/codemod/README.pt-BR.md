# Codemod do refine

`@refinedev/codemod` e uma ferramenta de migracao de codigo para projetos refine. Ela ajuda a aplicar transformacoes automaticas quando ha breaking changes entre versoes principais.

## Ver opcoes disponiveis

```sh
npx @refinedev/codemod --help
```

## Uso geral

No terminal, entre na raiz do projeto com `cd` e inicialize o `refine-codemod`:

```sh
npx @refinedev/codemod
```

Use esta ferramenta para reduzir o trabalho manual de upgrades, mantendo a revisao humana sobre as alteracoes geradas.
