# refine Codemod

`@refinedev/codemod` は refine プロジェクト向けのコード移行ツールです。主要バージョン間の breaking changes に合わせて、自動変換を適用する作業を補助します。

## 利用できるオプションを確認する

```sh
npx @refinedev/codemod --help
```

## 基本的な使い方

ターミナルでプロジェクトのルートへ移動し、`refine-codemod` を起動します。

```sh
npx @refinedev/codemod
```

アップグレード時の手作業を減らしつつ、生成された差分は必ず人がレビューする前提で使ってください。
