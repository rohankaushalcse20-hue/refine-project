# Refine codemod

`@refinedev/codemod` stellt Migrationsskripte fuer Refine-Projekte bereit. Es hilft beim Aktualisieren von Code, wenn zwischen groesseren Refine-Versionen breaking changes auftreten.

## Optionen anzeigen

```sh
npx @refinedev/codemod --help
```

## Allgemeine Verwendung

Wechsle im Terminal in das Root-Verzeichnis deines Projekts und starte den Codemod:

```sh
npx @refinedev/codemod
```

Das Tool analysiert Projektdateien und fuehrt passende Code-Transformationen aus, damit Upgrades weniger manuelle Anpassungen erfordern.

Weitere Details findest du in der [Refine documentation](https://refine.dev/docs/).
