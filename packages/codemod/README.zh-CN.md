# refine Codemod

`@refinedev/codemod` 是面向 refine 项目的代码迁移工具。当主要版本之间出现 breaking changes 时，它可以帮助自动应用代码转换。

## 查看可用选项

```sh
npx @refinedev/codemod --help
```

## 常规用法

在终端中使用 `cd` 进入项目根目录，然后启动 `refine-codemod`：

```sh
npx @refinedev/codemod
```

使用这个工具可以减少升级时的手动修改量，同时仍然保留对生成变更的人为审查。
