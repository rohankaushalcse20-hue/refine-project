# @refinedev/codemod

`@refinedev/codemod` bevat migratiehulpen die Refine-projecten kunnen aanpassen wanneer APIs of imports veranderen.

## Wat biedt het?

- Codemods voor ondersteunde Refine-upgrades
- Automatische wijzigingen voor bekende import- en API-patronen
- Een basis om migraties consistenter en minder handmatig te maken

## Wanneer gebruik je dit?

Gebruik dit pakket bij versie-upgrades waarbij de release notes een codemod aanbevelen. Controleer de diff daarna altijd handmatig, vooral rond aangepaste projectcode.

Package name, codemodnamen en commandos blijven ongewijzigd.
