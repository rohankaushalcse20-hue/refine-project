# create-refine-app

`create-refine-app` は、新しい Refine アプリケーションを対話的に作成するためのスターターです。ルーティング、UI フレームワーク、data provider などを選びながら、すぐに開発を始められるプロジェクトを生成できます。

## 実行

```sh
npm create refine-app@latest my-app
```

## できること

- Refine の推奨構成をもつ新規アプリケーションを作成する。
- React Router、Next.js、Remix などのルーティング構成を選ぶ。
- Ant Design、Material UI、Mantine、Chakra UI などの UI 統合を選ぶ。
- 認証、data provider、サンプル resource を含む初期構成を素早く用意する。

## 使いどころ

Refine を初めて導入する場合や、検証用の管理画面、ダッシュボード、内部ツールを短時間で立ち上げたい場合に適しています。

## 詳細

Refine の概要、チュートリアル、利用できるテンプレートは公式ドキュメントを参照してください。
