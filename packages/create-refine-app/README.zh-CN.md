# create-refine-app

`create-refine-app` 用于从终端创建新的 refine 项目。它是启动应用的推荐方式，可以根据你的场景选择合适的路由、UI 和 data provider。

## 创建项目

```sh
npm create refine-app@latest my-app
```

创建完成后，按照向导提示进入项目目录、安装依赖并启动开发环境。

## 为什么使用

- 从与 refine 生态兼容的项目结构开始。
- 避免手动配置核心包。
- 便于快速尝试 UI、后端和路由组合。
