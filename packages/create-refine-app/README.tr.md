# Create Refine App

`create-refine-app`, yeni Refine projelerini baslatmak icin resmi scaffolding aracidir. UI entegrasyonu, routing, data provider ve authentication seceneklerini ayni akista belirleyerek hizli bir baslangic saglar.

## Proje olusturma

```sh
npm create refine-app@latest my-app
```

Komut satiri sihirbazi framework, UI library, backend ve proje yapisi secimlerinde size rehberlik eder.

## Ne zaman kullanilmali?

Yeni admin panelleri, B2B uygulamalari, prototipler veya Refine'in guncel proje sablonlariyla baslamak istediginiz internal tools icin uygundur.

## Dokumantasyon

Uygulamayi olusturduktan sonraki adimlar icin [Refine getting started dokumantasyonunu](https://refine.dev/docs/getting-started/overview/) inceleyin.
