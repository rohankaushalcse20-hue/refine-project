# create refine app

`create-refine-app` नया Refine project शुरू करने का recommended starter command देता है। यह enterprise web applications, admin panels और dashboards के लिए शुरुआती structure तैयार करने में मदद करता है।

## Installation

```sh
npm create refine-app@latest my-app
```

## उपयोग

इस package का उपयोग तब करें जब आपको Refine project को जल्दी bootstrap करना हो और UI framework, data provider या routing setup जैसे शुरुआती choices command flow के जरिए configure करने हों।

Guides और next steps के लिए [Refine documentation](https://refine.dev/docs/) और [tutorials](https://refine.dev/docs/tutorial/introduction/index/) देखें।
