# create-refine-app

`create-refine-app` is de projectgenerator waarmee je snel een nieuwe Refine-app kunt starten.

## Wat biedt het?

- Interactieve keuzes voor framework, router, UI-integratie en data provider
- Een kant-en-klare projectstructuur
- Startconfiguratie voor lokale ontwikkeling
- Een snelle route van idee naar werkende Refine-app

## Wanneer gebruik je dit?

Gebruik dit pakket wanneer je een nieuw project begint en direct een Refine-opzet wilt die past bij je gekozen stack.

Package name, commandos en template-namen blijven ongewijzigd.
