# create-refine-app

`create-refine-app` crea nuovi progetti refine da riga di comando con template e configurazioni iniziali pronte per lo sviluppo.

## Installazione

```sh
npm create refine-app@latest
```

## Uso di base

Avvia il generatore, scegli router, framework UI, data provider e opzioni di esempio, quindi apri il progetto generato.

```sh
npm create refine-app@latest my-refine-app
```

Il pacchetto mantiene invariati package name, import path e comandi npm, ma guida la configurazione iniziale con domande interattive.
