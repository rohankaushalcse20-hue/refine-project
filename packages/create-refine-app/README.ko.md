# create refine app

`create-refine-app`은 새 Refine project를 시작하기 위한 recommended starter command를 제공합니다. enterprise web applications, admin panels, dashboards의 초기 structure를 빠르게 준비할 수 있습니다.

## 설치

```sh
npm create refine-app@latest my-app
```

## 사용

Refine project를 bootstrap하면서 UI framework, data provider, routing setup 같은 초기 choices를 command flow에서 고르고 싶을 때 사용하세요.

다음 단계는 [Refine documentation](https://refine.dev/docs/)과 [tutorials](https://refine.dev/docs/tutorial/introduction/index/)를 참고하세요.
