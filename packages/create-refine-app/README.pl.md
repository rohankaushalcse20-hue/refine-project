# create refine app

`create-refine-app` tworzy nowy projekt Refine z wybranym routerem, data providerem, UI framework i dodatkowymi ustawieniami. To najszybsza ścieżka do rozpoczęcia panelu administracyjnego, dashboardu albo narzędzia wewnętrznego na Refine.

## Użycie

```sh
npm create refine-app@latest my-app
```

Komenda przeprowadzi przez interaktywne pytania i przygotuje projekt z potrzebnymi zależnościami. Po utworzeniu przejdź do katalogu aplikacji i uruchom dev server zgodnie z podpowiedziami CLI.

## Co można skonfigurować

- UI framework: Ant Design, Material UI, Mantine, Chakra UI albo podejście headless.
- Router provider dla React Router, Next.js albo Remix.
- Data provider i dodatkowe integracje, jeśli zostaną wybrane w kreatorze.
