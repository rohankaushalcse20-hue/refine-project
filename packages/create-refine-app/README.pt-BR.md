# create-refine-app

`create-refine-app` cria novos projetos refine a partir do terminal. Ele e o caminho recomendado para iniciar uma aplicacao com as escolhas de roteamento, UI e data provider mais adequadas ao seu caso.

## Criar um projeto

```sh
npm create refine-app@latest my-app
```

Depois da criacao, siga as instrucoes do assistente para entrar na pasta do projeto, instalar dependencias e iniciar o ambiente de desenvolvimento.

## Por que usar

- Comeca com uma estrutura de projeto compativel com o ecossistema refine.
- Evita configurar manualmente os pacotes essenciais.
- Facilita testar combinacoes de UI, backend e roteamento.
