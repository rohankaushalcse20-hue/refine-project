# Create Refine App

`create-refine-app` adalah generator resmi untuk memulai project Refine. Generator ini membantu membuat aplikasi dengan cepat bersama integrasi UI, routing, dan data provider yang dibutuhkan.

## Membuat project

```sh
npm create refine-app@latest my-app
```

Assistant akan memandu Anda memilih framework, library UI, backend, dan opsi authentication agar project siap dikembangkan.

## Kapan digunakan?

Gunakan package ini untuk prototipe, admin panel baru, atau aplikasi B2B yang perlu dimulai dari struktur Refine yang dipelihara project.

## Dokumentasi

Baca [dokumentasi getting started Refine](https://refine.dev/docs/getting-started/overview/) untuk langkah berikutnya setelah aplikasi dibuat.
