# Create Refine App

`create-refine-app` ist das Scaffolding-Werkzeug fuer neue Refine-Anwendungen. Es hilft dir, ein Projekt mit passenden Framework-, Router-, UI- und Data-Provider-Optionen schnell zu erstellen.

## Projekt starten

```sh
npm create refine-app@latest my-refine-app
```

## Verwendung

Das Paket eignet sich fuer neue Admin-Panels, Dashboards und interne Tools. Die generierten Befehle, Package-Namen und Konfigurationsdateien bleiben technisch und sollten in Projektdokumentation unveraendert verwendet werden.

Mehr Informationen findest du in der [Getting-Started-Dokumentation](https://refine.dev/docs/getting-started/quickstart/).
