# Create Refine App

`create-refine-app` es el generador oficial para iniciar proyectos Refine. Permite crear rapidamente una aplicacion con las integraciones de UI, routing y data provider que necesites.

## Crear un proyecto

```sh
npm create refine-app@latest my-app
```

El asistente guia la seleccion de framework, libreria de UI, backend y opciones de autenticacion para dejar una base lista para desarrollar.

## Cuándo usarlo

Usa este paquete para prototipos, paneles administrativos nuevos o aplicaciones B2B que necesitan arrancar con una estructura Refine mantenida por el proyecto.

## Documentacion

Consulta la [documentacion de inicio de Refine](https://refine.dev/docs/getting-started/overview/) para conocer los siguientes pasos despues de crear la aplicacion.
