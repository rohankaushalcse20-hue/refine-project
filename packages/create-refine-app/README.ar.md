# Create Refine App

`create-refine-app` هو المولد الرسمي لبدء مشاريع Refine. يتيح إنشاء تطبيق بسرعة مع تكاملات UI وrouting وdata provider التي تحتاجها.

## إنشاء مشروع

```sh
npm create refine-app@latest my-app
```

يرشدك المساعد لاختيار framework ومكتبة UI وbackend وخيارات authentication حتى تحصل على قاعدة جاهزة للتطوير.

## متى تستخدمه؟

استخدم هذه الحزمة للنماذج الأولية أو لوحات الإدارة الجديدة أو تطبيقات B2B التي تحتاج إلى البدء ببنية Refine يحافظ عليها المشروع.

## التوثيق

راجع [توثيق البداية في Refine](https://refine.dev/docs/getting-started/overview/) لمعرفة الخطوات التالية بعد إنشاء التطبيق.
