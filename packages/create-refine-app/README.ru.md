# create refine app

`create-refine-app` создает новый проект refine с выбранным router, data provider, UI framework и дополнительными настройками. Это самый быстрый путь начать админ-панель, dashboard или внутренний инструмент на refine.

## Использование

```sh
npm create refine-app@latest my-app
```

Команда проведет через интерактивные вопросы и подготовит проект с нужными зависимостями. После создания перейдите в каталог приложения и запустите dev-сервер согласно подсказкам CLI.

## Что настраивается

- UI framework: Ant Design, Material UI, Mantine, Chakra UI или headless-подход.
- Router provider для React Router, Next.js или Remix.
- Data provider и дополнительные интеграции, если они выбраны в мастере.
