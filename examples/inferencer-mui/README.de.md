## MUI Inferencer-Beispiel

Dieses Beispiel zeigt, wie **Refine Inferencer** MUI-basierte CRUD-Seiten aus einer Resource ableitet. Es hilft beim schnellen Prototyping, bevor Seiten manuell verfeinert werden.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example inferencer-mui
```

## Wichtige Punkte

- Inferencer fuer MUI-Seiten ausprobieren
- Generierte Listen-, Show-, Create- und Edit-Ansichten pruefen
- Abgeleiteten Code als Ausgangspunkt fuer eigene Seiten nutzen
- Befehle, URLs und API-Namen unveraendert lassen
