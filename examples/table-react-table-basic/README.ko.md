## TanStack Table 기본 예제

이 예제는 **Refine**을 TanStack Table과 함께 사용해 headless table 흐름을 구성하는 방법을 보여줍니다. UI를 직접 제어하면서 Refine의 resource 데이터 흐름을 활용합니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example table-react-table-basic
```

## 핵심 포인트

- TanStack Table과 Refine data 흐름 연결
- headless table 구조로 UI 제어
- resource 목록, pagination, sorting 처리
- 원본 명령어, URL, API 이름 유지
