## React Table 基础表格示例

这个示例展示如何把 **Refine** 的数据层与 React Table 组合使用。Refine 提供资源查询和变更能力，React Table 负责表格结构和交互状态。

## 本地运行

```bash
npm create refine-app@latest -- --example table-react-table-basic
```

## 建议关注

- 查询结果如何传给 React Table
- 表格列定义与资源字段的对应关系
- 基础列表页面的数据加载和刷新流程
- 原始命令、URL 和 API 名称保持不变
