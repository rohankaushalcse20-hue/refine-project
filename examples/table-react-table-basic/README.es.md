## Ejemplo básico con TanStack Table

Este ejemplo muestra cómo usar **Refine** con TanStack Table para construir una tabla headless. Refine aporta el flujo de datos y TanStack Table permite controlar la representación.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example table-react-table-basic
```

## Puntos clave

- Integración de TanStack Table con resources de Refine
- Control headless de columnas y filas
- Datos obtenidos desde el data provider
- Comandos, URLs y nombres de API sin traducir
