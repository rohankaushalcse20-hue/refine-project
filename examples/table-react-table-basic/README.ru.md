## Базовый пример таблицы React Table

Этот пример показывает интеграцию **TanStack Table** с **Refine**. Refine получает данные и управляет ресурсами, а таблица отвечает за отображение строк и колонок.

## Запуск локально

```bash
npm create refine-app@latest -- --example table-react-table-basic
```

## Что проверить

- Конфигурацию columns и row model.
- Получение данных через `dataProvider`.
- Поведение sorting, pagination и loading state.
- Сохранение имен hooks, accessors и commands без локализации.
