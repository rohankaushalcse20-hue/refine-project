## React Table basic example

यह example दिखाता है कि **Refine** के data flow को React Table based list UI से कैसे जोड़ा जाता है। Table rendering React Table संभालता है, और Refine resource, pagination तथा CRUD state को coordinate करता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example table-react-table-basic
```

## मुख्य बिंदु

- React Table के साथ list screen बनाना
- data provider से जुड़े CRUD resources
- pagination और table state को Refine flow से जोड़ना
- commands और URLs को reproducible रखना
