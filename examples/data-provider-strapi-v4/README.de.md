## Data-provider-Beispiel mit Strapi v4

Dieses Beispiel zeigt, wie **Refine** Strapi v4 als Backend verwendet. Der data provider verbindet Refine-Resources mit Strapi-Endpunkten und laesst die Seitenlogik frameworknah bleiben.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example data-provider-strapi-v4
```

## Wichtige Punkte

- Strapi v4 als data provider konfigurieren
- CRUD-Aktionen ueber Refine-Resources ausfuehren
- Backend-Zugriff von UI-Komponenten trennen
- Commands, URLs und API-Namen unveraendert verwenden
