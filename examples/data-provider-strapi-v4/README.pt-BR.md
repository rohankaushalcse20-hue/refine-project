## Exemplo de data provider Strapi v4

Este exemplo mostra como conectar **refine** ao Strapi v4. Ele demonstra como usar o data provider especifico para adaptar resources do refine ao formato de API do Strapi v4.

## Testar localmente

```bash
npm create refine-app@latest -- --example data-provider-strapi-v4
```

## Pontos principais

- Configuracao do provider `@refinedev/strapi-v4`.
- Resources CRUD ligados ao backend Strapi v4.
- Mutacoes e listas seguindo o fluxo do refine.
- Comandos e URLs preservados para reproducao.
