## Exemplo de autenticacao com Material UI

Este exemplo mostra como usar **refine** com um fluxo de autenticacao em uma aplicacao React baseada em Material UI. A estrutura de CRUD continua controlada pelo refine, enquanto as telas e componentes visuais usam a integracao Material UI.

## Testar localmente

```bash
npm create refine-app@latest -- --example auth-material-ui
```

## Pontos principais

- Configuracao de `authProvider`.
- Rotas protegidas para recursos autenticados.
- Layout e formularios com Material UI.
- Resources, comandos e APIs preservados no codigo.

[Abrir o exemplo auth-material-ui no CodeSandbox](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/auth-material-ui?view=preview&theme=dark&codemirror=1)
