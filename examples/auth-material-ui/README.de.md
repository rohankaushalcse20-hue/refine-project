## Authentifizierungsbeispiel mit Material UI

Dieses Beispiel zeigt, wie **Refine** eine authentifizierte Anwendung mit Material UI aufbaut. Refine steuert auth flow, resources und routing, waehrend Material UI die Oberflaeche bereitstellt.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example auth-material-ui
```

## Wichtige Punkte

- Authentifizierte Refine-Anwendung mit Material UI
- Geschuetzte routes, login und logout
- UI-Komponenten getrennt von `authProvider` und resources
- Befehle, URLs und API-Namen bleiben unveraendert

[Beispiel auth-material-ui in CodeSandbox oeffnen](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/auth-material-ui?view=preview&theme=dark&codemirror=1)
