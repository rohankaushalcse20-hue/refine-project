## Material UI ile kimlik doğrulama örneği

Bu örnek, Material UI arayüzü kullanan bir Refine uygulamasında kimlik doğrulama akışını gösterir. Bileşen ve paket adları İngilizce teknik adlarıyla korunur.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example auth-material-ui
```

## Dikkat edilecek noktalar

- Material UI tabanlı giriş ekranı
- `authProvider` ile oturum kontrolü
- Giriş ve çıkış durumlarının arayüze yansıtılması

[auth-material-ui örneğini CodeSandbox'da aç](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/auth-material-ui?view=preview&theme=dark&codemirror=1)
