## Material UI authentication example

यह example दिखाता है कि Material UI आधारित React application में **Refine** authentication flow कैसे बनाया जाता है। CRUD structure Refine संभालता है, और screens तथा visual components Material UI integration से आते हैं।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example auth-material-ui
```

## मुख्य बिंदु

- `authProvider` की configuration
- authenticated resources के लिए protected routes
- Material UI के साथ layout और forms
- resources, commands और APIs को code में unchanged रखना
