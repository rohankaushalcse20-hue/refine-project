## Ejemplo de autenticación con Material UI

Este ejemplo muestra cómo construir una experiencia de autenticación en **Refine** con componentes de Material UI. Refine gestiona el contrato de autenticación y Material UI aporta la interfaz visual.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example auth-material-ui
```

## Puntos clave

- Pantallas de autenticación usando Material UI
- Uso de `authProvider` para login, logout e identidad
- Integración con rutas protegidas de Refine
- Preservación de comandos, URLs y nombres de APIs
