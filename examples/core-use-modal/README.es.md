## Ejemplo de `useModal`

Este ejemplo muestra cómo usar `useModal` en **Refine** para controlar la apertura, cierre y estado de modales. El hook permite mantener la lógica del modal fuera de los componentes visuales.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example core-use-modal
```

## Puntos clave

- Estado de modal gestionado con `useModal`
- Apertura y cierre controlados desde acciones de UI
- Separación entre lógica de estado y presentación
- Comandos, URLs y nombres técnicos conservados sin traducir
