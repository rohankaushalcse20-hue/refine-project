## Exemplo de `useModal`

Este exemplo mostra como o **Refine** usa `useModal` para controlar o estado de diálogos. O hook encapsula abertura, fechamento e visibilidade para componentes de modal personalizados.

## Executar localmente

```bash
npm create refine-app@latest -- --example core-use-modal
```

## Pontos principais

- Controle de estado modal com `useModal`
- Reutilização da lógica de abertura e fechamento
- Integração com formulários ou actions de resources
- Comandos, URLs e nomes de API preservados como no exemplo original
