## Headless-Basisbeispiel

Dieses Beispiel zeigt eine **Refine**-Anwendung ohne festes UI-Framework. Refine liefert Daten-, Routing- und Resource-Logik, waehrend die Oberflaeche komplett mit eigenen Komponenten gebaut wird.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example base-headless
```

## Wichtige Punkte

- Headless-Refine-Provider konfigurieren
- Eigene Listen-, Erstellen- und Bearbeiten-Seiten aufbauen
- Hooks fuer CRUD-Datenzugriff direkt nutzen
- Commands, Hooks und Resource-Namen unveraendert verwenden
