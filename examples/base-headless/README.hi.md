## Headless base example

यह example **Refine** के headless workflow का basic setup दिखाता है। इसमें framework-specific UI package के बिना resources, data hooks और routing का उपयोग करके custom interface बनाया जाता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example base-headless
```

## मुख्य बिंदु

- custom UI के लिए headless Refine architecture
- resources और data hooks के साथ CRUD behavior
- routing और state को UI framework से अलग रखना
- commands, URLs और hook names को original example जैसा रखना
