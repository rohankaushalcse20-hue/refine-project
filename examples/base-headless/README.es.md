## Ejemplo base headless

Este ejemplo muestra cómo usar **Refine** sin depender de una librería de UI específica. La aplicación se centra en los providers, resources y hooks principales para que puedas conectar tu propia capa visual.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example base-headless
```

## Puntos clave

- Configuración headless de Refine
- Resources y rutas listos para personalizar
- Libertad para usar cualquier sistema de diseño
- Comandos, URLs y nombres técnicos conservados sin traducir
