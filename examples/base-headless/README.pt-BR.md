## Exemplo base headless

Este exemplo mostra uma aplicacao **refine** sem uma biblioteca de UI opinativa. Ele destaca como usar os providers, hooks e resources do refine mantendo total liberdade para criar a interface.

## Testar localmente

```bash
npm create refine-app@latest -- --example base-headless
```

## Pontos principais

- Configuracao essencial de uma aplicacao refine.
- Uso headless dos hooks e providers.
- UI desacoplada da logica CRUD.
- Comandos, URLs e APIs preservados no codigo.
