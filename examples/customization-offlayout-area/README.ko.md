## Off Layout Area 예제

이 예제는 **Refine** layout 바깥에 추가 UI 영역을 배치하는 패턴을 보여줍니다. 전역 알림, floating action, 보조 navigation처럼 resource 화면과 독립적인 요소를 연결할 때 참고할 수 있습니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example customization-offlayout-area
```

## 확인할 점

- layout 외부 영역에 custom component를 렌더링하는 방법
- resource routes와 독립적인 UI 배치
- provider와 navigation 구조 보존
- 원본 명령어, URL, API 이름 유지
