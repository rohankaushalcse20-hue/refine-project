## Ejemplo de offLayoutArea personalizado

Este ejemplo muestra cómo renderizar contenido global fuera del layout principal usando `offLayoutArea` en una aplicación Refine.

## Probar localmente

```bash
npm create refine-app@latest -- --example customization-offlayout-area
```

## Qué revisar

- Uso de `offLayoutArea` para componentes globales.
- Renderizado independiente de páginas y resources.
- Casos como banners, accesos rápidos o elementos flotantes.
- Evitar acoplar contenido global a una pantalla concreta.
