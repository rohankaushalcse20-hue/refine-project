## Heroicons blog example

यह example दिखाता है कि Refine UI में Heroicons को project की screens और actions के साथ कैसे इस्तेमाल किया जा सकता है। API names, package names और icon imports source example जैसे ही रखें।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example blog-heroicons-example
```
