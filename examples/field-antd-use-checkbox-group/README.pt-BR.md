## Exemplo de `useCheckboxGroup` com Ant Design

Este exemplo mostra como usar **Refine** e Ant Design para renderizar grupos de checkbox em formulários. O hook prepara opções e valores para campos relacionados a resources.

## Executar localmente

```bash
npm create refine-app@latest -- --example field-antd-use-checkbox-group
```

## Pontos principais

- Uso de `useCheckboxGroup` com componentes do Ant Design
- Carregamento de opções a partir do `dataProvider`
- Integração com formulários de criação e edição
- Comandos, URLs e nomes de API preservados como no exemplo original
