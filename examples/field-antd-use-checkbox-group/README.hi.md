## Ant Design useCheckboxGroup example

यह example **Refine** और Ant Design में `useCheckboxGroup` hook से multi-select checkbox fields बनाना दिखाता है। Related records को checkbox options के रूप में form में इस्तेमाल किया जाता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example field-antd-use-checkbox-group
```

## मुख्य बिंदु

- Ant Design `Checkbox.Group` के साथ `useCheckboxGroup`
- related resource options को checkbox list में दिखाना
- multiple values को form submission में भेजना
- commands, URLs और hook names को original example जैसा रखना
