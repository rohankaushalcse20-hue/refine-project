## Ant Design useCheckboxGroup 예제

이 예제는 **Refine**에서 Ant Design checkbox group을 `useCheckboxGroup` hook과 함께 사용하는 방법을 보여줍니다. 관련 resource 데이터를 선택지로 불러와 form 안에서 여러 값을 선택할 수 있습니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example field-antd-use-checkbox-group
```

## 확인할 점

- `useCheckboxGroup`으로 checkbox options를 준비하는 흐름
- Ant Design form field와 Refine hook 연결
- resource 데이터 기반 다중 선택 UI
- 명령어, URL, API 이름은 원본 그대로 유지
