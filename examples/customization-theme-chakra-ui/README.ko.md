## Chakra UI Theme 커스터마이징 예제

이 예제는 **Refine** 애플리케이션에서 Chakra UI theme를 확장하고 적용하는 흐름을 보여줍니다. resource와 provider 구성은 그대로 두고 디자인 token과 컴포넌트 스타일을 조정합니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example customization-theme-chakra-ui
```

## 확인할 점

- Chakra UI theme 확장 위치
- Refine layout과 resource 화면에 theme를 적용하는 방식
- 공통 색상, typography, component 기본값 관리
- 원본 명령어, URL, API 이름 유지
