## Exemplo de `useDrawerForm` com Material UI

Este exemplo mostra como usar **Refine** e Material UI para editar registros dentro de um drawer. O hook `useDrawerForm` coordena estado do drawer, formulário e mutation.

## Executar localmente

```bash
npm create refine-app@latest -- --example form-material-ui-use-drawer-form
```

## Pontos principais

- Formulários em drawer com `useDrawerForm`
- Integração com componentes do Material UI
- Fluxos de criação e edição sem sair da página de lista
- Comandos, URLs e nomes de API preservados como no exemplo original
