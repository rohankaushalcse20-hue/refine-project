## Material UI `useDrawerForm` örneği

Bu örnek, Material UI arayüzünde çekmece içinde çalışan formlar için Refine `useDrawerForm` hook'unu gösterir. Kullanıcı, sayfadan ayrılmadan kayıt oluşturabilir veya düzenleyebilir.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example form-material-ui-use-drawer-form
```

## Dikkat edilecek noktalar

- Drawer içinde form açma ve kapatma akışı
- Refine form durumu ile Material UI bileşenlerinin birlikte kullanımı
- `useDrawerForm` ve ilgili prop adları orijinal kalır
