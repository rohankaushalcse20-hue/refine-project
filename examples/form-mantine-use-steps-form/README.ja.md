## Mantine のステップフォーム

この例では、**refine** と Mantine で複数ステップのフォームを作る方法を示します。長い入力フローを小さな手順に分けながら、resource と provider の連携を保てます。

## ローカルで試す

```bash
npm create refine-app@latest -- --example form-mantine-use-steps-form
```

## 主なポイント

- Mantine の UI で multi-step フォームを構成します。
- 各ステップの状態を refine のフォームフローに接続します。
- 入力項目が多い登録画面の出発点になります。
- CodeSandbox のリンクは元の例を保持しています。
