## Material UI Data Grid table example

यह example दिखाता है कि list screen बनाने के लिए **Refine** को Material UI Data Grid के साथ कैसे इस्तेमाल किया जाता है। Refine data, pagination, filters और mutations संभालता है, जबकि Data Grid table experience render करता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example table-material-ui-use-data-grid
```

## मुख्य बिंदु

- Refine table hooks का उपयोग
- Material UI Data Grid integration
- pagination, filters और list state को resource से जोड़ना
- example name और commands को unchanged रखना
