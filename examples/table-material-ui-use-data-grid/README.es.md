## Ejemplo de tabla con Material UI Data Grid

Este ejemplo muestra cómo usar **Refine** con Material UI Data Grid para crear listados administrables. Refine conecta el grid con el data provider y mantiene los patrones de resource.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example table-material-ui-use-data-grid
```

## Puntos clave

- Integración de Material UI Data Grid con Refine
- Manejo de datos desde resources y data provider
- Paginación, sorting y filtros en una tabla administrable
- Comandos, URLs y APIs conservados como en el original
