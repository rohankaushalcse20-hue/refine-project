## Material UI Data Grid useDataGrid örneği

Bu örnek, Material UI Data Grid ile Refine `useDataGrid` kullanımını gösterir. Bileşen, hook ve paket adları teknik adlarıyla korunur.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example table-material-ui-use-data-grid
```

## Dikkat edilecek noktalar

- `useDataGrid` ile tablo verisi ve sayfalama yönetimi
- Material UI Data Grid kolonlarının Refine verisiyle beslenmesi
- Filtreleme, sıralama ve liste yenileme davranışları

[table-material-ui-use-data-grid örneğini CodeSandbox'da aç](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/table-material-ui-use-data-grid?view=preview&theme=dark&codemirror=1)
