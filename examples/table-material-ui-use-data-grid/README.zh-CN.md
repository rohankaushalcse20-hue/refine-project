## Material UI Data Grid 表格示例

这个示例展示如何把 **Refine** 的表格状态接入 Material UI Data Grid。数据查询、分页和资源操作由 Refine 管理，Data Grid 提供丰富的表格交互。

## 本地运行

```bash
npm create refine-app@latest -- --example table-material-ui-use-data-grid
```

## 建议关注

- Refine 表格 hooks 与 Data Grid props 的映射
- 分页、排序和加载状态的同步方式
- 行操作如何连接到资源详情或编辑页面
- 原始命令、URL 和 API 名称保持不变
