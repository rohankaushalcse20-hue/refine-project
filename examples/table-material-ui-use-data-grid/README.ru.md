## Пример Material UI Data Grid

Этот пример показывает, как использовать **Material UI Data Grid** вместе с **Refine**. Данные приходят из `dataProvider`, а Data Grid отображает строки, колонки и действия.

## Запуск локально

```bash
npm create refine-app@latest -- --example table-material-ui-use-data-grid
```

## Что проверить

- Настройки columns и row identifiers.
- Пагинацию, сортировку и loading state.
- Интеграцию row actions с edit и show pages.
- Сохранение Data Grid props, hook names и command syntax без перевода.
