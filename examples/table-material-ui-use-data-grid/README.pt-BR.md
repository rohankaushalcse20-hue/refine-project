## Exemplo de tabela com Material UI Data Grid

Este exemplo mostra como usar **refine** com Material UI Data Grid para construir uma tela de lista. O refine controla dados, paginacao, filtros e mutacoes, enquanto o Data Grid fica responsavel pela experiencia visual da tabela.

## Testar localmente

```bash
npm create refine-app@latest -- --example table-material-ui-use-data-grid
```

## Pontos principais

- Uso de hooks de tabela do refine.
- Integracao com Material UI Data Grid.
- Paginacao, filtros e estado de lista conectados ao resource.
- Nome do exemplo e comandos preservados para reproducao.
