## Material UI Data Grid 테이블 예제

이 예제는 **Refine**과 Material UI Data Grid로 관리 가능한 목록 화면을 만드는 방법을 보여줍니다. Refine이 grid를 data provider와 연결하고 resource 패턴을 유지합니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example table-material-ui-use-data-grid
```

## 핵심 포인트

- Material UI Data Grid와 Refine 통합
- resources와 data provider에서 데이터 관리
- pagination, sorting, filters가 포함된 테이블 구성
- 원본 명령어, URL, API 이름 유지
