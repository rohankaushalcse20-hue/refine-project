## Mantine useModalForm example

यह example दिखाता है कि **Refine** और Mantine के साथ modal based forms कैसे बनाए जाते हैं। इसमें `useModalForm` hook modal state और form submit flow को resource mutation से जोड़ता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example form-mantine-use-modal-form
```

## मुख्य बिंदु

- Mantine modal में create और edit forms चलाना
- `useModalForm` से open, close और submit state संभालना
- list page से modal form workflow शुरू करना
- command, hook names और CodeSandbox URL को original example जैसा रखना
