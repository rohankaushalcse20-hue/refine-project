## Chakra UI advanced table example

यह example दिखाता है कि **Refine** और Chakra UI के साथ advanced table behavior कैसे बनाया जाता है। इसमें list data को बेहतर तरीके से browse करने के लिए sorting, filtering और pagination जैसे table features शामिल हैं।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example table-chakra-ui-advanced
```

## मुख्य बिंदु

- Chakra UI table layout में advanced list controls
- sorting, filtering और pagination को Refine data flow से जोड़ना
- records पर row level actions दिखाना
- command, hook names और CodeSandbox URL को original example जैसा रखना
