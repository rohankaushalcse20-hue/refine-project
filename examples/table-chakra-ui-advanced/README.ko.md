## Chakra UI 고급 테이블 예제

이 예제는 **Refine**과 Chakra UI로 더 복잡한 테이블 화면을 구성하는 방법을 보여줍니다. sorting, filtering, pagination을 포함한 목록 경험을 Refine resource 상태와 연결합니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example table-chakra-ui-advanced
```

## 핵심 포인트

- Chakra UI 기반 고급 테이블 UI
- Refine table state와 data provider 연결
- filters, sorting, pagination 흐름 확인
- 원본 명령어, URL, API 이름 유지
