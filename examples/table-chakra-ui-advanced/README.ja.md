## Chakra UI の高度なテーブル

この例では、Chakra UI を使った **refine** のより実践的な一覧画面を示します。管理画面で必要になる行アクション、状態表示、一覧操作を組み合わせる際の参考になります。

## ローカルで試す

```bash
npm create refine-app@latest -- --example table-chakra-ui-advanced
```

## 主なポイント

- Chakra UI で高度な一覧体験を構成します。
- refine の hooks と resource をテーブルに接続します。
- フィルター、ページング、行単位の操作を拡張しやすい形です。
- CodeSandbox の URL は変更していません。

[CodeSandbox で table-chakra-ui-advanced の例を開く](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/table-chakra-ui-advanced?view=preview&theme=dark&codemirror=1)
