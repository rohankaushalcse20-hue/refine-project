## Material UI table filter example

यह example दिखाता है कि **Refine** और Material UI table में filters कैसे लगाए जाते हैं। इसमें list records को user input के आधार पर narrow करने और filter state को data queries से जोड़ने का तरीका शामिल है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example table-material-ui-table-filter
```

## मुख्य बिंदु

- Material UI table columns के साथ filter controls
- filter values को Refine list query में भेजना
- filtered records को table में तुरंत दिखाना
- command, hook names और URLs को original example जैसा रखना
