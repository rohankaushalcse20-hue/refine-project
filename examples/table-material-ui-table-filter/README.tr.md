## Material UI tablo filtresi örneği

Bu örnek, Material UI tablolarında filtreleme arayüzünün Refine veri sorgularına nasıl bağlandığını gösterir. Kullanıcı seçimi tablo sonucunu ve sorgu parametrelerini günceller.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example table-material-ui-table-filter
```

## Dikkat edilecek noktalar

- Material UI tablo filtre bileşenleri
- Refine filtre durumunun veri sağlayıcıya aktarılması
- Filtre alanı ve hook adları özgün biçimde korunur
