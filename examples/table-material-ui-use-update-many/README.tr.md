## Material UI `useUpdateMany` tablo örneği

Bu örnek, Material UI tablosunda birden fazla kaydı aynı anda güncellemek için Refine `useUpdateMany` hook'unu gösterir. Seçili kayıtlar toplu mutasyon akışıyla işlenir.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example table-material-ui-use-update-many
```

## Dikkat edilecek noktalar

- Tablo seçiminden toplu güncelleme başlatma
- `useUpdateMany` ile mutasyon durumu ve sonuçları
- Teknik hook ve parametre adları değiştirilmez
