## Ejemplo de guardar y continuar

Este ejemplo muestra cómo mantener al usuario dentro del formulario después de guardar, util para flujos de edición repetida o captura progresiva.

## Probar localmente

```bash
npm create refine-app@latest -- --example form-save-and-continue
```

## Qué revisar

- Configuración del comportamiento posterior al guardado.
- Uso del formulario sin cambiar rutas manualmente.
- Feedback visual después de una mutacion exitosa.
- Conservación de acciones y nombres de recursos de Refine.
