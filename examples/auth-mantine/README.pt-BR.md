## Exemplo de autenticacao com Mantine

Este exemplo mostra como usar **refine** com Mantine para montar paginas de autenticacao em uma aplicacao CRUD. O refine controla o ciclo de autenticacao, enquanto Mantine cuida dos componentes de formulario e layout.

## Testar localmente

```bash
npm create refine-app@latest -- --example auth-mantine
```

## Pontos principais

- Integracao de `authProvider` com telas Mantine.
- Login, logout e protecao de rotas.
- Componentes de UI mantidos separados da logica de autenticacao.
- Comandos, URLs e APIs preservados no codigo.
