## MUI Data Grid Pro-Beispiel

Dieses Beispiel zeigt, wie **Refine** mit MUI X Data Grid Pro fuer anspruchsvollere Tabellen arbeitet. Refine steuert die Datenlogik, waehrend Data Grid Pro erweiterte Tabellenfunktionen darstellt.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example table-mui-data-grid-pro
```

## Wichtige Punkte

- Data Grid Pro in eine Refine resource einbinden
- Tabellenstatus ueber Refine-Hooks synchronisieren
- Erweiterte Grid-Funktionen ohne Aenderung der Datenlogik nutzen
- Befehle, URLs und API-Namen unveraendert lassen
