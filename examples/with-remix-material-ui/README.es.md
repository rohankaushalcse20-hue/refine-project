## Ejemplo con Remix y Material UI

Este ejemplo muestra cómo usar **Refine** en una aplicación Remix con Material UI. La estructura combina routing de Remix, resources de Refine y componentes visuales de Material UI.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example with-remix-material-ui
```

## Puntos clave

- Integración de Refine dentro de una app Remix
- Componentes y layout con Material UI
- Resources conectados a rutas y data provider
- Comandos, URLs y nombres de API preservados
