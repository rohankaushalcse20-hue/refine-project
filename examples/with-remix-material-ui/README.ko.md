## Remix와 Material UI 예제

이 예제는 Remix 애플리케이션에서 **Refine**을 Material UI와 함께 사용하는 방법을 보여줍니다. Remix routing, Refine resources, Material UI 컴포넌트를 하나의 앱 구조로 결합합니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example with-remix-material-ui
```

## 핵심 포인트

- Remix 앱 안에서 Refine 통합
- Material UI 기반 layout과 컴포넌트 사용
- routes와 data provider에 연결된 resources
- 원본 명령어, URL, API 이름 유지
