## Exemplo Remix com Material UI

Este exemplo mostra como executar **refine** em uma aplicacao Remix usando Material UI. Ele combina o roteamento do Remix com resources, providers e componentes visuais do ecossistema Material UI.

## Testar localmente

```bash
npm create refine-app@latest -- --example with-remix-material-ui
```

## Pontos principais

- Integracao entre Remix e refine.
- Layout e componentes com Material UI.
- Resources e rotas preservados no fluxo do framework.
- Comandos e links mantidos para reproducao local.
