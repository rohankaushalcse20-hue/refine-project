## Пример Refine с Remix и Material UI

Этот пример показывает приложение **Refine** на **Remix** с интерфейсом **Material UI**. Remix управляет routing и runtime, а Refine предоставляет CRUD-логику и resource model.

## Запуск локально

```bash
npm create refine-app@latest -- --example with-remix-material-ui
```

## Что проверить

- Интеграцию Remix routes с ресурсами Refine.
- Настройки Material UI theme и layout.
- Загрузку данных и обработку form actions.
- Сохранение route modules, file names и CLI command без перевода.
