# ตัวอย่าง Refine กับ Remix และ Material UI

ตัวอย่างนี้แสดงการใช้ Refine ในแอป Remix ที่ใช้ Material UI โดยเน้นการจัด routing, resource page และ UI integration ให้ทำงานร่วมกับโครงสร้างของ Remix

## จุดสำคัญ

- ใช้ Refine กับ Remix routing
- เชื่อม Material UI เข้ากับ layout และหน้าจอ CRUD
- คงชื่อ route, component, command และ package ตามต้นฉบับ
- เหมาะสำหรับทีมที่ต้องการใช้ Remix เป็น application framework หลัก

## รันตัวอย่าง

```bash
npm create refine-app@latest -- --example with-remix-material-ui
```
