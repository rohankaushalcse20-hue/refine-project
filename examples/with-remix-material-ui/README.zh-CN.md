## Remix 与 Material UI 示例

这个示例展示如何在 Remix 项目中使用 **Refine** 和 Material UI。Remix 负责路由和渲染基础，Refine 提供资源管理，Material UI 提供组件层。

## 本地运行

```bash
npm create refine-app@latest -- --example with-remix-material-ui
```

## 建议关注

- Remix routes 如何承载 Refine 页面
- Material UI provider 与 Refine 应用根节点的组合
- 数据请求和资源导航在 Remix 环境中的表现
- 原始命令、URL 和 API 名称保持不变
