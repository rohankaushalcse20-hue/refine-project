## Remix ve Material UI örneği

Bu örnek, Remix tabanlı bir uygulamada Refine ve Material UI kullanımını gösterir. Rotalama, veri yükleme ve arayüz bileşenleri Remix yapısı içinde birlikte çalışır.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example with-remix-material-ui
```

## Dikkat edilecek noktalar

- Remix projesinde Refine kurulumu
- Material UI bileşenleriyle uygulama ekranları
- Framework, paket ve komut adları çevrilmeden korunur
