## Date picker input 예제

이 예제는 **Refine** 폼에서 date picker 입력을 사용하는 방법을 보여줍니다. 날짜 값을 form state와 연결하고 저장 흐름에서 data provider로 전달하는 패턴을 확인할 수 있습니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example input-date-picker
```

## 핵심 포인트

- Date picker 입력을 Refine form state와 연결
- 날짜 필드를 create/edit 화면에서 처리
- UI 컴포넌트와 data provider 사이의 값 전달 확인
- 원본 명령어, URL, API 이름 유지
