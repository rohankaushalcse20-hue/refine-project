## Chakra UI useForm example

यह example दिखाता है कि **Refine** और Chakra UI के साथ create/edit forms कैसे बनाए जाते हैं। इसमें `useForm` hook form fields, validation और submit handling को Refine resource mutations से जोड़ता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example form-chakra-ui-use-form
```

## मुख्य बिंदु

- Chakra UI form controls के साथ `useForm` integration
- create और edit pages के लिए reusable form structure
- submit state और mutation lifecycle को साथ रखना
- command, hook names और URLs को original example जैसा रखना
