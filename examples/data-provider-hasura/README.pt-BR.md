## Exemplo de data provider Hasura

Este exemplo mostra como usar **refine** com Hasura. Ele conecta resources do refine a uma API GraphQL gerenciada pelo Hasura, mantendo consultas e mutacoes dentro do fluxo padrao do core.

## Testar localmente

```bash
npm create refine-app@latest -- --example data-provider-hasura
```

## Pontos principais

- Integracao com Hasura e GraphQL.
- Resources CRUD conectados ao data provider.
- Fluxo de listas, filtros e mutacoes pelo refine.
- Comandos e URLs preservados do exemplo original.
