## Ejemplo de data provider con Hasura

Este ejemplo muestra cómo usar **Refine** con Hasura para trabajar con un backend GraphQL. El data provider traduce las operaciones de resources a consultas y mutaciones compatibles.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example data-provider-hasura
```

## Puntos clave

- Integración de Hasura como data provider GraphQL
- Uso de resources de Refine sobre entidades del backend
- Operaciones CRUD mediante queries y mutations
- Comandos, URLs y nombres de API sin cambios
