## Mantine basic table example

यह example दिखाता है कि **Refine** और Mantine के साथ simple list table कैसे बनाई जाती है। यह resource records को table में दिखाने और basic CRUD actions तक पहुंच देने का छोटा pattern है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example table-mantine-basic
```

## मुख्य बिंदु

- Mantine table components के साथ Refine list page
- fetched records को readable rows में दिखाना
- create, edit और show जैसे actions के लिए UI entry points
- command, component names और URLs को original example जैसा रखना
