## Exemplo basico de tabela com Mantine

Este exemplo mostra como usar **refine** com Mantine para criar uma tabela CRUD simples. O refine fornece os dados, paginacao e acoes, enquanto Mantine cuida da estrutura visual da listagem.

## Testar localmente

```bash
npm create refine-app@latest -- --example table-mantine-basic
```

## Pontos principais

- Tabela Mantine conectada aos hooks do refine.
- Listagem de resources com paginacao.
- Acoes CRUD preservadas no fluxo da aplicacao.
- Comandos, URLs e APIs preservados no codigo.
