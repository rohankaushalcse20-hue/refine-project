## Ejemplo de data provider con Strapi

Este ejemplo muestra cómo conectar **Refine** con Strapi para construir una interfaz CRUD sobre contenido administrado en Strapi. Refine mantiene el flujo de resources y Strapi expone la API backend.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example data-provider-strapi
```

## Puntos clave

- Configuración de Strapi como data provider
- Consumo de contenido de Strapi desde resources de Refine
- Manejo de listados, creación y edición
- Endpoints, comandos y nombres de API conservados en inglés técnico
