## Data provider-Beispiel mit Strapi

Dieses Beispiel zeigt, wie **Refine** Strapi als Backend fuer CRUD-Anwendungen nutzt. Der data provider verbindet Refine resources mit Strapi-Endpunkten und haelt API-Zugriff und UI getrennt.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example data-provider-strapi
```

## Wichtige Punkte

- Strapi als data provider fuer Refine
- CRUD-Ablaufe ueber resources und provider
- Klare Trennung zwischen Backend, resources und UI
- Befehle, URLs und API-Namen bleiben unveraendert
