## Strapi data provider example

यह example दिखाता है कि **Refine** को Strapi से कैसे connect किया जाता है। Data provider Refine के CRUD resources को Strapi managed content API से map करता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example data-provider-strapi
```

## मुख्य बिंदु

- Strapi data provider की configuration
- headless CMS से जुड़े resources
- Refine के standard contract में CRUD operations
- commands, URLs और example names को unchanged रखना
