## Exemplo de data provider Strapi

Este exemplo mostra como conectar **refine** ao Strapi. Ele usa o data provider para mapear recursos CRUD do refine para uma API de conteudo gerenciada pelo Strapi.

## Testar localmente

```bash
npm create refine-app@latest -- --example data-provider-strapi
```

## Pontos principais

- Configuracao do data provider Strapi.
- Resources conectados a um CMS headless.
- Operacoes CRUD no contrato padrao do refine.
- Comandos, URLs e nomes de exemplo preservados.
