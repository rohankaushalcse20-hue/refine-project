## Birden fazla data provider örneği

Bu örnek, tek Refine uygulamasında birden fazla `dataProvider` kullanımını gösterir. Sağlayıcı adları, kaynak adları ve örnek komutu teknik doğruluk için korunur.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example data-provider-multiple
```

## Dikkat edilecek noktalar

- Farklı kaynakların farklı veri sağlayıcılarına bağlanması
- Varsayılan ve adlandırılmış `dataProvider` yapılandırmaları
- Kaynak tanımlarında sağlayıcı seçimi
