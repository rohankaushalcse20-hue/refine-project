## Ant Design simple list 예제

이 예제는 **Refine**과 Ant Design으로 간단한 목록 화면을 만드는 방법을 보여줍니다. `useSimpleList`를 사용해 resource 데이터를 가져오고 Ant Design 컴포넌트로 표시합니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example use-simple-list-antd
```

## 핵심 포인트

- `useSimpleList`로 목록 데이터 관리
- Ant Design UI 컴포넌트와 Refine resources 연결
- 간단한 리스트 화면에서 pagination 흐름 확인
- 원본 명령어, URL, API 이름 유지
