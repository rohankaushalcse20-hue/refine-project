## Template Ant Design

Este exemplo mostra um template **refine** com Ant Design. Ele serve como base para iniciar dashboards, admin panels e ferramentas internas com componentes prontos e resources conectados ao core.

## Testar localmente

```bash
npm create refine-app@latest -- --example template-antd
```

## Pontos principais

- Template inicial usando Ant Design.
- Layout e componentes prontos para CRUD.
- Providers e resources alinhados ao refine.
- Comando original preservado para criar o exemplo.
