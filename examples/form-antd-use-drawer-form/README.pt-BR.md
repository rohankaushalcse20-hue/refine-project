## Exemplo de formulario em drawer com Ant Design

Este exemplo mostra como usar **refine** e Ant Design para abrir formularios CRUD dentro de um drawer. O refine controla o estado da mutacao e da navegacao, enquanto Ant Design renderiza a experiencia lateral.

## Testar localmente

```bash
npm create refine-app@latest -- --example form-antd-use-drawer-form
```

## Pontos principais

- Uso de `useDrawerForm` com Ant Design.
- Criacao e edicao em drawer sem sair da lista.
- Sincronizacao entre formulario, URL e resource.
- Comandos, URLs e APIs preservados no codigo.
