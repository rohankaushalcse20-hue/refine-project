## Ejemplo de formulario en drawer con Ant Design

Este ejemplo muestra cómo usar `useDrawerForm` de **Refine** con Ant Design para editar registros en un drawer lateral. El patrón mantiene el contexto de la lista mientras se modifica un elemento.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example form-antd-use-drawer-form
```

## Puntos clave

- Formularios laterales gestionados con `useDrawerForm`
- Estado de apertura y envío coordinado
- Edición de registros sin abandonar la página principal
- Comandos, URLs y nombres técnicos conservados sin traducir
