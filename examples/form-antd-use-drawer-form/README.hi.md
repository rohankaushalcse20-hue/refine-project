## Ant Design useDrawerForm example

यह example **Refine** और Ant Design में drawer-based forms बनाना दिखाता है। `useDrawerForm` hook drawer visibility, form state और save mutations को एक reusable workflow में जोड़ता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example form-antd-use-drawer-form
```

## मुख्य बिंदु

- Ant Design drawer के अंदर create/edit form खोलना
- `useDrawerForm` से form lifecycle और submit handling
- list page actions से drawer form interaction
- commands, URLs और hook names को original example जैसा रखना
