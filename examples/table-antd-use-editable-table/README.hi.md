## Ant Design useEditableTable example

यह example **Refine** और Ant Design में inline editable table बनाना दिखाता है। `useEditableTable` hook rows को edit mode में बदलकर table के अंदर ही update workflow चलाता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example table-antd-use-editable-table
```

## मुख्य बिंदु

- Ant Design `Table` के साथ `useEditableTable`
- rows को inline edit और save mode में संभालना
- table cells से update mutations चलाना
- commands, URLs और hook names को original example जैसा रखना
