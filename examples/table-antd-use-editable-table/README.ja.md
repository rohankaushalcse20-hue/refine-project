## Ant Design の編集可能テーブル

この例では、Ant Design のテーブル内で **refine** の編集フローを扱う方法を示します。行をその場で編集する UI を作りたい場合の出発点になります。

## ローカルで試す

```bash
npm create refine-app@latest -- --example table-antd-use-editable-table
```

## 主なポイント

- Ant Design のテーブルでインライン編集を行います。
- refine の更新処理を行単位の編集に接続します。
- 一覧から離れずに値を変更する管理画面に向いています。
- ローカル実行用コマンドは元のままです。

[CodeSandbox で table-antd-use-editable-table の例を開く](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/table-antd-use-editable-table?view=preview&theme=dark&codemirror=1)
