## Ejemplo de tabla editable con Ant Design

Este ejemplo muestra cómo usar **Refine** y Ant Design para editar registros directamente dentro de una tabla. El patrón reduce cambios de contexto cuando los usuarios actualizan muchos campos en una lista.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example table-antd-use-editable-table
```

## Puntos clave

- Edición en línea dentro de una tabla Ant Design
- Integración con mutations y estado de Refine
- Flujo eficiente para actualizar filas sin abrir otra vista
- Comandos, URLs y nombres de API conservados como en el ejemplo original
