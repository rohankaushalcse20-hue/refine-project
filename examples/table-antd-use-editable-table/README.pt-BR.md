## Exemplo de tabela editavel com Ant Design

Este exemplo mostra como usar **refine** com Ant Design para editar registros diretamente na tabela. O refine coordena o estado de edicao e as mutacoes, enquanto Ant Design fornece a tabela e os campos inline.

## Testar localmente

```bash
npm create refine-app@latest -- --example table-antd-use-editable-table
```

## Pontos principais

- Uso de `useEditableTable` com Ant Design.
- Edicao inline de registros em uma lista CRUD.
- Salvamento e cancelamento conectados ao data provider.
- Comandos, URLs e APIs preservados no codigo.
