## Ant Design multipart upload example

यह example दिखाता है कि **Refine** और Ant Design के साथ multipart file upload workflow कैसे बनाया जाता है। इसमें upload control को form submit और backend file handling के साथ जोड़ने का तरीका शामिल है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example upload-antd-multipart
```

## मुख्य बिंदु

- Ant Design upload component के साथ multipart file handling
- form data और uploaded files को submit flow में शामिल करना
- backend endpoint के साथ file upload request भेजना
- command, component names और URLs को original example जैसा रखना
