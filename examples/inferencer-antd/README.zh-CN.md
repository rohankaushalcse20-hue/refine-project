## Ant Design Inferencer 示例

这个示例展示如何使用 **Refine** 的 Inferencer 为 Ant Design 快速生成资源页面。它适合查看数据结构并得到可继续定制的列表、展示和表单代码。

## 本地运行

```bash
npm create refine-app@latest -- --example inferencer-antd
```

## 建议关注

- Inferencer 如何根据资源数据推断 UI
- 生成的 Ant Design 代码如何继续调整
- 列表、展示和编辑页面的生成入口
- 原始命令、URL 和 API 名称保持不变
