## Ejemplo de `useMenu`

Este ejemplo muestra cómo usar `useMenu` en **Refine** para construir menús a partir de los resources configurados. Permite reflejar la estructura de navegación sin duplicar definiciones.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example core-use-menu
```

## Puntos clave

- Generación de navegación con `useMenu`
- Menús sincronizados con la configuración de resources
- Personalización de elementos visibles y activos
- Comandos, URLs y nombres de API conservados como en el ejemplo original
