## Exemplo de `useMenu`

Este exemplo mostra como o **Refine** usa `useMenu` para gerar dados de navegação a partir dos resources. Ele é útil para criar menus, sidebars e layouts próprios.

## Executar localmente

```bash
npm create refine-app@latest -- --example core-use-menu
```

## Pontos principais

- Entradas de menu derivadas da configuração de resources
- Navegação personalizada sem componentes de layout prontos
- Suporte a rotas ativas e estruturas aninhadas
- Comandos, URLs e nomes de API preservados como no exemplo original
