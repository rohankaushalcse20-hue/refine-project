## useMenu example

यह example **Refine** के `useMenu` hook से resource-based navigation बनाना दिखाता है। Hook configured resources को पढ़कर menu items देता है, जिन्हें custom layout में render किया जा सकता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example core-use-menu
```

## मुख्य बिंदु

- `useMenu` hook से navigation data लेना
- resources और routes के आधार पर menu structure बनाना
- custom layout में active और nested menu states संभालना
- commands, hook names और route names को original example जैसा रखना
