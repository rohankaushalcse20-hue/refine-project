## kbar command palette example

यह example दिखाता है कि **Refine** application में `@refinedev/kbar` के साथ command palette कैसे जोड़ी जाती है। Users keyboard-driven navigation और resource actions को quick commands से चला सकते हैं।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example command-palette-kbar
```

## मुख्य बिंदु

- `@refinedev/kbar` integration के साथ command palette
- resources और actions को searchable commands में बदलना
- keyboard-first admin workflows के लिए quick navigation
- commands और package names को original example जैसा रखना
