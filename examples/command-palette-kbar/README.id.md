## Contoh command palette dengan kbar

Contoh ini menunjukkan cara menambahkan command palette ke aplikasi **Refine** memakai kbar. Pengguna dapat membuka action navigasi dan operasi umum dari palette, sementara route dan resource tetap mengikuti konfigurasi Refine.

## Menjalankan secara lokal

```bash
npm create refine-app@latest -- --example command-palette-kbar
```

## Hal yang perlu diperhatikan

- Integrasi kbar untuk command palette
- Action navigasi yang membaca resource Refine
- Pengalaman keyboard-friendly untuk aplikasi admin
- Command, URL, dan nama teknis tetap dipertahankan tanpa diterjemahkan
