## Exemplo de Command Palette com kbar

Este exemplo mostra como usar **Refine** com `@refinedev/kbar` para oferecer uma Command Palette. A navegação fica mais rápida para resources, actions e páginas frequentes.

## Executar localmente

```bash
npm create refine-app@latest -- --example command-palette-kbar
```

## Pontos principais

- Integração com `@refinedev/kbar`
- Navegação rápida por resources e páginas
- Actions acessíveis a partir da Command Palette
- Comandos, URLs e nomes de API preservados como no exemplo original
