## Ejemplo de paleta de comandos con kbar

Este ejemplo muestra cómo añadir una paleta de comandos a una aplicación de **Refine** con kbar. La paleta permite navegar y ejecutar acciones frecuentes sin abandonar el flujo de trabajo.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example command-palette-kbar
```

## Puntos clave

- Integración de kbar con la navegación de Refine
- Acciones rápidas para resources y páginas
- Experiencia de teclado para paneles administrativos
- Comandos, URLs y nombres de API conservados como en el ejemplo original
