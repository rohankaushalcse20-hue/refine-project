## kbar komut paleti örneği

Bu örnek, Refine uygulamasına `kbar` ile komut paleti eklemeyi gösterir. Kullanıcılar klavye üzerinden kaynaklara ve uygulama eylemlerine hızlıca erişebilir.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example command-palette-kbar
```

## Dikkat edilecek noktalar

- `kbar` tabanlı komut paleti entegrasyonu
- Refine kaynakları için hızlı gezinme eylemleri
- Paket ve hook adları çevrilmeden bırakılmıştır
