## Mantine useDrawerForm example

यह example दिखाता है कि **Refine** और Mantine के साथ drawer based forms कैसे बनाए जाते हैं। यह list context छोड़े बिना create और edit workflows चलाने के लिए उपयोगी है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example form-mantine-use-drawer-form
```

## मुख्य बिंदु

- Mantine drawer में form UI दिखाना
- `useDrawerForm` से drawer visibility और form state संभालना
- create/edit mutations को drawer submit action से जोड़ना
- command, hook names और URLs को original example जैसा रखना
