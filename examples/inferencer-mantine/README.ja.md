## Mantine の Inferencer

この例では、**refine** の Inferencer と Mantine を使って初期 CRUD 画面を生成する方法を示します。resource を素早く試し、生成された UI をあとから調整するための実用的な出発点です。

## ローカルで試す

```bash
npm create refine-app@latest -- --example inferencer-mantine
```

## 主なポイント

- Inferencer で一覧やフォームの初期画面を生成します。
- 生成 UI に Mantine のコンポーネントを適用します。
- resource のプロトタイプを短時間で確認できます。
- 例のコマンドと URL は元のままです。
