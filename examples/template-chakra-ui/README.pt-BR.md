## Primeiros passos

**refine** e um framework baseado em React para criar aplicacoes orientadas a dados rapidamente.

Refine oferece varias funcionalidades prontas para acelerar o desenvolvimento sem abrir mao de customizacao. Casos de uso incluem, entre outros, admin panels, aplicacoes B2B e dashboards.

## Scripts disponiveis

### Executar o servidor de desenvolvimento.

```bash
npm run dev
```

### Gerar build de producao.

```bash
npm run build
```

### Executar o servidor de producao.

```bash
npm run dev
```
