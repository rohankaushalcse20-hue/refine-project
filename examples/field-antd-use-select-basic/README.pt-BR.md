## Exemplo básico de `useSelect` com Ant Design

Este exemplo mostra como usar **Refine** com Ant Design para preencher um campo `Select`. O hook `useSelect` busca opções no `dataProvider` e entrega os dados no formato esperado pela UI.

## Executar localmente

```bash
npm create refine-app@latest -- --example field-antd-use-select-basic
```

## Pontos principais

- Campo `Select` do Ant Design alimentado por `useSelect`
- Busca de opções a partir de resources
- Uso em formulários de criação e edição
- Comandos, URLs e nomes de API preservados como no exemplo original
