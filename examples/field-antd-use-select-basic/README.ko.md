## Ant Design useSelect 기본 예제

이 예제는 **Refine**의 `useSelect` hook을 Ant Design `Select` 컴포넌트와 연결하는 기본 패턴을 보여줍니다. 관련 resource 목록을 option으로 불러와 form 입력에서 사용할 수 있습니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example field-antd-use-select-basic
```

## 확인할 점

- `useSelect`가 select options를 준비하는 방식
- Ant Design `Select`와 Refine form의 연결
- resource 데이터 기반 관계형 입력
- 명령어, URL, API 이름은 원본 그대로 유지
