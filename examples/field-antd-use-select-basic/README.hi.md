## Ant Design useSelect basic example

यह example **Refine** और Ant Design में `useSelect` hook से select fields बनाना दिखाता है। Related resources से options load करके forms में reusable dropdowns तैयार किए जाते हैं।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example field-antd-use-select-basic
```

## मुख्य बिंदु

- Ant Design `Select` component के साथ `useSelect`
- resource records से dropdown options load करना
- form fields को related resource values से जोड़ना
- commands, URLs और hook names को original example जैसा रखना
