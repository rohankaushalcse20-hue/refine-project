## Material UI tema özelleştirme örneği

Bu örnek, Material UI teması üzerinden Refine uygulamasının görünümünü özelleştirmeyi gösterir. Renkler, tipografi ve bileşen stilleri merkezi tema ayarlarıyla yönetilir.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example customization-theme-material-ui
```

## Dikkat edilecek noktalar

- Material UI `theme` yapılandırması
- Refine uygulama kabuğunda tema sağlayıcısı kullanımı
- Tema anahtarları ve bileşen adları teknik biçimleriyle korunur

[customization-theme-material-ui örneğini CodeSandbox'da aç](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/customization-theme-material-ui?view=preview&theme=dark&codemirror=1)
