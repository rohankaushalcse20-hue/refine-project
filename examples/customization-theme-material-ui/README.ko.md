## Material UI Theme 커스터마이징 예제

이 예제는 **Refine** 애플리케이션에서 Material UI theme를 정의하고 관리 화면 전체에 적용하는 방법을 보여줍니다. provider와 resource 구조는 유지하면서 palette, typography, component 기본값을 바꿀 수 있습니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example customization-theme-material-ui
```

## 확인할 점

- Material UI theme 설정과 provider 연결
- Refine layout, form, table에 theme가 적용되는 방식
- 브랜드별 palette와 component override 관리
- 원본 명령어, URL, API 이름 유지
