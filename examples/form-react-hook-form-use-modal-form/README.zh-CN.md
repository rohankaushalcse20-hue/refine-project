## React Hook Form 模态表单示例

这个示例展示如何在 **Refine** 中结合 React Hook Form 和模态窗口处理表单。Refine 管理资源变更流程，React Hook Form 负责字段状态和验证。

## 本地运行

```bash
npm create refine-app@latest -- --example form-react-hook-form-use-modal-form
```

## 建议关注

- `useModalForm` 与 React Hook Form 的配合方式
- 创建和编辑操作如何复用模态表单
- 表单提交后列表数据的刷新流程
- 原始命令、URL 和 API 名称保持不变
