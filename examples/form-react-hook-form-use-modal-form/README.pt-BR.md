## Exemplo de `useModalForm` com React Hook Form

Este exemplo mostra como usar **Refine** com React Hook Form para gerenciar formulários em modal. O fluxo mantém a validação e o envio ligados aos resources do Refine.

## Executar localmente

```bash
npm create refine-app@latest -- --example form-react-hook-form-use-modal-form
```

## Pontos principais

- Formulários em modal com React Hook Form
- Integração com hooks de formulário do Refine
- Mutations de criação e edição a partir do modal
- Comandos, URLs e nomes de API preservados como no exemplo original
