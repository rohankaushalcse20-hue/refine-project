## Exemplo de data provider NestJS Query

Este exemplo mostra como integrar o Refine a uma API baseada em NestJS Query. A aplicacao usa o data provider para transformar operacoes de resources em chamadas compativeis com o backend.

## Testar localmente

```bash
npm create refine-app@latest -- --example data-provider-nestjs-query
```

## Pontos principais

- Conexao entre Refine resources e uma API NestJS Query.
- Fluxos de CRUD usando o data provider.
- Separacao entre camada de dados e componentes de UI.
- Preservacao de nomes de schema, endpoints e parametros usados pelo exemplo.
