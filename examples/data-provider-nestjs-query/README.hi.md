## NestJS Query data provider example

यह example **Refine** में NestJS Query data provider के साथ CRUD workflows बनाना दिखाता है। Application resources को NestJS Query API से जोड़कर list, create, edit और delete screens चलाए जाते हैं।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example data-provider-nestjs-query
```

## मुख्य बिंदु

- NestJS Query data provider के साथ Refine resource setup
- CRUD hooks को backend queries और mutations से जोड़ना
- generated list/create/edit pages के लिए data flow
- commands, URLs और API names को original example जैसा रखना
