## Ejemplo de data provider NestJS Query

Este ejemplo muestra cómo conectar Refine con un backend NestJS Query usando el data provider correspondiente.

## Probar localmente

```bash
npm create refine-app@latest -- --example data-provider-nestjs-query
```

## Qué revisar

- Configuración del endpoint de NestJS Query.
- Lectura de listas con paginación y filtros.
- Mutaciones create, update y delete desde Refine.
- Compatibilidad entre resources y entidades del backend.
