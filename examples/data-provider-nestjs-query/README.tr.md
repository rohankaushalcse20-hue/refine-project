## NestJS Query data provider örneği

Bu örnek, NestJS Query tabanlı GraphQL API'sini Refine veri akışına bağlamayı gösterir. Paket, framework ve API adları özgün halleriyle korunur.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example data-provider-nestjs-query
```

## Dikkat edilecek noktalar

- NestJS Query şemasıyla liste ve form ekranları oluşturma
- GraphQL sorgularının `dataProvider` tarafından yönetilmesi
- Filtreleme, sıralama ve sayfalama davranışları
