## Ant Design useSelect infinite example

यह example **Refine** और Ant Design में large option lists के लिए infinite select pattern दिखाता है। `useSelect` hook pagination और search के साथ options को जरूरत के हिसाब से load करता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example field-antd-use-select-infinite
```

## मुख्य बिंदु

- Ant Design `Select` में paginated options load करना
- `useSelect` के साथ search और infinite loading
- बड़े related datasets के लिए responsive field UX
- commands, URLs और hook names को original example जैसा रखना
