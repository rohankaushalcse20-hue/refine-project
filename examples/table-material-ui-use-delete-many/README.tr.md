## Material UI `useDeleteMany` tablo örneği

Bu örnek, Material UI tablosunda birden fazla kaydı silmek için Refine `useDeleteMany` hook'unun kullanımını gösterir. Seçili satırlar tek bir toplu işlemle veri sağlayıcıya gönderilir.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example table-material-ui-use-delete-many
```

## Dikkat edilecek noktalar

- Tablo satırı seçimiyle toplu silme
- `useDeleteMany` üzerinden mutasyon yönetimi
- API ve hook adları çevrilmeden korunur
