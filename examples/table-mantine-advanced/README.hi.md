## Mantine advanced table example

यह example दिखाता है कि **Refine** और Mantine के साथ richer table experience कैसे बनाया जाता है। इसमें list view में pagination, filtering और row actions जैसे features को एक साथ रखा गया है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example table-mantine-advanced
```

## मुख्य बिंदु

- Mantine UI के साथ advanced table controls
- filtering और pagination को Refine resource queries से जोड़ना
- table rows से CRUD actions चलाना
- command, hook names और CodeSandbox URL को original example जैसा रखना
