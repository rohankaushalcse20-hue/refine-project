## Mantine の高度なテーブル

この例では、Mantine を使った **refine** のより高度な一覧画面を示します。resource と連携した管理テーブルに、行アクションや状態表示を追加する際の参考になります。

## ローカルで試す

```bash
npm create refine-app@latest -- --example table-mantine-advanced
```

## 主なポイント

- Mantine のコンポーネントで高度な一覧を構成します。
- refine のデータ hooks とテーブル UI を接続します。
- フィルター、ページング、行アクションを拡張しやすい構成です。
- CodeSandbox のリンクは元の例を保持しています。

[CodeSandbox で table-mantine-advanced の例を開く](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/table-mantine-advanced?view=preview&theme=dark&codemirror=1)
