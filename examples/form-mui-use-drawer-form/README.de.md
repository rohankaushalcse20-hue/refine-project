## MUI Drawer-Formularbeispiel

Dieses Beispiel zeigt, wie **Refine** Formulare in einem MUI Drawer oeffnet. Nutzer koennen Datensaetze bearbeiten, ohne die aktuelle Listenansicht zu verlassen.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example form-mui-use-drawer-form
```

## Wichtige Punkte

- Drawer-basierte Create- und Edit-Formulare aufbauen
- Refine-Formularstatus mit MUI Drawer-Zustand verbinden
- Listenansicht und Bearbeitungsformular zusammen nutzen
- Befehle, URLs und API-Namen unveraendert lassen
