## Ejemplo de layout con menú superior

Este ejemplo muestra cómo usar un layout con menú superior en lugar de navegación lateral dentro de una aplicación Refine.

## Probar localmente

```bash
npm create refine-app@latest -- --example customization-top-menu-layout
```

## Qué revisar

- Cambio de estructura de navegación principal.
- Renderizado de recursos en un menú horizontal.
- Comportamiento responsive del layout.
- Separación entre shell visual y páginas CRUD.
