## Ejemplo de formulario Ant Design con `useForm`

Este ejemplo muestra cómo usar `useForm` de **Refine** con Ant Design para crear y editar registros. El hook conecta el formulario con mutations, validación y estado de envío.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example form-antd-use-form
```

## Puntos clave

- Formularios CRUD con `useForm`
- Integración con componentes de Ant Design
- Manejo de carga, validación y envío
- Comandos, URLs y nombres técnicos conservados sin traducir
