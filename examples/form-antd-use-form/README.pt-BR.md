## Exemplo de formulario Ant Design com `useForm`

Este exemplo mostra como usar **refine** com Ant Design para criar formularios CRUD usando `useForm`. O refine conecta o formulario as mutacoes do resource, enquanto Ant Design fornece os campos e validacoes visuais.

## Testar localmente

```bash
npm create refine-app@latest -- --example form-antd-use-form
```

## Pontos principais

- Uso de `useForm` com componentes Ant Design.
- Submissao conectada ao fluxo de criacao e edicao do refine.
- Estado do formulario sincronizado com o resource.
- Comandos, URLs e APIs preservados no codigo.
