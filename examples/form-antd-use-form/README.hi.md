## Ant Design useForm example

यह example **Refine** और Ant Design के साथ `useForm` hook का basic form workflow दिखाता है। इसमें create और edit screens को form state, validation और save actions से जोड़ा गया है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example form-antd-use-form
```

## मुख्य बिंदु

- Ant Design `Form` component के साथ `useForm` integration
- create/edit pages के लिए initial values और submit handling
- Refine mutations के जरिए record save करना
- commands, URLs और hook names को original example जैसा रखना
