## Ant Design useRadioGroup example

यह example **Refine** और Ant Design में `useRadioGroup` hook से single-choice fields बनाना दिखाता है। Related resource data को radio options में बदलकर forms में predictable selection flow मिलता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example field-antd-use-radio-group
```

## मुख्य बिंदु

- Ant Design `Radio.Group` के साथ `useRadioGroup`
- related records से radio options load करना
- single selected value को form state में रखना
- commands, URLs और hook names को original example जैसा रखना
