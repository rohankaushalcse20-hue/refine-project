## Ant Design useRadioGroup 예제

이 예제는 **Refine**에서 Ant Design radio group을 `useRadioGroup` hook과 함께 구성하는 방법을 보여줍니다. resource 데이터를 단일 선택 옵션으로 가져와 form 입력과 연결합니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example field-antd-use-radio-group
```

## 확인할 점

- `useRadioGroup`으로 radio options를 구성하는 방식
- Ant Design form field와 Refine resource 데이터 연결
- 단일 선택 값의 submit 흐름
- 원본 명령어, URL, API 이름 유지
