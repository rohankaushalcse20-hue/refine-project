## Exemplo de `useRadioGroup` com Ant Design

Este exemplo mostra como usar **Refine** e Ant Design para criar grupos de radio em formulários. O hook organiza as opções para que o campo possa consumir dados vindos de resources.

## Executar localmente

```bash
npm create refine-app@latest -- --example field-antd-use-radio-group
```

## Pontos principais

- Uso de `useRadioGroup` com Ant Design
- Opções carregadas por meio do `dataProvider`
- Campos conectados a formulários do Refine
- Comandos, URLs e nomes de API preservados como no exemplo original
