## Ant Design import/export example

यह example दिखाता है कि **Refine** और Ant Design के साथ records को import और export कैसे किया जा सकता है। इसमें table workflow के साथ file upload, data parsing और export action को जोड़ा गया है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example import-export-antd
```

## मुख्य बिंदु

- Ant Design table UI के साथ import और export actions
- records को bulk में upload करने के लिए file based workflow
- list page से export controls जोड़ना
- command, component names और CodeSandbox URL को original example जैसा रखना
