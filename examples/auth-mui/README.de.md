## Authentifizierungsbeispiel mit MUI

Dieses Beispiel zeigt, wie **Refine** Authentifizierung mit einer MUI-Oberflaeche kombiniert. Login, Logout, Identitaet und geschuetzte Seiten werden ueber den Refine auth provider gesteuert.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example auth-mui
```

## Wichtige Punkte

- Login- und Logout-Ablauf mit dem auth provider abbilden
- Geschuetzte Seiten in einer MUI-App anzeigen
- Benutzeridentitaet in Refine bereitstellen
- Befehle, URLs und API-Namen unveraendert lassen

[Beispiel auth-mui in CodeSandbox oeffnen](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/auth-mui?view=preview&theme=dark&codemirror=1)
