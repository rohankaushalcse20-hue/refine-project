## Custom Sider 예제

이 예제는 **Refine**의 기본 sider navigation을 프로젝트에 맞게 바꾸는 방법을 보여줍니다. resource 기반 메뉴 구조는 유지하면서 메뉴 항목, 접힘 상태, 브랜드 영역을 조정할 수 있습니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example customization-sider
```

## 확인할 점

- custom sider component와 Refine layout 연결
- resource metadata로 메뉴를 구성하는 방식
- navigation 상태와 route 이동 흐름
- 원본 명령어, URL, API 이름 유지
