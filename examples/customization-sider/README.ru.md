## Пример кастомного sider

Этот пример показывает, как заменить боковую навигацию Refine собственным `Sider`. Он полезен для приложений с особой структурой меню, дополнительными группами ссылок или брендированным поведением навигации.

## Запуск локально

```bash
npm create refine-app@latest -- --example customization-sider
```

## Что проверить

- Подключение пользовательского `Sider` к layout.
- Отображение ресурсов и активного пункта меню.
- Поведение сворачивания и переходов между страницами.
- Неизменность component names, resource names и commands.
