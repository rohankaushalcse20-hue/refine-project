## Ejemplo de sider personalizado

Este ejemplo muestra cómo adaptar el menú lateral de Refine para ajustar navegación, etiquetas y estructura visual de la aplicación.

## Probar localmente

```bash
npm create refine-app@latest -- --example customization-sider
```

## Qué revisar

- Personalización del componente sider.
- Uso de recursos para construir elementos de menú.
- Estados de seleccion y navegación activa.
- Conservación de rutas y permisos existentes.
