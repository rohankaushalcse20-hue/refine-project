## Job posting blog example

यह example job posting application के लिए Refine resources, list pages और form flows का इस्तेमाल दिखाता है। इसे hiring या marketplace-style admin experiences के लिए starting point की तरह पढ़ा जा सकता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example blog-job-posting
```
