## Ejemplo de data provider Sanity

Este ejemplo muestra cómo conectar Refine con Sanity para administrar contenido usando un data provider adaptado al CMS.

## Probar localmente

```bash
npm create refine-app@latest -- --example data-provider-sanity
```

## Qué revisar

- Configuración del proyecto y dataset de Sanity.
- Lectura y escritura de documentos como resources.
- Uso de filtros compatibles con Sanity.
- Preservacion de schemas y nombres de documentos.
