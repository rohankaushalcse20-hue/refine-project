## MUI-Tabellenfilter-Beispiel

Dieses Beispiel zeigt, wie **Refine** Filterwerte aus einer MUI-Tabelle verwaltet. Filter werden in Refine synchronisiert und koennen dadurch mit Routing, Datenabfragen und Listenstatus zusammenarbeiten.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example table-mui-table-filter
```

## Wichtige Punkte

- Tabellenfilter mit Refine-Listenstatus verbinden
- MUI-Filterfelder fuer serverseitige Abfragen verwenden
- Filterlogik reproduzierbar und routingfreundlich halten
- Befehle, URLs und API-Namen unveraendert lassen
