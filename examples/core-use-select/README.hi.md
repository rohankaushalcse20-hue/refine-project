## useSelect example

यह example **Refine** के `useSelect` hook से select inputs के लिए remote options load करना दिखाता है। Hook data provider से records fetch करता है और form controls को resource data से जोड़ता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example core-use-select
```

## मुख्य बिंदु

- `useSelect` hook के साथ resource-backed select options
- search, filtering और default values का select workflow
- forms में related resources को जोड़ने का pattern
- commands, hook names और API names को original example जैसा रखना
