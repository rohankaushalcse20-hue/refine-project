## Ejemplo de `useSelect`

Este ejemplo muestra cómo usar `useSelect` en **Refine** para cargar opciones desde un resource y conectarlas a controles de selección. Es útil para relaciones, filtros y formularios con datos remotos.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example core-use-select
```

## Puntos clave

- Opciones remotas gestionadas con `useSelect`
- Integración con resources y data providers
- Soporte para búsqueda, paginación y valores por defecto
- Comandos, URLs y nombres de API conservados como en el ejemplo original
