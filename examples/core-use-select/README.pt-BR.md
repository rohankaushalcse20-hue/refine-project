## Exemplo de `useSelect`

Este exemplo mostra como o **Refine** usa `useSelect` para carregar opções de seleção a partir de resources. O hook conecta consultas, paginação e busca aos componentes de formulário.

## Executar localmente

```bash
npm create refine-app@latest -- --example core-use-select
```

## Pontos principais

- Opções carregadas pelo `dataProvider`
- Suporte a busca e paginação em campos de seleção
- Uso em formulários e filtros personalizados
- Comandos, URLs e nomes de API preservados como no exemplo original
