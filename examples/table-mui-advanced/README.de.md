## Erweitertes MUI-Tabellenbeispiel

Dieses Beispiel zeigt, wie **Refine** mit MUI komplexe Tabellenansichten aufbaut. Listenlogik, Filter, Sortierung und Pagination bleiben in Refine gebuendelt, waehrend MUI die Tabellenoberflaeche rendert.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example table-mui-advanced
```

## Wichtige Punkte

- Tabellenzustand mit Refine-Hooks verwalten
- MUI-Komponenten fuer Filter, Sortierung und Pagination verwenden
- UI, resources und data provider getrennt halten
- Befehle, URLs und API-Namen unveraendert lassen
