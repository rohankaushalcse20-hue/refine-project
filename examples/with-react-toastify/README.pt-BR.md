## Exemplo com React Toastify

Este exemplo mostra como usar **refine** com React Toastify para notificacoes. Ele demonstra como conectar feedback visual de sucesso, erro e operacoes ao notification provider da aplicacao.

## Testar localmente

```bash
npm create refine-app@latest -- --example with-react-toastify
```

## Pontos principais

- Integracao de notificacoes com React Toastify.
- Mensagens conectadas a operacoes CRUD.
- Providers do refine mantidos no fluxo principal.
- Comandos e URLs preservados para reproducao.
