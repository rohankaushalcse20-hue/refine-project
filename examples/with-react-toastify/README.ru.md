## Пример уведомлений с React Toastify

Этот пример показывает, как подключить **React Toastify** к notification flow в **Refine**. Уведомления помогают отображать успех, ошибку и состояние операций CRUD.

## Запуск локально

```bash
npm create refine-app@latest -- --example with-react-toastify
```

## Что проверить

- Конфигурацию notification provider.
- Отображение success и error toast messages.
- Связь уведомлений с create, edit и delete actions.
- Сохранение package names, provider API и command syntax без перевода.
