## React Toastify notification example

यह example दिखाता है कि notifications के लिए **Refine** को React Toastify के साथ कैसे इस्तेमाल किया जाता है। Success, error और operation feedback application के notification provider से जुड़ता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example with-react-toastify
```

## मुख्य बिंदु

- React Toastify के साथ notification integration
- CRUD operations से जुड़ी messages
- Refine providers को main flow में रखना
- commands और URLs को reproducible रखना
