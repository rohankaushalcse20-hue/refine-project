## Ejemplo con React Toastify

Este ejemplo muestra cómo usar **Refine** con React Toastify para mostrar notificaciones de aplicación. Refine emite eventos de notificación y React Toastify se encarga de la presentación visual.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example with-react-toastify
```

## Puntos clave

- Integración de React Toastify como notification provider
- Mensajes de éxito y error dentro de flujos CRUD
- Separación entre eventos de Refine y presentación de notificaciones
- Comandos, URLs y nombres técnicos conservados
