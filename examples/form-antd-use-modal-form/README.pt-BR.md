## Exemplo de formulario modal com Ant Design

Este exemplo mostra como usar **refine** e Ant Design para criar e editar registros em um modal. O hook de formulario do refine cuida da mutacao e do estado, enquanto Ant Design fornece o modal e os campos.

## Testar localmente

```bash
npm create refine-app@latest -- --example form-antd-use-modal-form
```

## Pontos principais

- Uso de `useModalForm` com Ant Design.
- Formularios de criacao e edicao em modal.
- Estado do modal alinhado ao fluxo CRUD.
- Comandos, URLs e APIs preservados no codigo.
