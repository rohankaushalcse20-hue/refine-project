## Ejemplo de formulario modal Ant Design

Este ejemplo muestra cómo usar `useModalForm` de **Refine** con Ant Design para crear y editar registros dentro de un modal. La lógica del formulario y la visibilidad del modal se gestionan juntas.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example form-antd-use-modal-form
```

## Puntos clave

- Formularios en modal con `useModalForm`
- Apertura, cierre y envío coordinados
- Integración con mutations de Refine
- Comandos, URLs y nombres de API conservados como en el ejemplo original
