## Ejemplo de Inferencer con Material UI

Este ejemplo muestra cómo usar **Refine Inferencer** con Material UI para generar pantallas CRUD iniciales a partir de un resource. Sirve como punto de partida para revisar y adaptar el código generado.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example inferencer-material-ui
```

## Puntos clave

- Uso de Inferencer para crear vistas iniciales
- Componentes de Material UI para list, show, create y edit
- Relación entre resources y data provider
- Comandos, URLs y nombres de API conservados
