## Material UI Inferencer example

यह example दिखाता है कि **Refine** Inferencer को Material UI के साथ कैसे इस्तेमाल किया जाता है। Inferencer resource metadata से pages generate करने में मदद करता है, और Material UI generated interface को render करता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example inferencer-material-ui
```

## मुख्य बिंदु

- Material UI के साथ Inferencer output
- resource metadata से generated CRUD pages
- generated code को आगे customize करने की base
- commands, URLs और API names को सुरक्षित रखना
