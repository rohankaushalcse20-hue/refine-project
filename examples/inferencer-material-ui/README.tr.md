## Material UI Inferencer örneği

Bu örnek, Material UI ile Refine Inferencer kullanımını gösterir. Inferencer, veri yapısını inceleyerek liste, gösterim ve form ekranları için başlangıç kodu üretmeye yardımcı olur.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example inferencer-material-ui
```

## Dikkat edilecek noktalar

- Material UI uyumlu Inferencer çıktıları
- Kaynak şemasından hızlı ekran oluşturma
- `Inferencer` ve bileşen adları teknik adlarıyla korunur
