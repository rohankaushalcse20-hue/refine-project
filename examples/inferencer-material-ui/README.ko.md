## Material UI Inferencer 예제

이 예제는 **Refine**의 Inferencer가 resource schema를 바탕으로 Material UI 화면을 생성하는 방법을 보여줍니다. 생성된 코드를 출발점으로 목록, 상세, 생성, 수정 화면을 빠르게 구성할 수 있습니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example inferencer-material-ui
```

## 핵심 포인트

- Material UI 기반 Inferencer 사용
- data provider 응답에서 resource 화면 추론
- 생성된 CRUD 화면을 프로젝트 코드로 확장
- 원본 명령어, URL, API 이름 유지
