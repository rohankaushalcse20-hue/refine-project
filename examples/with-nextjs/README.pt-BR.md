## Exemplo com Next.js

Este exemplo mostra uma aplicacao Refine criada sobre Next.js. Ele demonstra como combinar resources, data provider e roteamento com a estrutura de uma aplicacao Next.js.

## Testar localmente

```bash
npm create refine-app@latest -- --example with-nextjs
```

## Pontos principais

- Estrutura de projeto Refine com Next.js.
- Roteamento integrado ao framework.
- Fluxos de CRUD conectados ao data provider.
- Comandos, paths e nomes de arquivos preservados para facilitar a reproducao.
