## Ejemplo de tema personalizado con Mantine

Este ejemplo muestra cómo configurar un tema Mantine para adaptar la apariencia de una aplicación Refine.

## Probar localmente

```bash
npm create refine-app@latest -- --example customization-theme-mantine
```

## Qué revisar

- Definición del tema Mantine.
- Propagación del provider visual a componentes Refine.
- Consistencia entre formularios, tablas y navegación.
- Separación entre configuración visual y comportamiento CRUD.
