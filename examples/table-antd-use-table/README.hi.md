## Ant Design table example

यह example दिखाता है कि table based list बनाने के लिए **Refine** को Ant Design के साथ कैसे इस्तेमाल किया जाता है। Refine का table hook pagination, filters और data को resource से जोड़ता है, जबकि Ant Design interface render करता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example table-antd-use-table
```

## मुख्य बिंदु

- Ant Design के साथ `useTable` का उपयोग
- data provider से जुड़ी CRUD list
- pagination और filters को resource से जोड़ना
- commands और URLs सुरक्षित रखना
