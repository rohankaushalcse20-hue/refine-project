## Ejemplo de tabla con Ant Design

Este ejemplo muestra cómo usar **Refine** con Ant Design para construir una tabla conectada a resources. El hook `useTable` ayuda a coordinar paginación, filtros y datos.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example table-antd-use-table
```

## Puntos clave

- Uso de `useTable` con componentes de Ant Design
- Listados conectados al data provider
- Paginación, filtros y sorting dentro del flujo de Refine
- Comandos, URLs y nombres técnicos sin cambios
