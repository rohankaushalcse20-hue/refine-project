## Exemplo de tabela com Ant Design

Este exemplo mostra como usar **refine** com Ant Design para construir uma lista baseada em tabela. O hook de tabela do refine conecta paginacao, filtros e dados ao resource, enquanto Ant Design renderiza a interface.

## Testar localmente

```bash
npm create refine-app@latest -- --example table-antd-use-table
```

## Pontos principais

- Uso de `useTable` com Ant Design.
- Lista CRUD ligada ao data provider.
- Paginacao e filtros conectados ao resource.
- Comandos e URLs preservados para reproducao.
