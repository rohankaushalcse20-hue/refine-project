## Ant Design `useTable` 예제

이 예제는 **Refine**의 `useTable`을 Ant Design Table과 함께 사용해 목록 화면을 구성하는 방법을 보여줍니다. data provider에서 받은 데이터를 pagination, sorting, filtering 흐름과 연결합니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example table-antd-use-table
```

## 핵심 포인트

- Ant Design Table과 `useTable` 통합
- pagination, sorting, filtering 상태 처리
- resource 목록을 data provider와 연결
- 원본 명령어, URL, API 이름 유지
