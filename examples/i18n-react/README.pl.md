# Przykład Refine i18n React

Ten przykład pokazuje, jak skonfigurować przepływ i18n oparty na React w aplikacji Refine. Celem jest pokazanie `i18nProvider`, funkcji tłumaczeń i zmiany locale w małej aplikacji.

## Najważniejsze punkty

- Używa kontraktu Refine `i18nProvider`.
- Pokazuje zmianę języka razem ze state aplikacji.
- Demonstruje rozdzielenie tekstów resource i stron przez klucze tłumaczeń.
- Nazwy API, imports i komendy pozostają bez zmian.

## Uruchomienie

```sh
npm install
npm run dev
```

## Kiedy używać?

Przykład jest przydatny, gdy chcesz zrozumieć granice providera przed podłączeniem własnej biblioteki i18n do prostej wielojęzycznej aplikacji React z Refine.
