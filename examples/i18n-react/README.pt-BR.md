## Exemplo de i18n com React

Este exemplo mostra como usar **Refine** com internacionalização em uma aplicação React. A lógica de CRUD continua no Refine, enquanto as traduções entram por meio de um provider adequado.

## Testar localmente

```bash
npm create refine-app@latest -- --example i18n-react
```

## Pontos principais

- Configuração do i18n provider.
- Troca de idioma pela interface.
- Menus, ações e textos visíveis traduzidos.
- Resources, rotas e APIs preservados no código.
