# Esempio Refine i18n React

Questo esempio mostra come configurare un flusso i18n basato su React in un'applicazione Refine. L'obiettivo è rendere visibili `i18nProvider`, funzioni di traduzione e cambio locale in una piccola applicazione.

## Punti principali

- Usa il contratto Refine `i18nProvider`.
- Mostra il cambio lingua insieme allo state dell'applicazione.
- Esemplifica come separare testi di resource e pagine tramite chiavi di traduzione.
- Nomi API, imports e comandi restano invariati.

## Esecuzione

```sh
npm install
npm run dev
```

## Quando usarlo?

È utile per capire i confini del provider prima di collegare la tua libreria i18n a Refine in una semplice applicazione React multilingua.
