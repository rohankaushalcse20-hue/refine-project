## React 的 i18n 示例

这个 example 展示了如何在 React 应用中把 **Refine** 与国际化能力结合起来使用。CRUD 逻辑由 Refine 负责，翻译能力则通过合适的 provider 接入。

## 本地运行

```bash
npm create refine-app@latest -- --example i18n-react
```

## 建议关注

- `i18nProvider` 的配置方式
- UI 中切换语言的流程
- menus、actions 与展示文本的翻译
- code 里的 resources、routes 与 APIs 是否保持原样
