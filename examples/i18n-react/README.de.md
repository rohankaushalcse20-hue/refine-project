## i18n-Beispiel mit React

Dieses Beispiel zeigt, wie du **Refine** mit Internationalisierung in einer React-Anwendung verwendest. Die CRUD-Logik bleibt in Refine, waehrend die Uebersetzungen ueber einen passenden Provider eingebunden werden.

## Lokal testen

```bash
npm create refine-app@latest -- --example i18n-react
```

## Wichtige Punkte

- Konfiguration des i18n-Providers.
- Sprachwechsel ueber die Benutzeroberflaeche.
- Uebersetzte Menues, Aktionen und sichtbare Texte.
- Unveraenderte Resources, Routen und APIs im Code.
