# Refine i18n React voorbeeld

Dit voorbeeld laat zien hoe je een React-gebaseerde i18n-flow configureert in een Refine-applicatie. Het doel is om `i18nProvider`, vertaalfuncties en locale wisselen zichtbaar te maken in een kleine applicatie.

## Belangrijkste punten

- Gebruikt het Refine-contract `i18nProvider`.
- Toont locale wisselen naast de state van de applicatie.
- Laat zien hoe je resource- en paginagebonden teksten scheidt met vertaalkeys.
- API-namen, imports en commands blijven ongewijzigd.

## Uitvoeren

```sh
npm install
npm run dev
```

## Wanneer gebruik je dit?

Dit voorbeeld is nuttig om de grenzen van de provider te begrijpen voordat je je eigen i18n-bibliotheek aan Refine koppelt in een eenvoudige meertalige React-applicatie.
