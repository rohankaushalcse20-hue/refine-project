## Material UI `useModalForm` örneği

Bu örnek, Material UI modal penceresinde Refine `useModalForm` hook'u ile form yönetimini gösterir. Modal açma, kapatma, gönderim ve kayıt yenileme akışları birlikte ele alınır.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example form-material-ui-use-modal-form
```

## Dikkat edilecek noktalar

- Modal içinde kayıt oluşturma ve düzenleme
- Material UI form bileşenleriyle Refine form yardımcıları
- Komutlar ve hook adları çevrilmeden korunur
