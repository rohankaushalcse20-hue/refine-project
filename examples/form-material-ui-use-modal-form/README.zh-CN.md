## Material UI 模态表单示例

这个示例展示如何使用 **Refine** 的 `useModalForm` 与 Material UI 构建模态表单。它适合在列表页内完成创建和编辑，而不离开当前上下文。

## 本地运行

```bash
npm create refine-app@latest -- --example form-material-ui-use-modal-form
```

## 建议关注

- 模态窗口打开和关闭状态的管理
- `useModalForm` 如何处理提交和默认值
- Material UI 表单控件与 Refine mutation 的连接
- 原始命令、URL 和 API 名称保持不变
