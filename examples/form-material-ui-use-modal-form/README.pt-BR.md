## Exemplo de `useModalForm` com Material UI

Este exemplo mostra como usar **Refine** e Material UI para criar ou editar registros em um modal. O hook `useModalForm` simplifica a ligação entre modal, formulário e mutation.

## Executar localmente

```bash
npm create refine-app@latest -- --example form-material-ui-use-modal-form
```

## Pontos principais

- Formulários em modal com `useModalForm`
- Componentes Material UI para a interface
- CRUD sem trocar de rota principal
- Comandos, URLs e nomes de API preservados como no exemplo original
