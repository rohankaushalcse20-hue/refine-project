# Tremor और refine के साथ React Admin Dashboard

**Refine** data-intensive applications को कम समय में बनाने के लिए React-आधारित framework है ✨

Refine तेज development के लिए कई out-of-the-box सुविधाएं देता है, और extreme customizability से समझौता नहीं करता। इसके use-cases में admin panels, B2B applications और dashboards शामिल हैं।

## Quick Start

Project download करने के लिए यह command चलाएं:

```
npm create refine-app@latest -- --example blog-refine-tremor
```

Setup पूरा होने के बाद project folder में जाएं और अपना project start करें:

```
npm run dev
```
