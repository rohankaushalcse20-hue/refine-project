## Invoice generator blog example

यह example Refine के साथ invoice generation workflow दिखाता है। इसमें form-driven data entry, preview और business document तैयार करने जैसे user-facing steps शामिल हैं।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example blog-invoice-generator
```
