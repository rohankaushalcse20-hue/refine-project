## MUI-Beispiel fuer `useDeleteMany`

Dieses Beispiel zeigt, wie **Refine** mehrere Datensaetze aus einer MUI-Tabelle loescht. Auswahl, Aktion und Rueckmeldung bleiben in der UI sichtbar, waehrend Refine die Mutation ausfuehrt.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example table-mui-use-delete-many
```

## Wichtige Punkte

- Mehrfachauswahl in MUI-Tabellen nutzen
- `useDeleteMany` fuer Bulk-Loeschaktionen verwenden
- Mutationsstatus und Benachrichtigungen in der UI abbilden
- Befehle, URLs und API-Namen unveraendert lassen
