## MUI Multipart-Upload-Beispiel

Dieses Beispiel zeigt, wie **Refine** Datei-Uploads mit MUI und Multipart-Requests umsetzt. Formularstatus, Upload-Aktion und Resource-Mutation bleiben dabei klar getrennt.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example upload-mui-multipart
```

## Wichtige Punkte

- Datei-Uploads in MUI-Formulare integrieren
- Multipart-Daten an den passenden data provider senden
- Upload-Status und Formularspeicherung koordinieren
- Befehle, URLs und API-Namen unveraendert lassen
