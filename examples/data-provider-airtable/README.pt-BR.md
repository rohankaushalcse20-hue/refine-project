## Exemplo de data provider Airtable

Este exemplo mostra como conectar **refine** ao Airtable por meio de um data provider. Ele demonstra como tratar tabelas do Airtable como resources dentro do fluxo CRUD do refine.

## Testar localmente

```bash
npm create refine-app@latest -- --example data-provider-airtable
```

## Pontos principais

- Configuracao do data provider Airtable.
- Resources conectados a dados externos.
- Listas e mutacoes mantidas no contrato do refine.
- Comandos e links preservados para reproducao.
