## Data provider-Beispiel mit Airtable

Dieses Beispiel zeigt, wie **Refine** Airtable als Backend verwendet. Der data provider verbindet Refine resources mit Airtable-Bases, damit CRUD-Ablaufe klar strukturiert bleiben.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example data-provider-airtable
```

## Wichtige Punkte

- Airtable als data provider konfigurieren
- Records ueber Refine resources lesen und schreiben
- Trennung von UI, resources und Datenzugriff
- Befehle, URLs und technische Namen bleiben unveraendert
