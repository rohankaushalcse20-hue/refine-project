## Ejemplo de data provider con Airtable

Este ejemplo muestra cómo usar **Refine** con Airtable como backend. El data provider conecta los resources de Refine con las bases de Airtable para mantener un flujo CRUD claro.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example data-provider-airtable
```

## Puntos clave

- Configuración de Airtable como data provider
- Lectura y escritura de records desde resources de Refine
- Separación entre UI, resources y acceso a datos
- Comandos, URLs y nombres técnicos conservados sin traducir
