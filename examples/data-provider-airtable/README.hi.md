## Airtable data provider example

यह example दिखाता है कि **Refine** को Airtable से data provider के माध्यम से कैसे जोड़ा जाता है। Airtable tables को Refine के CRUD flow में resources की तरह इस्तेमाल किया जा सकता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example data-provider-airtable
```

## मुख्य बिंदु

- Airtable data provider की configuration
- external data से जुड़े resources
- lists और mutations को Refine contract में रखना
- reproducible setup के लिए commands और links सुरक्षित रखना
