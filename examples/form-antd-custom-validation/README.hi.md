## Ant Design custom validation example

यह example **Refine** और Ant Design forms में custom validation rules लगाना दिखाता है। Form fields को business rules से validate करके save action से पहले user feedback दिया जाता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example form-antd-custom-validation
```

## मुख्य बिंदु

- Ant Design `Form` validation rules के साथ Refine form workflow
- custom field validation और error messages
- save action से पहले invalid input रोकना
- commands, URLs और component names को original example जैसा रखना
