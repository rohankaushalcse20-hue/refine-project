## Exemplo de validação customizada com Ant Design

Este exemplo mostra como aplicar validações customizadas em formulários do **Refine** com Ant Design. As regras de validação ficam próximas dos campos, enquanto o fluxo CRUD continua usando os hooks do Refine.

## Executar localmente

```bash
npm create refine-app@latest -- --example form-antd-custom-validation
```

## Pontos principais

- Regras de validação customizadas em formulários Ant Design
- Integração com hooks de formulário do Refine
- Mensagens e estados de erro no fluxo de edição
- Comandos, URLs e nomes de API preservados como no exemplo original
