## Ejemplo base con Ant Design

Este ejemplo muestra una aplicación mínima de **Refine** con Ant Design. Sirve como punto de partida para construir interfaces CRUD con los componentes, hooks y layouts de `@refinedev/antd`.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example base-antd
```

## Puntos clave

- Configuración base de Refine con Ant Design
- Resources conectados a vistas CRUD
- Uso de componentes de `@refinedev/antd`
- Comandos, URLs y nombres técnicos conservados sin traducir

[Abrir el ejemplo base-antd en CodeSandbox](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/base-antd?view=preview&theme=dark&codemirror=1)
