## Contoh dasar dengan Ant Design

Contoh ini menunjukkan aplikasi **Refine** minimal dengan Ant Design. Ini dapat dipakai sebagai titik awal untuk membuat interface CRUD memakai komponen, hooks, dan layout dari `@refinedev/antd`.

## Menjalankan secara lokal

```bash
npm create refine-app@latest -- --example base-antd
```

## Hal yang perlu diperhatikan

- Konfigurasi dasar Refine dengan Ant Design
- `resources` yang terhubung ke tampilan CRUD
- Penggunaan komponen dari `@refinedev/antd`
- Command, URL, dan nama teknis tetap dipertahankan tanpa diterjemahkan

[Buka contoh base-antd di CodeSandbox](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/base-antd?view=preview&theme=dark&codemirror=1)
