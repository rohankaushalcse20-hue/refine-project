## Ant Design base example

यह example **Refine** और Ant Design के साथ एक basic CRUD application setup दिखाता है। इसमें resource configuration, data fetching और Ant Design based list/create/edit screens का starter pattern शामिल है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example base-antd
```

## मुख्य बिंदु

- Ant Design UI package के साथ Refine starter structure
- resources, routes और CRUD pages की basic wiring
- admin interface के लिए reusable layout pattern
- commands, URLs और package names को original example जैसा रखना
