## Ant Design 기본 예제

이 예제는 **Refine**에서 Ant Design 기반 CRUD 화면을 가장 기본적인 구조로 구성하는 흐름을 보여줍니다. `resources`, routing, `dataProvider` 연결은 유지하면서 목록, 생성, 수정 화면의 기본 동작을 확인할 수 있습니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example base-antd
```

## 확인할 점

- Ant Design 컴포넌트와 Refine resource 구성
- list, create, edit 화면의 기본 CRUD 흐름
- `dataProvider`와 routes 연결
- 명령어, URL, API 이름은 원본 그대로 유지
