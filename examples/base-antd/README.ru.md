## Базовый пример с Ant Design

Этот пример показывает минимальное приложение Refine на **Ant Design**. Он подходит как стартовая точка для проверки ресурсов, layout-компонентов, таблиц и форм перед добавлением аутентификации, кастомной бизнес-логики или собственного data provider.

## Запуск локально

```bash
npm create refine-app@latest -- --example base-antd
```

## Что проверить

- Базовую структуру `Refine`, resources и router provider.
- Отображение Ant Design-страниц списка, создания и редактирования.
- Подключение стилей Ant Design и layout Refine.
- Сохранение импортов, package names и команд без локализации.
