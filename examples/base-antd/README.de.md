## Basisbeispiel mit Ant Design

Dieses Beispiel zeigt eine einfache **Refine**-Anwendung mit Ant Design. Es verbindet Resources, Routing, Datenzugriff und vorgefertigte Ant Design-Komponenten zu einer kompakten CRUD-Oberflaeche.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example base-antd
```

## Wichtige Punkte

- Grundlegende Refine-Provider konfigurieren
- Listen-, Erstellen-, Bearbeiten- und Anzeigen-Seiten mit Ant Design nutzen
- Resource-Namen und Routen strukturiert halten
- Commands, URLs und API-Namen unveraendert uebernehmen
