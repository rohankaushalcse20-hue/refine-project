## Exemplo base com Ant Design

Este exemplo apresenta uma aplicacao **refine** basica usando Ant Design. Ele demonstra a estrutura minima para combinar resources, providers e componentes visuais de Ant Design em um fluxo CRUD.

## Testar localmente

```bash
npm create refine-app@latest -- --example base-antd
```

## Pontos principais

- Setup inicial de uma aplicacao refine.
- Layout e componentes com Ant Design.
- Providers essenciais configurados.
- Base pronta para dashboards e ferramentas internas.
