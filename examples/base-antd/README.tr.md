## Ant Design temel örneği

Bu örnek, Ant Design bileşenleriyle kurulmuş sade bir Refine CRUD uygulamasını gösterir. Kaynak, veri sağlayıcı ve görünüm akışı basit tutulur; böylece Ant Design entegrasyonunun başlangıç yapısı kolayca incelenebilir.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example base-antd
```

## Dikkat edilecek noktalar

- Ant Design tabanlı liste, oluşturma ve düzenleme ekranları
- Refine kaynak tanımlarıyla standart CRUD akışı
- Bileşen ve paket adları özgün teknik adlarıyla korunur
