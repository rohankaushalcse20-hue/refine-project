## Win95 blog example

यह example Refine application को Win95-inspired visual treatment के साथ दिखाता है। इसमें CRUD workflows वही रहते हैं, लेकिन layout और styling nostalgic desktop UI की तरह प्रस्तुत किए जाते हैं।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example blog-win95
```
