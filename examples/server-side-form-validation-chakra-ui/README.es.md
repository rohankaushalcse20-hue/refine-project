## Validación de formularios en servidor con Chakra UI

Este ejemplo muestra cómo reflejar errores de validación del servidor en formularios Chakra UI conectados a las mutaciones de Refine.

## Probar localmente

```bash
npm create refine-app@latest -- --example server-side-form-validation-chakra-ui
```

## Qué revisar

- Integración de errores remotos con componentes Chakra UI.
- Uso de `useForm` para controlar envío y estado.
- Mensajes accesibles para campos invalidos.
- Respuesta del formulario ante fallos de validación.
