## Ejemplo de personalización RTL

Este ejemplo muestra cómo preparar una interfaz Refine para idiomas de derecha a izquierda sin cambiar rutas ni APIs.

## Probar localmente

```bash
npm create refine-app@latest -- --example customization-rtl
```

## Qué revisar

- Configuración de dirección RTL en la interfaz.
- Revisión de layout, menús y componentes de formulario.
- Compatibilidad con estilos de la librería UI usada.
- Preservacion de recursos, rutas y comandos del proyecto.
