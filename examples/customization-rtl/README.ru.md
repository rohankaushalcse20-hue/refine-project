## Пример настройки RTL

Этот пример демонстрирует, как настроить интерфейс Refine для языков с направлением письма справа налево. Он помогает проверить тему, layout, таблицы и формы в RTL-режиме без изменения имен ресурсов или API.

## Запуск локально

```bash
npm create refine-app@latest -- --example customization-rtl
```

## Что проверить

- Переключение направления интерфейса на RTL.
- Поведение layout, меню, таблиц и форм.
- Совместимость выбранной UI-библиотеки с RTL-настройками.
- Сохранение commands, package names и route paths без локализации.
