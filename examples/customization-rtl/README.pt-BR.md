## Exemplo de customização RTL

Este exemplo mostra como preparar uma aplicação **Refine** para layouts right-to-left. Ele é útil para interfaces e idiomas que precisam de direção RTL.

## Executar localmente

```bash
npm create refine-app@latest -- --example customization-rtl
```

## Pontos principais

- Configuração de layout RTL na aplicação
- Ajuste de direção, tema e componentes visuais
- Resources do Refine independentes da direção de escrita
- Comandos, URLs e nomes de API preservados como no exemplo original
