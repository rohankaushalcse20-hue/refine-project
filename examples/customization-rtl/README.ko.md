## RTL Layout 예제

이 예제는 **Refine** 애플리케이션에서 오른쪽에서 왼쪽으로 읽는 UI 방향을 적용하는 방법을 보여줍니다. locale, theme, layout 설정을 함께 확인해 RTL 언어 지원을 준비할 수 있습니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example customization-rtl
```

## 확인할 점

- RTL 방향을 적용하는 theme와 layout 설정
- navigation, form, table이 RTL에서 보이는 방식
- locale별 UI 방향을 분리하는 위치
- 명령어, URL, API 이름은 원본 그대로 유지
