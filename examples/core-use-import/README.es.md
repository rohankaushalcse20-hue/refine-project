## Ejemplo de `useImport`

Este ejemplo muestra cómo usar `useImport` en **Refine** para importar datos desde archivos. El hook ayuda a transformar registros externos y enviarlos al data provider con una experiencia controlada.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example core-use-import
```

## Puntos clave

- Importación de datos con `useImport`
- Mapeo de registros antes de enviarlos al backend
- Integración con resources y data providers de Refine
- Comandos, URLs y nombres técnicos conservados sin traducir
