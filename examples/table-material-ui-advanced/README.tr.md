## Material UI gelişmiş tablo örneği

Bu örnek, Material UI ile gelişmiş tablo ekranı kurulumunu gösterir. Sıralama, filtreleme, sayfalama ve satır eylemleri Refine veri akışıyla birlikte çalışır.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example table-material-ui-advanced
```

## Dikkat edilecek noktalar

- Gelişmiş Material UI tablo düzeni
- Filtreleme, sıralama ve sayfalama davranışları
- Tablo hook'ları ve parametre adları çevrilmeden korunur
