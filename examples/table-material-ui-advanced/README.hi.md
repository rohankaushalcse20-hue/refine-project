## Material UI advanced table example

यह example दिखाता है कि **Refine** और Material UI के साथ advanced table page कैसे बनाया जाता है। इसमें records को browse, filter और manage करने के लिए richer list controls शामिल हैं।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example table-material-ui-advanced
```

## मुख्य बिंदु

- Material UI table controls के साथ Refine list page
- sorting, filtering और pagination जैसे table workflows
- resource actions को table rows से जोड़ना
- command, component names और URLs को original example जैसा रखना
