## Material UI multipart upload example

यह example दिखाता है कि multipart file upload के लिए **Refine** को Material UI के साथ कैसे इस्तेमाल किया जाता है। Upload fields forms और mutations से जुड़ते हैं, और Refine का resource flow बना रहता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example upload-material-ui-multipart
```

## मुख्य बिंदु

- Material UI form में upload field
- multipart upload को mutations से जोड़ना
- resource और data provider flow को सुरक्षित रखना
- example command और link को unchanged रखना
