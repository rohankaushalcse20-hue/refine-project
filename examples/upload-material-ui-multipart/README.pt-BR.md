## Exemplo de upload multipart com Material UI

Este exemplo mostra como usar **refine** com Material UI para enviar arquivos via multipart. Ele demonstra como conectar campos de upload a formularios e mutacoes sem perder o fluxo de resources do refine.

## Testar localmente

```bash
npm create refine-app@latest -- --example upload-material-ui-multipart
```

## Pontos principais

- Campo de upload em formulario Material UI.
- Envio multipart conectado a mutacoes.
- Resource e data provider preservados no fluxo do refine.
- Comando e link do exemplo mantidos.
