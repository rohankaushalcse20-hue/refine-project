## Material UI multipart yükleme örneği

Bu örnek, Material UI formundan multipart dosya yükleme akışını Refine veri işlemleriyle birlikte kullanmayı gösterir. Dosya seçimi, form gönderimi ve API isteği tek akışta ele alınır.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example upload-material-ui-multipart
```

## Dikkat edilecek noktalar

- Multipart dosya yükleme formu
- Material UI alanlarıyla Refine gönderim akışı
- `FormData` ve API adları özgün biçimde korunur

[upload-material-ui-multipart örneğini CodeSandbox'da aç](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/upload-material-ui-multipart?view=preview&theme=dark&codemirror=1)
