## Ejemplo de upload multipart con Material UI

Este ejemplo muestra cómo implementar carga de archivos multipart con **Refine** y Material UI. La interfaz conserva los componentes visuales de Material UI y envía los datos mediante el flujo de Refine.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example upload-material-ui-multipart
```

## Puntos clave

- Carga de archivos con multipart form data
- Campos y layout construidos con Material UI
- Integración del submit con data provider y mutations
- Comandos, URLs y nombres técnicos preservados
