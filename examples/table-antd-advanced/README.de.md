## Erweitertes Tabellenbeispiel mit Ant Design

Dieses Beispiel zeigt, wie **Refine** und Ant Design komplexere Tabellenansichten aufbauen. Listenlogik, Filter, Sortierung und Pagination werden ueber Refine gesteuert und in Ant Design-Komponenten dargestellt.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example table-antd-advanced
```

## Wichtige Punkte

- Tabellenzustand mit Refine-Hooks verwalten
- Filter, Sortierung und Pagination in Ant Design anzeigen
- Datenprovider und UI-Komponenten getrennt halten
- Commands, URLs und API-Namen unveraendert lassen
