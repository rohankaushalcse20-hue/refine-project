## Exemplo avancado de tabela com Ant Design

Este exemplo mostra como usar **refine** com Ant Design para construir uma tabela CRUD com recursos avancados. O refine fornece os dados e o estado da tabela, enquanto Ant Design renderiza a interface de listagem.

## Testar localmente

```bash
npm create refine-app@latest -- --example table-antd-advanced
```

## Pontos principais

- Uso de tabela Ant Design com dados do refine.
- Ordenacao, filtros e paginacao conectados ao provider.
- Acoes CRUD integradas a cada linha.
- Comandos, URLs e APIs preservados no codigo.
