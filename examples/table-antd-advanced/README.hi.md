## Ant Design advanced table example

यह example **Refine** और Ant Design में advanced table screen बनाना दिखाता है। Table को sorting, filtering, pagination और row actions के साथ resource data से जोड़ा गया है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example table-antd-advanced
```

## मुख्य बिंदु

- Ant Design `Table` के साथ Refine table hooks
- sorting, filters और pagination का coordinated state
- row-level edit/show/delete actions
- commands, URLs और component names को original example जैसा रखना
