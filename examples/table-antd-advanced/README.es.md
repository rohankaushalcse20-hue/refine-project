## Ejemplo avanzado de tabla con Ant Design

Este ejemplo muestra cómo construir una tabla avanzada con **Refine** y Ant Design. Incluye patrones útiles para listar resources con controles de tabla más completos.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example table-antd-advanced
```

## Puntos clave

- Tabla Ant Design conectada a datos de Refine
- Listados con estado, filtros y ordenación
- Base para paneles administrativos con muchas filas
- Comandos, URLs y nombres técnicos conservados sin traducir
