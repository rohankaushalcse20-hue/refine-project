## Ejemplo de formulario por pasos con Ant Design

Este ejemplo muestra cómo usar `useStepsForm` de **Refine** con Ant Design para dividir formularios largos en pasos. El hook coordina el progreso, la validación y el envío final.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example form-antd-use-steps-form
```

## Puntos clave

- Formularios multipaso con `useStepsForm`
- Validación y navegación entre pasos
- Flujo de creación o edición más guiado
- Comandos, URLs y nombres de API conservados como en el ejemplo original
