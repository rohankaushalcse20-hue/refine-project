## Exemplo de `useStepsForm` com Ant Design

Este exemplo mostra como criar formulários em etapas com **Refine** e Ant Design. O hook `useStepsForm` gerencia navegação, validação e envio entre as etapas.

## Executar localmente

```bash
npm create refine-app@latest -- --example form-antd-use-steps-form
```

## Pontos principais

- Formulários multi-step com `useStepsForm`
- Controle de etapa atual e validação por etapa
- Integração com create e edit pages do Refine
- Comandos, URLs e nomes de API preservados como no exemplo original
