## MUI Theme-Demo

Dieses Beispiel zeigt, wie **Refine** mit einem MUI Theme angepasst wird. Farben, Typografie und Komponentenstil koennen zentral gesteuert werden, ohne die Refine-Resources zu veraendern.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example theme-mui-demo
```

## Wichtige Punkte

- MUI Theme-Konfiguration in einer Refine-App verwenden
- Visuelle Tokens zentral pflegen
- Styling von Datenlogik und Resources trennen
- Befehle, URLs und API-Namen unveraendert lassen
