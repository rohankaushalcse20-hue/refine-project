## Issue tracker blog example

यह example enterprise web applications के लिए issue tracking workflow दिखाता है। Refine repetitive CRUD tasks को कम करता है और authentication, access control, routing, networking, state management और i18n जैसे project concerns के लिए standard structure देता है।

## About

[refine](https://refine.dev/) **headless by design** है, इसलिए styling और customization पर पूरा control रहता है। Convenience के लिए यह [Ant Design](https://ant.design/), [Material UI](https://mui.com/material-ui/getting-started/overview/), [Mantine](https://mantine.dev/) और [Chakra UI](https://chakra-ui.com/) integrations भी देता है।
