## Exemplo de mutation mode com Ant Design

Este exemplo mostra como usar diferentes modos de mutation em formulários do **Refine** com Ant Design. Ele ajuda a comparar fluxos pessimistic, optimistic e undoable.

## Executar localmente

```bash
npm create refine-app@latest -- --example form-antd-mutation-mode
```

## Pontos principais

- Uso de `mutationMode` em formulários
- Comparação entre pessimistic, optimistic e undoable
- Feedback de atualização para o usuário
- Comandos, URLs e nomes de API preservados como no exemplo original
