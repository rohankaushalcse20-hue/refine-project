## Ant Design mutation mode example

यह example **Refine** और Ant Design forms में mutation mode behavior दिखाता है। Form submissions को pessimistic, optimistic या undoable flows के हिसाब से चलाया जा सकता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example form-antd-mutation-mode
```

## मुख्य बिंदु

- Ant Design form के साथ Refine `mutationMode`
- optimistic और undoable updates का user experience
- create/edit submissions में mutation behavior बदलना
- commands, URLs और API names को original example जैसा रखना
