## MUI Theme-Anpassungsbeispiel

Dieses Beispiel zeigt, wie **Refine** und MUI gemeinsam fuer ein angepasstes Theme eingerichtet werden. Die Oberflaeche wird visuell angepasst, waehrend Resource- und Routing-Konfiguration stabil bleiben.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example customization-theme-mui
```

## Wichtige Punkte

- MUI Theme-Provider in Refine integrieren
- Farben und Komponentenvarianten zentral anpassen
- Layout und CRUD-Logik voneinander getrennt halten
- Befehle, URLs und API-Namen unveraendert lassen
