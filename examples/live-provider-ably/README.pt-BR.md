## Exemplo de live provider com Ably

Este exemplo mostra como usar **refine** com Ably para recursos em tempo real. O live provider permite que listas e detalhes reajam a eventos sem perder a estrutura de resources e providers do refine.

## Testar localmente

```bash
npm create refine-app@latest -- --example live-provider-ably
```

## Pontos principais

- Configuracao de `liveProvider`.
- Eventos em tempo real com Ably.
- Resources conectados ao fluxo de atualizacao do refine.
- Comandos e links mantidos como no exemplo original.
