## Live provider-Beispiel mit Ably

Dieses Beispiel zeigt, wie **Refine** mit Ably Echtzeit-Updates verarbeitet. Der live provider verbindet Refine resources mit realtime events, damit Listen und Detailansichten aktuelle Daten anzeigen koennen.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example live-provider-ably
```

## Wichtige Punkte

- Ably als live provider fuer Refine
- Realtime events fuer resources und CRUD-Ansichten
- Live-Updates getrennt von UI-Komponenten halten
- Befehle, URLs und API-Namen bleiben unveraendert
