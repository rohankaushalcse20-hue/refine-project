## Ejemplo de live provider con Ably

Este ejemplo muestra cómo usar **Refine** con Ably para recibir eventos en tiempo real. El live provider permite que las vistas reaccionen a cambios de datos sin abandonar los patrones de Refine.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example live-provider-ably
```

## Puntos clave

- Configuración de Ably como `liveProvider`
- Actualizaciones en tiempo real para resources
- Sincronización de eventos con listados y detalles
- Comandos, URLs y nombres de API conservados
