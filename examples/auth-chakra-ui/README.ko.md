## Chakra UI 인증 예제

이 예제는 **Refine** 인증 흐름을 Chakra UI 화면과 함께 구성하는 방법을 보여줍니다. `authProvider`를 통해 로그인, 로그아웃, 보호된 resource 접근을 다룹니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example auth-chakra-ui
```

## 핵심 포인트

- `authProvider`를 사용한 인증 상태 관리
- Chakra UI로 로그인 화면 구성
- 보호된 routes와 resources 흐름 확인
- 원본 명령어, URL, API 이름 유지

[CodeSandbox에서 auth-chakra-ui 예제 열기](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/auth-chakra-ui?view=preview&theme=dark&codemirror=1)
