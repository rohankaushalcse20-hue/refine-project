## Exemplo de autenticacao com Chakra UI

Este exemplo mostra como usar **refine** com Chakra UI para criar telas de autenticacao em uma aplicacao CRUD. O refine gerencia login, logout e rotas protegidas, enquanto Chakra UI fornece os componentes visuais.

## Testar localmente

```bash
npm create refine-app@latest -- --example auth-chakra-ui
```

## Pontos principais

- Uso de `authProvider` com componentes Chakra UI.
- Fluxos de login e logout conectados ao refine.
- Protecao de paginas internas da aplicacao.
- Comandos, URLs e APIs preservados no codigo.
