## Пример кастомного footer

Этот пример показывает, как заменить или расширить footer в layout Refine. Он полезен, когда приложению нужны собственные ссылки, служебная информация, версия продукта или элементы навигации в нижней части интерфейса.

## Запуск локально

```bash
npm create refine-app@latest -- --example customization-footer
```

## Что проверить

- Место подключения пользовательского footer-компонента.
- Сохранение стандартного layout и навигации Refine.
- Поведение footer на разных страницах ресурсов.
- Неизменность component names, imports и commands.
