## Ejemplo de footer personalizado

Este ejemplo muestra cómo personalizar el footer de una aplicación Refine manteniendo el layout y la navegación existentes.

## Probar localmente

```bash
npm create refine-app@latest -- --example customization-footer
```

## Qué revisar

- Ubicacion del footer dentro del layout.
- Contenido visible al pie de la aplicación.
- Compatibilidad con páginas y resources existentes.
- Separación entre personalización visual y lógica de datos.
