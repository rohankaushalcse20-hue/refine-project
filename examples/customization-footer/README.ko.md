## Custom Footer 예제

이 예제는 **Refine** layout 안에서 footer 영역을 프로젝트 요구사항에 맞게 교체하는 방법을 보여줍니다. 기본 navigation과 resource 흐름은 유지하면서 하단 UI만 커스터마이징합니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example customization-footer
```

## 확인할 점

- 기본 layout에 custom footer를 연결하는 방식
- resource 화면과 footer UI의 공존
- provider, routes, commands는 원본 구조 유지
- footer 텍스트와 링크를 프로젝트에 맞게 바꾸는 위치
