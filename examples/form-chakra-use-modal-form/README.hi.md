## Chakra UI useModalForm example

यह example दिखाता है कि **Refine** और Chakra UI के साथ modal form workflow कैसे बनाया जाता है। इसमें `useModalForm` hook modal lifecycle, form state और submit mutation को साथ संभालता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example form-chakra-use-modal-form
```

## मुख्य बिंदु

- Chakra UI modal में create/edit form दिखाना
- `useModalForm` से open, close और submit behavior नियंत्रित करना
- list page से modal workflow शुरू करना
- command, hook names और CodeSandbox URL को original example जैसा रखना
