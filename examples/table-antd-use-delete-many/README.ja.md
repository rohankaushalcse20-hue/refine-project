## Ant Design の一括削除テーブル

この例では、Ant Design のテーブルで **refine** の一括削除操作を扱う方法を示します。複数レコードを選択して削除する管理画面の基本フローを確認できます。

## ローカルで試す

```bash
npm create refine-app@latest -- --example table-antd-use-delete-many
```

## 主なポイント

- Ant Design のテーブルで複数行を選択します。
- refine の削除処理を一括操作に接続します。
- 管理画面でよく使う bulk action の参考になります。
- CodeSandbox のリンクは元の例を保持しています。
