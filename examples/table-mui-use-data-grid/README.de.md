## MUI Data Grid-Beispiel

Dieses Beispiel zeigt, wie **Refine** `useDataGrid` mit MUI X Data Grid verbindet. Refine liefert Daten, Pagination und Sortierung, waehrend Data Grid die interaktive Tabellenansicht bereitstellt.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example table-mui-use-data-grid
```

## Wichtige Punkte

- `useDataGrid` fuer MUI Data Grid konfigurieren
- Servergesteuerte Tabellenparameter an Refine anbinden
- Data Grid-Spalten und Refine resources klar trennen
- Befehle, URLs und API-Namen unveraendert lassen
