## قالب Material UI

يوفر هذا القالب نقطة بداية جاهزة تجمع بين **Refine** وMaterial UI، وهو مناسب للانطلاق في admin panels وdashboards وinternal tools من دون بناء الهيكل الأساسي من الصفر.

## التشغيل محلياً

```bash
npm create refine-app@latest -- --example template-material-ui
```

## ماذا يتضمن؟

- دمج أساسي بين Refine وMaterial UI
- هيكل أولي لـ resources وصفحات CRUD
- قاعدة قابلة للتوسعة من أجل auth وpermissions وnotifications وi18n

بعد إنشاء المشروع يمكنك توصيل data provider وتعريف الـ resources الرئيسية في التطبيق.
