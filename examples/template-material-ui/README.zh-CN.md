## Material UI 模板

这个 template 提供了把 **Refine** 与 Material UI 组合在一起的起步应用，适合作为管理后台、仪表盘和内部工具的基础项目。

## 本地运行

```bash
npm create refine-app@latest -- --example template-material-ui
```

## 包含内容

- Refine 与 Material UI 的集成基础
- resources 与 CRUD pages 的初始结构
- 便于后续接入 auth、permissions、notifications 与 i18n 的项目骨架

完成 scaffold 后，可以继续配置 data provider，并定义应用中的主要 resources。
