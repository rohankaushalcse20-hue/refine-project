## Material UI 템플릿

이 template은 **Refine**와 Material UI를 결합한 스타터 애플리케이션을 제공합니다. 접근 가능하고 커스터마이즈하기 쉬운 components가 필요한 관리자 패널, 대시보드, 내부 도구의 출발점으로 적합합니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example template-material-ui
```

## 포함된 내용

- Refine와 Material UI 통합
- resources와 CRUD pages의 초기 구조
- auth, permissions, notifications, i18n을 추가하기 쉬운 기반

scaffold 후에는 data provider를 설정하고 애플리케이션의 주요 resources를 정의하세요.
