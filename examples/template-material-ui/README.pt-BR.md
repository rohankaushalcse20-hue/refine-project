## Template Material UI

Este template inicia uma aplicação **Refine** com Material UI. Ele é uma base prática para painéis administrativos, dashboards e ferramentas internas que precisam de componentes acessíveis e fáceis de personalizar.

## Testar localmente

```bash
npm create refine-app@latest -- --example template-material-ui
```

## Inclui

- Integração do Refine com Material UI.
- Estrutura inicial para resources e páginas CRUD.
- Um ponto de partida para autenticação, permissões, notificações e i18n.

Depois do scaffolding, configure seu data provider e defina os resources centrais da aplicação.
