# Template Refine Material UI

Template นี้แสดงวิธีเริ่มแอป Refine ด้วย Material UI โดยรวมการตั้งค่า `resources`, data provider, routing และ component ของ MUI สำหรับหน้าจอ CRUD ทั่วไป

## จุดสำคัญ

- ใช้ integration ของ Refine กับ Material UI
- มีโครงสร้างโปรเจกต์ที่พร้อมต่อยอดสำหรับ `list`, `create`, `edit` และ `show`
- คง package name, import, command และ API ในรูปเดิม
- เหมาะเป็นฐานสำหรับ admin panel หรือ internal tool

## รัน template

```sh
npm install
npm run dev
```

## ใช้เมื่อใด?

เลือก template นี้เมื่อคุณต้องการสร้างแอป CRUD ด้วย component ของ Material UI อย่างรวดเร็ว แต่ยังคงสถาปัตยกรรม providers และ hooks ของ Refine
