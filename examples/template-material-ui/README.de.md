## Material-UI-Template

Dieses Template startet eine **Refine**-Anwendung mit Material UI. Es ist eine praktische Grundlage fuer Admin-Panels, Dashboards und interne Tools, die zugaengliche und anpassbare Komponenten brauchen.

## Lokal testen

```bash
npm create refine-app@latest -- --example template-material-ui
```

## Enthalten

- Refine-Integration mit Material UI.
- Eine startklare Struktur fuer Resources und CRUD-Seiten.
- Ein Ausgangspunkt fuer Authentifizierung, Berechtigungen, Benachrichtigungen und i18n.

Nach dem Scaffolding richtest du deinen Data Provider ein und definierst die zentralen Resources deiner Anwendung.
