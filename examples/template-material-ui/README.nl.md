# Refine Material UI template voorbeeld

Deze template biedt een compacte basis voor ontwikkelaars die een Refine-applicatie met Material UI willen starten. CRUD-pagina's, layout en providerkoppelingen zijn zo georganiseerd dat je ze kunt aanpassen aan een echt project.

## Belangrijkste punten

- Toont de Refine resource-structuur met Material UI-componenten.
- Gebruikt `resources`, routing en data provider configuratie samen.
- Biedt een eerste skelet voor admin panels of interne tools.

## Uitvoeren

```sh
npm install
npm run dev
```

Deze Nederlandse README licht het doel van het voorbeeld toe; commands en package names blijven ongewijzigd voor consistentie met het project.
