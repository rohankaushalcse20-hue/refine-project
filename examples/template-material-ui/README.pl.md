# Szablon Refine Material UI

Ten szablon pokazuje, jak rozpocząć aplikację Refine z Material UI. Łączy konfigurację `resources`, data provider, routing i gotowe komponenty MUI dla typowych widoków CRUD.

## Najważniejsze punkty

- Używa integracji Refine z Material UI.
- Pokazuje strukturę projektu gotową do rozbudowy o list, create, edit i show.
- Zachowuje nazwy pakietów, importy, komendy i API bez tłumaczenia.
- Nadaje się jako baza dla panelu administracyjnego albo narzędzia wewnętrznego.

## Uruchomienie

```sh
npm install
npm run dev
```

## Kiedy używać?

Wybierz ten szablon, gdy chcesz szybko zbudować aplikację CRUD z komponentami Material UI, ale zachować architekturę providerów i hooków Refine.
