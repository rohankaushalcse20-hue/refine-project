# Template Refine Material UI

Template này cho thấy cách bắt đầu một ứng dụng Refine với Material UI. Nó kết hợp cấu hình `resources`, data provider, routing và các component MUI có sẵn cho những view CRUD phổ biến.

## Điểm chính

- Dùng tích hợp Refine với Material UI.
- Thể hiện cấu trúc dự án sẵn sàng mở rộng cho list, create, edit và show.
- Giữ nguyên tên package, imports, commands và API.
- Phù hợp làm nền tảng cho admin panel hoặc công cụ nội bộ.

## Chạy thử

```sh
npm install
npm run dev
```

## Khi nào nên dùng?

Chọn template này khi bạn muốn xây dựng nhanh ứng dụng CRUD với component Material UI, nhưng vẫn giữ kiến trúc providers và hooks của Refine.
