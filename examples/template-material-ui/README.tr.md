## Material UI Template

Bu template, **Refine** ve Material UI'ı bir araya getiren kullanıma hazır bir başlangıç noktası sunar. Admin panels, dashboards ve internal tools geliştirmeye sıfırdan temel yapı kurmadan başlamak için uygundur.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example template-material-ui
```

## Neler içerir?

- Refine ile Material UI arasında temel entegrasyon
- Resources ve CRUD sayfaları için başlangıç yapısı
- Auth, permissions, notifications ve i18n ile genişletilebilir bir temel

Proje oluşturulduktan sonra data provider bağlayabilir ve uygulamanın ana resources yapılarını tanımlayabilirsiniz.
