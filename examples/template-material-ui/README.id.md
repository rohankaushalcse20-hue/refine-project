## Template Material UI

Template ini memberi titik awal siap pakai yang menggabungkan **Refine** dan Material UI. Template ini cocok untuk memulai admin panels, dashboards, dan internal tools tanpa membangun struktur dasar dari nol.

## Menjalankan secara lokal

```bash
npm create refine-app@latest -- --example template-material-ui
```

## Apa yang disertakan?

- Integrasi dasar antara Refine dan Material UI
- Struktur awal untuk resources dan halaman CRUD
- Fondasi yang dapat diperluas untuk auth, permissions, notifications, dan i18n

Setelah proyek dibuat, Anda dapat menghubungkan data provider dan mendefinisikan resources utama aplikasi.
