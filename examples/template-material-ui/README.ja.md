## Material UI テンプレート

この template は、**Refine** と Material UI を組み合わせたスターターアプリケーションを用意します。アクセシブルでカスタマイズしやすい components が必要な管理画面、ダッシュボード、社内ツールの出発点として適しています。

## ローカルで実行する

```bash
npm create refine-app@latest -- --example template-material-ui
```

## 含まれるもの

- Refine と Material UI の統合
- resources と CRUD pages の初期構成
- auth、permissions、notifications、i18n を追加しやすい土台

scaffold 後に data provider を設定し、アプリケーションの主要 resources を定義してください。
