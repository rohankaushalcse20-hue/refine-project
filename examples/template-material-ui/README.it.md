# Esempio template Refine Material UI

Questo template offre una base essenziale per sviluppatori che vogliono avviare un'applicazione Refine con Material UI. Pagine CRUD, layout e collegamenti provider sono organizzati in modo da poter essere adattati a un progetto reale.

## Punti principali

- Mostra la struttura resource di Refine con componenti Material UI.
- Usa insieme `resources`, routing e configurazione data provider.
- Offre uno scheletro iniziale per pannelli admin o strumenti interni.

## Esecuzione

```sh
npm install
npm run dev
```

Questo README italiano spiega lo scopo dell'esempio; comandi e package name restano invariati per coerenza con il progetto.
