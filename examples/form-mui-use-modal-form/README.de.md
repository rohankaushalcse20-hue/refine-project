## MUI Modal-Formularbeispiel

Dieses Beispiel zeigt, wie **Refine** Formulare in einem MUI Modal verwaltet. Die Modallogik bleibt mit Refine-Formularstatus, Submit-Aktionen und Resource-Routing abgestimmt.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example form-mui-use-modal-form
```

## Wichtige Punkte

- Modal-basierte Formulare fuer Create und Edit einsetzen
- MUI Modal-Zustand mit Refine-Hooks synchronisieren
- Speichern, Schliessen und Aktualisieren der Liste koordinieren
- Befehle, URLs und API-Namen unveraendert lassen
