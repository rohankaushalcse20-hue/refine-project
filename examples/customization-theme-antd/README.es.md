## Ejemplo de tema personalizado con Ant Design

Este ejemplo muestra cómo ajustar el tema visual de Ant Design en una aplicación Refine sin modificar la lógica de recursos.

## Probar localmente

```bash
npm create refine-app@latest -- --example customization-theme-antd
```

## Qué revisar

- Configuración de tokens de Ant Design.
- Aplicacion del tema alrededor de Refine.
- Revisión de colores, componentes y estados interactivos.
- Compatibilidad con pantallas create, edit, list y show.
