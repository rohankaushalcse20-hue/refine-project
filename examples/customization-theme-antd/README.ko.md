## Ant Design Theme 커스터마이징 예제

이 예제는 **Refine**와 Ant Design을 사용할 때 theme token과 스타일을 프로젝트에 맞게 조정하는 방법을 보여줍니다. CRUD 화면 구조는 유지하면서 색상, 컴포넌트 기본값, layout 분위기를 바꿀 수 있습니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example customization-theme-antd
```

## 확인할 점

- Ant Design theme 설정 위치
- Refine resource 화면에 theme가 적용되는 방식
- layout과 component 스타일의 분리
- 명령어, URL, API 이름은 원본 그대로 유지
