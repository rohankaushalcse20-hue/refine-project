## Contoh kustomisasi theme Ant Design

Contoh ini menunjukkan cara menyesuaikan theme Ant Design di aplikasi **Refine**. Token dan konfigurasi theme dapat diubah tanpa mengganggu resource, provider, atau route yang sudah mengikuti pola Refine.

## Menjalankan secara lokal

```bash
npm create refine-app@latest -- --example customization-theme-antd
```

## Hal yang perlu diperhatikan

- Kustomisasi theme untuk komponen Ant Design
- Struktur aplikasi Refine tetap tidak berubah
- Cocok sebagai dasar branding untuk dashboard CRUD
- Command, URL, dan nama teknis tetap dipertahankan tanpa diterjemahkan
