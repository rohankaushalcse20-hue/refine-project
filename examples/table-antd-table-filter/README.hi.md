## Ant Design table filter example

यह example **Refine** और Ant Design tables में filter controls जोड़ना दिखाता है। Column filters को Refine table state से जोड़कर users resource records को जल्दी narrow कर सकते हैं।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example table-antd-table-filter
```

## मुख्य बिंदु

- Ant Design `Table` filters और Refine query state
- column-level filtering के लिए reusable controls
- filtered list results को backend query से sync करना
- commands, URLs और component names को original example जैसा रखना
