## Exemplo de filtros em tabela com Ant Design

Este exemplo mostra como aplicar filtros em tabelas do **Refine** com Ant Design. A tabela envia os filtros para o `dataProvider`, mantendo a listagem sincronizada com os parâmetros da interface.

## Executar localmente

```bash
npm create refine-app@latest -- --example table-antd-table-filter
```

## Pontos principais

- Filtros em `Table` do Ant Design
- Sincronização dos filtros com list pages do Refine
- Consultas filtradas via `dataProvider`
- Comandos, URLs e nomes de API preservados como no exemplo original
