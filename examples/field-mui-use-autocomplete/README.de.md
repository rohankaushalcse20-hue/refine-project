## MUI Autocomplete-Beispiel

Dieses Beispiel zeigt, wie **Refine** Auswahlfelder mit MUI Autocomplete verbindet. Optionen koennen ueber Refine geladen und in Formularen oder Filtern komfortabel ausgewaehlt werden.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example field-mui-use-autocomplete
```

## Wichtige Punkte

- MUI Autocomplete mit Refine-Datenquellen verwenden
- Optionslisten aus resources laden
- Auswahlwerte in Formularen und Filtern stabil halten
- Befehle, URLs und API-Namen unveraendert lassen
