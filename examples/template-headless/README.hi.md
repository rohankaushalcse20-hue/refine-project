## Getting Started

**refine** data-intensive applications को कम समय में बनाने के लिए React-आधारित framework है ✨

Refine तेज development के लिए बहुत सी out-of-the-box functionality देता है, और extreme customizability से समझौता नहीं करता। इसके use-cases में admin panels, B2B applications और dashboards शामिल हैं।

## Available Scripts

### Development server चलाना।

```bash
npm run dev
```

### Production के लिए build बनाना।

```bash
npm run build
```

### Production server चलाना।

```bash
npm run dev
```
