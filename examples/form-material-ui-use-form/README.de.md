## Formularbeispiel mit Material UI und `useForm`

Dieses Beispiel zeigt, wie **Refine** mit Material UI ein CRUD-Formular erstellt. `useForm` verwaltet Datenbindung, Validierung und submit flow, waehrend Material UI die Eingabeelemente liefert.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example form-material-ui-use-form
```

## Wichtige Punkte

- `useForm` fuer create- und edit-Formulare
- Material UI-Komponenten fuer Felder und Layout
- Mutation flow ueber den data provider
- Befehle, URLs und API-Namen bleiben unveraendert
