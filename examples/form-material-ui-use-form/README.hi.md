## Material UI form example

यह example दिखाता है कि CRUD forms बनाने के लिए **Refine** को Material UI के साथ कैसे इस्तेमाल किया जाता है। Refine resource और mutation flow संभालता है, जबकि Material UI fields और visual experience देता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example form-material-ui-use-form
```

## मुख्य बिंदु

- Refine flow में `useForm` का उपयोग
- Material UI के साथ fields और layout
- submission को data provider से जोड़ना
- commands, URLs और APIs को सुरक्षित रखना
