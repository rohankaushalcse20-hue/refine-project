## Exemplo de formulario com Material UI

Este exemplo mostra como usar **refine** com Material UI para construir formularios de CRUD. O refine coordena o resource e a mutacao, enquanto Material UI fornece os campos e a experiencia visual.

## Testar localmente

```bash
npm create refine-app@latest -- --example form-material-ui-use-form
```

## Pontos principais

- Uso de `useForm` no fluxo do refine.
- Campos e layout com Material UI.
- Submissao conectada ao data provider.
- Comandos, URLs e APIs preservados.
