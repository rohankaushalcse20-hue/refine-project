## Material UI `useForm` 예제

이 예제는 **Refine**의 `useForm` 흐름을 Material UI 입력 컴포넌트와 연결하는 방법을 보여줍니다. 관리 화면에서 생성과 수정 form을 일관된 UI로 구성합니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example form-material-ui-use-form
```

## 핵심 포인트

- Material UI form 컴포넌트와 Refine 통합
- resource mutation과 submit 상태 연결
- create와 edit 페이지에서 재사용 가능한 form 패턴
- 원본 명령어, URL, API 이름 유지
