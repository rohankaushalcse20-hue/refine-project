## Material UI `useForm` örneği

Bu örnek, Material UI formlarında Refine `useForm` hook'unun nasıl kullanılacağını gösterir. Form durumu, gönderim ve hata yönetimi Refine tarafından sağlanan yardımcılarla bağlanır.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example form-material-ui-use-form
```

## Dikkat edilecek noktalar

- Material UI form alanlarıyla `useForm` kullanımı
- Oluşturma ve düzenleme ekranlarında kayıt gönderimi
- Hook ve prop adları çevrilmeden korunur
