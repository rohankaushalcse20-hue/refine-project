## Ejemplo de formulario con Material UI

Este ejemplo muestra cómo usar **Refine** con Material UI para crear formularios CRUD. Refine gestiona el resource y la mutation, mientras Material UI aporta campos y layout.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example form-material-ui-use-form
```

## Puntos clave

- Uso de `useForm` dentro del flujo de Refine
- Campos y layout construidos con Material UI
- Conexión del submit con el data provider
- Comandos, URLs y nombres de API preservados
