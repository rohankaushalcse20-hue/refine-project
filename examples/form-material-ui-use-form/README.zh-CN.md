## Material UI `useForm` 表单示例

这个示例展示如何在 Material UI 界面中使用 **Refine** 的 `useForm`。它把资源变更、表单状态和 UI 组件组合成一个标准的创建或编辑流程。

## 本地运行

```bash
npm create refine-app@latest -- --example form-material-ui-use-form
```

## 建议关注

- `useForm` 返回值如何传给 Material UI 表单控件
- 提交、加载和错误状态的显示方式
- 表单页面如何与 Refine resources 对齐
- 原始命令、URL 和 API 名称保持不变
