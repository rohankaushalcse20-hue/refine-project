## Пример формы с Material UI

Этот пример показывает, как построить CRUD-форму **Refine** на компонентах **Material UI**. `useForm` управляет сохранением записи, а Material UI формирует пользовательский интерфейс полей.

## Запуск локально

```bash
npm create refine-app@latest -- --example form-material-ui-use-form
```

## Что проверить

- Связь `useForm` с input-компонентами Material UI.
- Отправку create и edit запросов.
- Отображение ошибок и loading state.
- Сохранение prop names, hook names и CLI command без перевода.
