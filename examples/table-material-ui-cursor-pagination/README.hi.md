## Material UI cursor pagination table example

यह example दिखाता है कि **Refine** और Material UI के साथ cursor based pagination कैसे इस्तेमाल की जाती है। यह उन APIs के लिए उपयोगी है जहां next और previous cursors से page navigation किया जाता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example table-material-ui-cursor-pagination
```

## मुख्य बिंदु

- Material UI table में cursor pagination controls
- cursor based APIs के साथ list queries चलाना
- next और previous page states को UI से जोड़ना
- command, API names और CodeSandbox URL को original example जैसा रखना
