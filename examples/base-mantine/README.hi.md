## Mantine base example

यह example **Refine** और Mantine UI के साथ एक basic admin application बनाना दिखाता है। Resources, routes और CRUD pages Mantine components के साथ configured हैं।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example base-mantine
```

## मुख्य बिंदु

- Mantine UI package के साथ Refine starter setup
- resource definitions से generated navigation और pages
- list/create/edit screens के लिए common admin pattern
- commands और package names को original example जैसा रखना
