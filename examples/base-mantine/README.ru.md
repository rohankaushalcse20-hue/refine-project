## Базовый пример с Mantine

Этот пример демонстрирует минимальное приложение Refine на **Mantine**. Он подходит для проверки CRUD-страниц, layout и базовой навигации перед подключением дополнительных провайдеров или расширенной логики.

## Запуск локально

```bash
npm create refine-app@latest -- --example base-mantine
```

## Что проверить

- Инициализацию `Refine` и список resources.
- Работу Mantine-компонентов в стандартных CRUD-экранах.
- Подключение темы, layout и навигации.
- Неизменность package names, imports и route identifiers.
