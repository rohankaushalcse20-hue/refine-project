## Exemplo base com Mantine

Este exemplo mostra uma aplicacao **refine** inicial usando Mantine. Ele combina a configuracao padrao do refine com componentes Mantine para criar uma base de CRUD pronta para evoluir.

## Testar localmente

```bash
npm create refine-app@latest -- --example base-mantine
```

## Pontos principais

- Estrutura inicial de resources e providers.
- Integracao com Mantine para layout e componentes.
- Base simples para novas telas CRUD.
- Comandos, URLs e APIs preservados no codigo.
