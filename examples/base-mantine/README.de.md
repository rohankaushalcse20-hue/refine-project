## Basisbeispiel mit Mantine

Dieses Beispiel zeigt eine einfache **Refine**-Anwendung mit Mantine. Es kombiniert Refine-Resources und Datenprovider mit Mantine-Komponenten fuer Seiten, Formulare und Navigation.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example base-mantine
```

## Wichtige Punkte

- Mantine als UI-Schicht fuer Refine verwenden
- Standardseiten fuer CRUD-Workflows einrichten
- Datenlogik und UI-Komponenten getrennt halten
- Commands, URLs und API-Namen unveraendert uebernehmen
