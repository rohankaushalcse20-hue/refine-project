## Mantine temel örneği

Bu örnek, Mantine bileşenleriyle hazırlanmış başlangıç seviyesinde bir Refine CRUD uygulamasını gösterir. Mantine düzeni, Refine kaynakları ve veri işlemleri birlikte kullanılacak şekilde yapılandırılmıştır.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example base-mantine
```

## Dikkat edilecek noktalar

- Mantine tabanlı temel uygulama kabuğu
- CRUD ekranlarının Refine kaynaklarıyla eşleşmesi
- Kod içindeki paket ve bileşen adları çevrilmez
