## Contoh dasar dengan Mantine

Contoh ini menunjukkan aplikasi **Refine** minimal dengan Mantine. Ini menyediakan fondasi CRUD yang memakai komponen Mantine, sambil mempertahankan pola `resources`, routing, dan data hooks dari Refine.

## Menjalankan secara lokal

```bash
npm create refine-app@latest -- --example base-mantine
```

## Hal yang perlu diperhatikan

- Integrasi Refine dengan komponen Mantine
- Layout awal untuk halaman CRUD
- Resource dan data provider tetap mengikuti struktur Refine
- Command, URL, dan nama teknis tetap dipertahankan tanpa diterjemahkan
