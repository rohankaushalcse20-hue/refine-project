## Ejemplo base con Mantine

Este ejemplo muestra una aplicación mínima de **Refine** con Mantine. Ofrece una base para construir paneles CRUD usando los hooks de Refine junto con los componentes y estilos de Mantine.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example base-mantine
```

## Puntos clave

- Configuración inicial de Refine con Mantine
- Resources conectados a páginas CRUD
- Integración con componentes de `@refinedev/mantine`
- Comandos, URLs y nombres de API conservados como en el ejemplo original
