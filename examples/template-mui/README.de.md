## MUI-Template-Beispiel

Dieses Beispiel zeigt ein startbares **Refine**-Template mit MUI. Es eignet sich als Ausgangspunkt fuer CRUD-Anwendungen, die Refine-Logik mit einer MUI-Oberflaeche verbinden.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example template-mui
```

## Wichtige Punkte

- Projektstruktur eines MUI-basierten Refine-Templates pruefen
- Resource-Seiten und Layout als Startpunkt verwenden
- Template fuer eigene Datenquellen erweitern
- Befehle, URLs und API-Namen unveraendert lassen
