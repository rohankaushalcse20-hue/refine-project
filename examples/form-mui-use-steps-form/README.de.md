## MUI Steps-Formularbeispiel

Dieses Beispiel zeigt, wie **Refine** mehrstufige Formulare mit MUI umsetzt. Jeder Schritt sammelt einen Teil der Daten, waehrend Refine Formularstatus und finale Mutation verwaltet.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example form-mui-use-steps-form
```

## Wichtige Punkte

- Mehrstufige Formulare mit Refine strukturieren
- MUI Stepper fuer Formularfortschritt verwenden
- Validierung und Speichern ueber Schritte hinweg koordinieren
- Befehle, URLs und API-Namen unveraendert lassen
