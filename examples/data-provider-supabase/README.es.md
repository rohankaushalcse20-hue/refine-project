## Ejemplo de data provider con Supabase

Este ejemplo muestra cómo usar **Refine** con Supabase para crear una aplicación CRUD respaldada por tablas y servicios de Supabase. El data provider mantiene la conexión entre resources y backend.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example data-provider-supabase
```

## Puntos clave

- Configuración de Supabase como data provider
- Resources de Refine sobre tablas del backend
- Lectura, creación, edición y borrado de registros
- Comandos, URLs y nombres técnicos preservados
