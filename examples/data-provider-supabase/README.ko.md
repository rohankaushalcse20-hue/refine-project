## Supabase data provider 예제

이 예제는 Supabase를 backend로 사용해 **Refine** 애플리케이션을 구성하는 방법을 보여줍니다. Supabase tables와 인증 기능을 Refine resources와 함께 사용할 수 있습니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example data-provider-supabase
```

## 핵심 포인트

- Supabase data provider 설정
- tables를 Refine resources로 연결
- Supabase 인증과 데이터 접근 흐름 활용
- 원본 명령어, URL, API 이름 유지
