## Supabase data provider örneği

Bu örnek, Supabase veritabanını Refine `dataProvider` ile kullanmayı gösterir. Supabase tablo adları, komut ve CodeSandbox URL'si özgün haliyle korunur.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example data-provider-supabase
```

## Dikkat edilecek noktalar

- Supabase istemcisinin Refine veri katmanına bağlanması
- CRUD ekranlarında tablo verilerinin kullanılması
- Filtreleme, sıralama ve sayfalama davranışları

[data-provider-supabase örneğini CodeSandbox'da aç](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/data-provider-supabase?view=preview&theme=dark&codemirror=1)
