## Data provider-Beispiel mit Supabase

Dieses Beispiel zeigt, wie **Refine** Supabase als Backend verwendet. Der data provider bildet Refine resource-Aktionen auf Supabase-Operationen ab und unterstuetzt so klare CRUD-Flows.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example data-provider-supabase
```

## Wichtige Punkte

- Supabase als data provider einbinden
- Refine resources fuer Lesen, Erstellen und Aktualisieren nutzen
- Datenzugriff von UI-Komponenten entkoppeln
- Befehle, URLs und API-Namen bleiben unveraendert
