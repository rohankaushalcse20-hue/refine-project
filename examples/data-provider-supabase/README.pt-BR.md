## Exemplo de data provider Supabase

Este exemplo mostra como conectar **refine** ao Supabase usando um data provider. Ele demonstra como manter resources, listas e mutacoes no padrao do refine enquanto os dados sao lidos e gravados pelo backend Supabase.

## Testar localmente

```bash
npm create refine-app@latest -- --example data-provider-supabase
```

## Pontos principais

- Configuracao do cliente Supabase.
- Uso do data provider para recursos CRUD.
- Fluxo de dados conectado ao core do refine.
- Comandos, URLs e nomes de exemplo preservados.
