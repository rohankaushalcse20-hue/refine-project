## Nestjsx CRUD data provider örneği

Bu örnek, Nestjsx CRUD API'sini Refine `dataProvider` ile kullanmayı gösterir. `data-provider-nestjsx-crud` örnek adı ve komut satırı aynen korunur.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example data-provider-nestjsx-crud
```

## Dikkat edilecek noktalar

- REST tabanlı Nestjsx CRUD uç noktaları
- Liste, oluşturma ve düzenleme aksiyonlarının veri sağlayıcıya bağlanması
- Kaynak adlarının API rotalarıyla tutarlı kalması
