## Exemplo de data provider Nestjsx CRUD

Este exemplo mostra como usar **refine** com o data provider Nestjsx CRUD. A aplicacao usa os hooks CRUD do refine e envia as operacoes para uma API compativel com Nestjsx CRUD.

## Testar localmente

```bash
npm create refine-app@latest -- --example data-provider-nestjsx-crud
```

## Pontos principais

- Configuracao de `dataProvider` para Nestjsx CRUD.
- Listagem, filtros e mutacoes conectados ao backend.
- Resources do refine preservados sobre uma API REST.
- Comandos, URLs e APIs preservados no codigo.
