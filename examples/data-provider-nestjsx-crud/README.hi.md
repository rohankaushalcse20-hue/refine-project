## Nestjsx CRUD data provider example

यह example **Refine** में Nestjsx CRUD data provider के साथ admin screens बनाना दिखाता है। Resources को Nestjsx CRUD endpoints से जोड़कर table, form और record actions काम करते हैं।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example data-provider-nestjsx-crud
```

## मुख्य बिंदु

- Nestjsx CRUD data provider के साथ resource configuration
- REST-style CRUD endpoints से list/create/edit/delete flows
- Refine hooks और generated pages के बीच data binding
- commands, URLs और provider names को original example जैसा रखना
