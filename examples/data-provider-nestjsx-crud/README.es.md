## Ejemplo de data provider Nestjsx CRUD

Este ejemplo muestra cómo utilizar Refine con APIs basadas en Nestjsx CRUD y su convencion de endpoints REST.

## Probar localmente

```bash
npm create refine-app@latest -- --example data-provider-nestjsx-crud
```

## Qué revisar

- Configuración del data provider Nestjsx CRUD.
- Traduccion de filtros y ordenamiento a parámetros REST.
- Uso de resources de Refine sobre controladores existentes.
- Revisión de requests generados por el provider.
