## Blog ecommerce example

यह example blog content के साथ ecommerce-style Refine application चलाने का तरीका दिखाता है। इसमें routing, resource pages और reusable UI patterns को एक छोटे demo में जोड़ा गया है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example blog-ecommerce
```
