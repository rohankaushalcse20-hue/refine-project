## Basisbeispiel mit MUI

Dieses Beispiel zeigt eine einfache **Refine**-Anwendung mit MUI. Refine uebernimmt Resources, Routing und Datenzugriff, waehrend MUI die sichtbaren CRUD-Seiten bereitstellt.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example base-mui
```

## Wichtige Punkte

- MUI-Komponenten in eine Refine-App einbinden
- Listen-, Erstellen-, Bearbeiten- und Anzeigen-Seiten bereitstellen
- Resource-Konfiguration und UI sauber trennen
- Befehle, URLs und API-Namen unveraendert lassen
