## React Hook Form `useForm` 예제

이 예제는 **Refine**의 form 흐름을 React Hook Form과 함께 사용하는 방법을 보여줍니다. `useForm`을 통해 입력값, validation, submit 동작을 resource mutation과 연결합니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example form-react-hook-form-use-form
```

## 핵심 포인트

- React Hook Form과 Refine form 훅 통합
- create와 edit 화면의 submit 흐름 처리
- validation 상태와 server mutation 연결
- 원본 명령어, URL, API 이름 유지
