## Ejemplo de formulario con React Hook Form

Este ejemplo muestra cómo usar **Refine** con React Hook Form para crear formularios conectados a operaciones CRUD. Refine coordina mutations y resources, mientras React Hook Form gestiona el estado del formulario.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example form-react-hook-form-use-form
```

## Puntos clave

- Uso de `useForm` con React Hook Form
- Enlace entre submit del formulario y data provider
- Validación y estado del formulario dentro del flujo de Refine
- Comandos, URLs y APIs conservados sin traducir
