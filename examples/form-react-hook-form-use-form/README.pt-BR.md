## Exemplo de formulario com React Hook Form

Este exemplo mostra como usar **refine** com React Hook Form para criar formularios conectados a recursos CRUD. O refine coordena a mutacao e o estado do resource, enquanto React Hook Form gerencia os campos e a validacao.

## Testar localmente

```bash
npm create refine-app@latest -- --example form-react-hook-form-use-form
```

## Pontos principais

- Uso de `useForm` com React Hook Form.
- Submissao conectada ao fluxo de mutacao do refine.
- Campos e validacao mantidos na camada de formulario.
- Comandos, URLs e APIs preservados no codigo.
