## Formularbeispiel mit React Hook Form

Dieses Beispiel zeigt, wie **Refine** mit React Hook Form zusammenarbeitet. `useForm` verbindet resource-Daten, Validierung und submit flow, waehrend React Hook Form die Formularlogik bereitstellt.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example form-react-hook-form-use-form
```

## Wichtige Punkte

- Integration von Refine `useForm` mit React Hook Form
- Formularstatus und Validierung getrennt von resource-Logik
- Mutationen ueber den data provider
- Befehle, URLs und API-Namen bleiben unveraendert
