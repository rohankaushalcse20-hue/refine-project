## i18n-Beispiel mit Next.js

Dieses Beispiel zeigt, wie sich **Refine**, Next.js und Internationalisierung kombinieren lassen, damit Routing, Rendering und Inhalte auf die Sprache der Nutzer reagieren.

## Lokal testen

```bash
npm create refine-app@latest -- --example i18n-nextjs
```

## Wichtige Punkte

- Locale-Konfiguration in Next.js.
- Einbindung des i18n-Providers in `<Refine />`.
- Uebersetzte Navigation und CRUD-Aktionen.
- Kompatibilitaet mit Routing und Rendering in Next.js.
