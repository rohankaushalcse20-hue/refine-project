# Refine i18n Next.js voorbeeld

Dit voorbeeld laat zien hoe je i18n-gedrag configureert in een Refine-applicatie op basis van Next.js. Routes, locale en vertaalstate worden binnen hetzelfde project beheerd.

## Belangrijkste punten

- Combineert Refine `i18nProvider` met een locale-flow op basis van Next.js.
- Beheert teksten voor pagina's en resources via vertaalkeys.
- Toont hoe locale wisselen kan samenwerken met routing.
- Frameworks, packages en API-namen blijven in het Engels.

## Uitvoeren

```sh
npm install
npm run dev
```

## Wanneer gebruik je dit?

Dit is een goed startpunt wanneer je meertalige routes en UI-teksten plant in een Refine-project met Next.js.
