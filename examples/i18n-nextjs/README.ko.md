## Next.js용 i18n 예제

이 example은 **Refine**, Next.js, 국제화를 함께 사용해 routes, rendering, content가 사용자의 locale 설정을 따르도록 구성하는 방법을 설명합니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example i18n-nextjs
```

## 주요 포인트

- Next.js의 locales 설정
- `<Refine />`에 `i18nProvider`를 통합하는 방법
- navigation과 CRUD actions 번역
- Next.js routing 및 rendering 흐름과의 호환성
