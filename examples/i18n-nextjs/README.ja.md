## Next.js 向け i18n サンプル

この example では、**Refine**、Next.js、国際化を組み合わせ、routes、rendering、content がユーザーの locale 設定に追従する構成を紹介します。

## ローカルで実行する

```bash
npm create refine-app@latest -- --example i18n-nextjs
```

## 主なポイント

- Next.js における locales の設定
- `<Refine />` への `i18nProvider` 統合
- navigation と CRUD actions の翻訳
- Next.js の routing と rendering フローとの互換性

[i18n-nextjs example を開く](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/i18n-nextjs?view=preview&theme=dark&codemirror=1)
