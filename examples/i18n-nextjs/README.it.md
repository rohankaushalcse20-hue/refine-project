# Esempio Refine i18n Next.js

Questo esempio mostra come configurare il comportamento i18n in un'applicazione Refine basata su Next.js. Route, locale e state delle traduzioni sono gestiti nello stesso progetto.

## Punti principali

- Combina Refine `i18nProvider` con un flusso locale basato su Next.js.
- Gestisce testi di pagine e resource tramite chiavi di traduzione.
- Mostra come il cambio locale può lavorare insieme al routing.
- Framework, package e nomi API restano in inglese.

## Esecuzione

```sh
npm install
npm run dev
```

## Quando usarlo?

È un buon punto di partenza quando pianifichi route e testi UI multilingua in un progetto Refine con Next.js.
