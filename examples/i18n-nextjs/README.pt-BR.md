## Exemplo de i18n com Next.js

Este exemplo mostra como combinar **Refine**, Next.js e internacionalização para que routing, rendering e conteúdo acompanhem o idioma de quem usa a aplicação.

## Testar localmente

```bash
npm create refine-app@latest -- --example i18n-nextjs
```

## Pontos principais

- Configuração de locales no Next.js.
- Integração do i18n provider em `<Refine />`.
- Navegação e ações de CRUD traduzidas.
- Compatibilidade com routing e rendering do Next.js.
