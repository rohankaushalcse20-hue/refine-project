## Exemplo de `useStepsForm` com React Hook Form

Este exemplo mostra como usar **Refine** com React Hook Form em formulários divididos por etapas. A abordagem ajuda a organizar fluxos longos mantendo validação e envio em um único processo.

## Executar localmente

```bash
npm create refine-app@latest -- --example form-react-hook-form-use-steps-form
```

## Pontos principais

- Formulário multi-step com React Hook Form
- Estado de etapas gerenciado pelos hooks do Refine
- Validação e mutation integradas ao fluxo CRUD
- Comandos, URLs e nomes de API preservados como no exemplo original
