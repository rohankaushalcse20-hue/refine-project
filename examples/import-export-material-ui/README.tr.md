## Material UI içe ve dışa aktarma örneği

Bu örnek, Material UI tabanlı Refine ekranlarında veri içe aktarma ve dışa aktarma akışlarını gösterir. Tablo verileri, kullanıcı eylemleriyle dosya işlemlerine bağlanır.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example import-export-material-ui
```

## Dikkat edilecek noktalar

- Material UI arayüzünde içe aktarma ve dışa aktarma eylemleri
- Refine kaynak verilerinin dosya iş akışına bağlanması
- Dosya, hook ve provider adları çevrilmeden korunur
