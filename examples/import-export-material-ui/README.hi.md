## Material UI import/export example

यह example दिखाता है कि **Refine** और Material UI के साथ import/export feature को list experience में कैसे जोड़ा जाता है। यह bulk record handling के लिए UI controls और data operations को साथ रखता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example import-export-material-ui
```

## मुख्य बिंदु

- Material UI controls से import और export actions चलाना
- records को file से import करने का workflow
- list data को export करने के लिए action surface
- command, API names और CodeSandbox URL को original example जैसा रखना

[import-export-material-ui example CodeSandbox में खोलें](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/import-export-material-ui?view=preview&theme=dark&codemirror=1)
