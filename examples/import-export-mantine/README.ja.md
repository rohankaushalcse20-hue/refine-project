## Mantine でのインポートとエクスポート

この例では、Mantine を使った **refine** アプリケーションでデータのインポートとエクスポートを扱う方法を示します。管理画面で一括データ操作を提供する際の参考になります。

## ローカルで試す

```bash
npm create refine-app@latest -- --example import-export-mantine
```

## 主なポイント

- インポートとエクスポートの操作を refine に統合します。
- Mantine の UI でコマンドとフィードバックを表示します。
- 大量データを扱う管理ワークフローに向いた例です。
- コマンドと CodeSandbox の URL は保持しています。

[CodeSandbox で import-export-mantine の例を開く](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/import-export-mantine?view=preview&theme=dark&codemirror=1)
