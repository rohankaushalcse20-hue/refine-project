## Mantine import/export example

यह example दिखाता है कि **Refine** और Mantine UI के साथ data import और export controls कैसे बनाए जाते हैं। यह bulk data workflows को list pages से जोड़ने का practical pattern देता है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example import-export-mantine
```

## मुख्य बिंदु

- Mantine components के साथ import/export buttons
- uploaded data को Refine resource workflow में शामिल करना
- list records को export करने का user-facing action
- command, package names और URLs को original example जैसा रखना
