## Базовый пример с Chakra UI

Этот пример показывает минимальную интеграцию Refine с **Chakra UI**. Он помогает быстро проверить ресурсную модель Refine, routing и готовые экраны CRUD, сохраняя визуальный слой на компонентах Chakra UI.

## Запуск локально

```bash
npm create refine-app@latest -- --example base-chakra-ui
```

## Что проверить

- Регистрацию resources внутри `Refine`.
- Работу списка, создания, редактирования и просмотра записей.
- Согласованность Chakra UI-темы и layout-компонентов.
- Неизменность API names, импортов и команд запуска.
