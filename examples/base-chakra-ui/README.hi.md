## Chakra UI base example

यह example **Refine** को Chakra UI के साथ शुरू करने का basic setup दिखाता है। Application resources, routes और CRUD views को Chakra components के साथ compose करती है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example base-chakra-ui
```

## मुख्य बिंदु

- Chakra UI package के साथ Refine application shell
- list, create और edit जैसे CRUD screens की base structure
- resource-driven navigation और routing
- commands और package names को original example जैसा रखना
