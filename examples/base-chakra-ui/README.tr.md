## Chakra UI temel örneği

Bu örnek, Chakra UI bileşenleriyle hazırlanmış temel bir Refine uygulamasını yerelleştirilmiş olarak açıklar. Amaç, CRUD ekranlarının Chakra UI düzeni içinde nasıl bağlandığını hızlıca göstermektir.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example base-chakra-ui
```

## Dikkat edilecek noktalar

- Chakra UI ile temel sayfa ve form düzeni
- Refine kaynaklarının liste ve kayıt işlemlerine bağlanması
- Komutlar, URL'ler ve API adları değiştirilmeden bırakılmıştır
