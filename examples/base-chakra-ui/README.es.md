## Ejemplo base con Chakra UI

Este ejemplo muestra una aplicación mínima de **Refine** con Chakra UI. Es una base ligera para crear pantallas CRUD usando los providers de Refine y los componentes de Chakra UI.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example base-chakra-ui
```

## Puntos clave

- Configuración inicial de Refine con Chakra UI
- Estructura de resources lista para CRUD
- Separación entre providers, rutas y componentes visuales
- Comandos, URLs y nombres de API conservados como en el ejemplo original
