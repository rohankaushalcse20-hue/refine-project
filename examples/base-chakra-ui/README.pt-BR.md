## Exemplo base com Chakra UI

Este exemplo mostra uma aplicacao **refine** inicial usando Chakra UI. Ele e um ponto de partida para montar recursos CRUD com componentes Chakra UI e provedores do refine.

## Testar localmente

```bash
npm create refine-app@latest -- --example base-chakra-ui
```

## Pontos principais

- Estrutura basica de uma aplicacao refine.
- Integracao com Chakra UI para componentes e layout.
- Configuracao inicial de resources e providers.
- Comandos, URLs e APIs preservados no codigo.
