## Contoh dasar dengan Chakra UI

Contoh ini menunjukkan aplikasi **Refine** minimal dengan Chakra UI. Struktur ini cocok untuk mulai membuat halaman CRUD dengan komponen Chakra UI sambil tetap memakai data flow dan routing Refine.

## Menjalankan secara lokal

```bash
npm create refine-app@latest -- --example base-chakra-ui
```

## Hal yang perlu diperhatikan

- Konfigurasi Refine dengan Chakra UI
- Resource CRUD yang siap dikembangkan
- Pemisahan komponen UI dari logika data Refine
- Command, URL, dan nama teknis tetap dipertahankan tanpa diterjemahkan
