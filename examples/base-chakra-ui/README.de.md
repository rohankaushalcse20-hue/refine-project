## Basisbeispiel mit Chakra UI

Dieses Beispiel zeigt eine einfache **Refine**-Anwendung mit Chakra UI. Die Refine-Provider stellen CRUD- und Routing-Logik bereit, waehrend Chakra UI das Layout und die Bedienelemente liefert.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example base-chakra-ui
```

## Wichtige Punkte

- Refine mit Chakra UI-Komponenten starten
- Resources fuer Standard-CRUD-Seiten definieren
- Datenzugriff und Darstellung sauber trennen
- Befehle, URLs und API-Namen unveraendert lassen
