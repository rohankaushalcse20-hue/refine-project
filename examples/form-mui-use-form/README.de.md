## MUI-Formularbeispiel mit `useForm`

Dieses Beispiel zeigt, wie **Refine** `useForm` mit MUI-Formularfeldern kombiniert. Refine verwaltet Submit, Mutation und Datensatzstatus, waehrend MUI die Eingabeelemente rendert.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example form-mui-use-form
```

## Wichtige Punkte

- `useForm` fuer Create- und Edit-Workflows verwenden
- MUI-Felder an Refine-Formularstatus anbinden
- Validierung und Speichern klar strukturieren
- Befehle, URLs und API-Namen unveraendert lassen
