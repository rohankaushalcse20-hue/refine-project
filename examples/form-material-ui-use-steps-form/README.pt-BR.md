## Exemplo de `useStepsForm` com Material UI

Este exemplo mostra como criar formulários em etapas com **Refine** e Material UI. Ele organiza campos complexos em passos menores sem perder a integração com resources.

## Executar localmente

```bash
npm create refine-app@latest -- --example form-material-ui-use-steps-form
```

## Pontos principais

- Formulários multi-step com `useStepsForm`
- Componentes Material UI para navegação entre etapas
- Validação e envio conectados aos hooks do Refine
- Comandos, URLs e nomes de API preservados como no exemplo original
