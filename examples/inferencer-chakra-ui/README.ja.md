## Chakra UI の Inferencer

この例では、**refine** の Inferencer で生成した初期 CRUD 画面を Chakra UI で表示する方法を示します。resource を素早く確認し、後から生成コードを製品向けに調整するための出発点になります。

## ローカルで試す

```bash
npm create refine-app@latest -- --example inferencer-chakra-ui
```

## 主なポイント

- Inferencer で一覧やフォームの初期 UI を生成します。
- 生成された UI に Chakra UI の見た目を適用します。
- resource のプロトタイピングを短時間で進められます。
- 例のコマンドと URL はそのまま保持しています。

[CodeSandbox で inferencer-chakra-ui の例を開く](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/inferencer-chakra-ui?view=preview&theme=dark&codemirror=1)
