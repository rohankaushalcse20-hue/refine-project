## Validación de formularios en servidor con Mantine

Este ejemplo muestra cómo mostrar validaciónes del backend en formularios Mantine sin perder el flujo declarativo de Refine.

## Probar localmente

```bash
npm create refine-app@latest -- --example server-side-form-validation-mantine
```

## Qué revisar

- Conexión entre errores del servidor y campos Mantine.
- Estado de envío y errores con hooks de Refine.
- Mensajes localizados cerca del campo correspondiente.
- Manejo de respuestas de validación fallidas.
