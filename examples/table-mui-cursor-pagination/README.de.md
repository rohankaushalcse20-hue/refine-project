## MUI-Beispiel fuer Cursor-Pagination

Dieses Beispiel zeigt, wie **Refine** Cursor-Pagination mit einer MUI-Tabelle umsetzt. Die UI bleibt vertraut, waehrend die Navigation auf Cursor-Werten statt Seitenzahlen basiert.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example table-mui-cursor-pagination
```

## Wichtige Punkte

- Cursor-basierte Listenabfragen in Refine verwenden
- MUI-Tabellensteuerung an vorherige und naechste Cursor koppeln
- Pagination-Logik vom Tabellenlayout trennen
- Befehle, URLs und API-Namen unveraendert lassen
