## Exemplo de autenticacao com Ant Design

Este exemplo mostra como usar **refine** com um fluxo de autenticacao em uma aplicacao baseada em Ant Design. O refine cuida do estado de autenticacao e das rotas protegidas, enquanto os formularios usam componentes Ant Design.

## Testar localmente

```bash
npm create refine-app@latest -- --example auth-antd
```

## Pontos principais

- Configuracao de `authProvider`.
- Rotas protegidas para usuarios autenticados.
- Formularios e layout com Ant Design.
- Comandos, URLs e APIs preservados no codigo.

[Abrir o exemplo auth-antd no CodeSandbox](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/auth-antd?view=preview&theme=dark&codemirror=1)
