## JavaScript 예제

이 예제는 TypeScript 없이 JavaScript로 **Refine** 애플리케이션을 구성하는 방법을 보여줍니다. Refine의 resource 패턴과 provider 설정은 유지하면서 JavaScript 프로젝트에서 빠르게 시작할 수 있습니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example with-javascript
```

## 핵심 포인트

- JavaScript 기반 Refine 프로젝트 구성
- resources와 data provider 연결
- TypeScript 설정 없이 CRUD 흐름 확인
- 원본 명령어, URL, API 이름 유지
