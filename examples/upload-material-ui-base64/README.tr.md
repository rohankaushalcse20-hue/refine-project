## Material UI Base64 yükleme örneği

Bu örnek, Material UI formunda dosyaları Base64 olarak işleyip Refine kayıt akışına bağlamayı gösterir. Dosya içeriği form değeri olarak hazırlanır ve gönderim sırasında kullanılır.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example upload-material-ui-base64
```

## Dikkat edilecek noktalar

- Material UI dosya alanı ve önizleme akışı
- Base64 veri üretimi ve form değerine bağlama
- Dosya işleme API adları çevrilmeden korunur
