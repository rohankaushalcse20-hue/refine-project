## Ejemplo de data provider con Appwrite

Este ejemplo muestra cómo usar **Refine** con Appwrite como backend. El data provider conecta los resources con Appwrite para que la interfaz se centre en los flujos CRUD.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example data-provider-appwrite
```

## Puntos clave

- Configuración del data provider de Appwrite
- Conexión de resources de Refine con colecciones backend
- Patrones de list, create, edit y delete
- Variables, collections y nombres de API preservados como contratos técnicos
