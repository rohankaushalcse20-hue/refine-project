## Appwrite data provider örneği

Bu örnek, Appwrite veritabanı kaynaklarını Refine `dataProvider` sözleşmesiyle kullanmayı gösterir. Appwrite koleksiyon adları ve kod içi API adları korunur.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example data-provider-appwrite
```

## Dikkat edilecek noktalar

- Appwrite koleksiyonlarının Refine kaynaklarına eşlenmesi
- Listeleme, oluşturma, güncelleme ve silme işlemleri
- İstemci yapılandırmasının uygulama başlangıcında sağlanması
