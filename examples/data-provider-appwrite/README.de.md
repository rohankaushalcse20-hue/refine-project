## Data provider-Beispiel mit Appwrite

Dieses Beispiel zeigt, wie **Refine** mit Appwrite als Backend arbeitet. Der data provider uebersetzt Refine resource-Aktionen in Appwrite-Operationen und haelt die UI von der Datenlogik getrennt.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example data-provider-appwrite
```

## Wichtige Punkte

- Appwrite als data provider einrichten
- CRUD-Operationen ueber Refine resources ausfuehren
- Backend-Zugriff getrennt von Seiten und Komponenten halten
- Befehle, URLs und API-Namen bleiben unveraendert
