## Appwrite data provider example

यह example दिखाता है कि Appwrite backend के साथ **Refine** कैसे इस्तेमाल किया जाता है। Data provider Refine resources को Appwrite endpoints से जोड़ता है, ताकि interface CRUD flows पर केंद्रित रहे।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example data-provider-appwrite
```

## मुख्य बिंदु

- Appwrite data provider की configuration
- Refine resources को backend से जोड़ना
- list, create, edit और delete patterns को सुरक्षित रखना
- collections, variables और API names को technical contracts की तरह रखना
