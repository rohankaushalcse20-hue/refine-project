## Exemplo de data provider Appwrite

Este exemplo mostra como usar o Refine com Appwrite como backend. O data provider conecta os resources do Refine aos endpoints do Appwrite, mantendo a interface focada nos fluxos de CRUD.

## Testar localmente

```bash
npm create refine-app@latest -- --example data-provider-appwrite
```

## Pontos principais

- Configuracao do data provider Appwrite.
- Resources do Refine conectados ao backend.
- Padroes de listagem, criacao, edicao e exclusao preservados.
- Nomes de collections, variaveis e APIs mantidos como contratos tecnicos.
