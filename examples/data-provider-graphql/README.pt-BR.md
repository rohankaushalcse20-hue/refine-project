## Exemplo de data provider GraphQL

Este exemplo mostra como usar **refine** com um data provider GraphQL. O refine converte operacoes CRUD em chamadas ao provider, permitindo trabalhar com recursos remotos usando uma API GraphQL.

## Testar localmente

```bash
npm create refine-app@latest -- --example data-provider-graphql
```

## Pontos principais

- Configuracao de `dataProvider` para GraphQL.
- Operacoes de listagem, criacao, edicao e exclusao via provider.
- Resources do refine conectados a uma API remota.
- Comandos, URLs e APIs preservados no codigo.
