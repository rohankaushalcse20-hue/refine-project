## Ejemplo de data provider GraphQL

Este ejemplo muestra cómo usar un data provider GraphQL con Refine para consultar y mutar recursos mediante una API GraphQL.

## Probar localmente

```bash
npm create refine-app@latest -- --example data-provider-graphql
```

## Qué revisar

- Configuración del cliente GraphQL.
- Implementacion de operaciónes CRUD en el data provider.
- Consulta de listas y detalles desde resources de Refine.
- Preservacion de queries, mutations y nombres de campos.
