## Contoh dasar dengan Material UI

Contoh ini menunjukkan aplikasi **Refine** minimal dengan Material UI. Proyek ini dapat menjadi starter untuk membuat layar CRUD dengan komponen Material UI dan paket integrasi Refine.

## Menjalankan secara lokal

```bash
npm create refine-app@latest -- --example base-material-ui
```

## Hal yang perlu diperhatikan

- Konfigurasi Refine dengan Material UI
- Resource CRUD dan layout aplikasi dasar
- Penggunaan komponen UI tanpa mengubah API Refine
- Command, URL, dan nama teknis tetap dipertahankan tanpa diterjemahkan
