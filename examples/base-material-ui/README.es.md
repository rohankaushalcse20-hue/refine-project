## Ejemplo base con Material UI

Este ejemplo muestra una aplicación mínima de **Refine** con Material UI. Es un punto de partida para crear interfaces CRUD con los providers de Refine y los componentes de `@refinedev/mui`.

## Ejecutar en local

```bash
npm create refine-app@latest -- --example base-material-ui
```

## Puntos clave

- Configuración base de Refine con Material UI
- Resources y rutas preparados para CRUD
- Uso de componentes de `@refinedev/mui`
- Comandos, URLs y nombres técnicos conservados sin traducir
