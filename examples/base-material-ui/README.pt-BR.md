## Exemplo base com Material UI

Este exemplo apresenta uma aplicacao **refine** basica usando Material UI. Ele serve como ponto de partida para projetos que precisam de layout, resources e fluxo CRUD com a integracao visual do Material UI.

## Testar localmente

```bash
npm create refine-app@latest -- --example base-material-ui
```

## Pontos principais

- Setup inicial de uma aplicacao refine.
- Componentes e layout com Material UI.
- Providers essenciais conectados ao core.
- Estrutura pronta para expandir resources.
