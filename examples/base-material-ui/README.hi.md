## Material UI base example

यह example **Refine** और Material UI के साथ basic CRUD application setup दिखाता है। इसमें common admin layout, resource routing और Material UI components पर बने CRUD screens शामिल हैं।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example base-material-ui
```

## मुख्य बिंदु

- Material UI package के साथ Refine starter application
- resources के आधार पर list, create और edit pages
- admin layout और navigation का basic pattern
- commands, URLs और package names को original example जैसा रखना
