## Material UI 기본 예제

이 예제는 **Refine**을 Material UI 화면 구성과 함께 시작하는 기본 패턴을 보여줍니다. CRUD 동작과 provider 연결은 Refine 구조를 따르고, 사용자 인터페이스는 Material UI 컴포넌트로 구성합니다.

## 로컬에서 실행하기

```bash
npm create refine-app@latest -- --example base-material-ui
```

## 확인할 점

- Material UI 컴포넌트로 만든 resource 화면
- `dataProvider`, routes, layout의 기본 연결
- list, create, edit 화면의 CRUD 동작
- 명령어, URL, API 이름은 원문 그대로 유지
