## Material UI temel örneği

Bu örnek, Material UI bileşenleriyle kurulan temel Refine uygulamasını açıklar. Listeleme, kayıt oluşturma ve düzenleme akışları Material UI düzeni içinde çalışır.

## Lokal çalıştırma

```bash
npm create refine-app@latest -- --example base-material-ui
```

## Dikkat edilecek noktalar

- Material UI ile temel CRUD ekranları
- Refine kaynak tanımları ve veri sağlayıcı bağlantısı
- Teknik adlar, komutlar ve URL'ler orijinal biçimleriyle korunur

[base-material-ui örneğini CodeSandbox'da aç](https://codesandbox.io/embed/github/refinedev/refine/tree/main/examples/base-material-ui?view=preview&theme=dark&codemirror=1)
