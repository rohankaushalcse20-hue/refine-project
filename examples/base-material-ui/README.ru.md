## Базовый пример с Material UI

Этот пример показывает стартовую интеграцию Refine с **Material UI**. Он помогает проверить стандартные страницы CRUD, layout, navigation и взаимодействие с data provider до добавления более сложной логики приложения.

## Запуск локально

```bash
npm create refine-app@latest -- --example base-material-ui
```

## Что проверить

- Базовую конфигурацию `Refine`, resources и router provider.
- Использование Material UI-компонентов в списках и формах.
- Подключение темы и layout Refine.
- Сохранение команд, imports и API names в исходном виде.
