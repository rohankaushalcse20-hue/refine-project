## Basisbeispiel mit Material UI

Dieses Beispiel zeigt eine einfache **Refine**-Anwendung mit Material UI. Refine uebernimmt Resources, Routing und Datenzugriff, waehrend Material UI die sichtbaren CRUD-Seiten bereitstellt.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example base-material-ui
```

## Wichtige Punkte

- Material UI-Komponenten in eine Refine-App einbinden
- Listen-, Erstellen-, Bearbeiten- und Anzeigen-Seiten bereitstellen
- Resource-Konfiguration und UI sauber trennen
- Befehle, URLs und API-Namen unveraendert lassen
