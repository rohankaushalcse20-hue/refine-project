## Import- und Exportbeispiel mit MUI

Dieses Beispiel zeigt, wie **Refine** Import- und Exportablaeufe in einer MUI-Anwendung unterstuetzt. Nutzer koennen Datenlisten ausgeben oder neue Daten einlesen, ohne die Resource-Struktur zu verlassen.

## Lokal ausfuehren

```bash
npm create refine-app@latest -- --example import-export-mui
```

## Wichtige Punkte

- Exportaktionen fuer Listenansichten bereitstellen
- Importablaeufe in eine MUI-Oberflaeche einbinden
- Datenoperationen ueber Refine resources ausfuehren
- Befehle, URLs und API-Namen unveraendert lassen
