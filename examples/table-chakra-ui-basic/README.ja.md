## Chakra UI の基本テーブル

この例では、Chakra UI のコンポーネントで **refine** の基本的な CRUD 一覧を作る方法を示します。resource と data provider に接続されたシンプルなテーブルの参照実装です。

## ローカルで試す

```bash
npm create refine-app@latest -- --example table-chakra-ui-basic
```

## 主なポイント

- Chakra UI のテーブルで resource を一覧表示します。
- 読み込み状態とデータ取得を refine に接続します。
- フィルターや行アクションを追加する土台になります。
- ローカル実行用コマンドは元のままです。
