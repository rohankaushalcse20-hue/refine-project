## Chakra UI basic table example

यह example दिखाता है कि **Refine** और Chakra UI के साथ basic list table कैसे बनाई जाती है। इसमें resource records को fetch करके table rows में दिखाने और common list actions जोड़ने का तरीका शामिल है।

## लोकल मशीन पर चलाएं

```bash
npm create refine-app@latest -- --example table-chakra-ui-basic
```

## मुख्य बिंदु

- Chakra UI table components के साथ Refine list page
- records fetching और table rendering का basic pattern
- row actions को resource operations से जोड़ना
- command, component names और URLs को original example जैसा रखना
