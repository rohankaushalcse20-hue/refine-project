## Chakra UI 기본 테이블 예제

이 예제는 **Refine**과 Chakra UI로 기본 테이블 목록을 구성하는 방법을 보여줍니다. data provider에서 가져온 resource 데이터를 Chakra UI 테이블로 표시합니다.

## 로컬에서 실행

```bash
npm create refine-app@latest -- --example table-chakra-ui-basic
```

## 핵심 포인트

- Chakra UI 테이블 컴포넌트와 Refine 통합
- resources에서 목록 데이터 가져오기
- 기본 목록 화면의 loading, pagination 흐름 확인
- 원본 명령어, URL, API 이름 유지
