[Kinde](https://kinde.com/) เป็นบริการที่ทำให้ authentication และ authorization ง่ายขึ้นด้วยวิธีให้เลือกหลายรูปแบบ ในตัวอย่างนี้ คุณจะเห็นวิธีใช้ Kinde Login กับ Refine

ตัวอย่าง Kinde ไม่ทำงานในโหมดฝังของ CodeSandbox เพราะต้อง whitelist callback URLs คุณสามารถเปิดตัวอย่างในเบราว์เซอร์และทดลองได้ผ่าน [ลิงก์นี้](https://xnv6hq-5173.csb.app/)
