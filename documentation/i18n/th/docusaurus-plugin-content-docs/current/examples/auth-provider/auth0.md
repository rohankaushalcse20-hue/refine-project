[Auth0](https://auth0.com/) เป็นบริการ authentication และ authorization แบบโมดูลาร์ที่ออกแบบโดยให้ API มาก่อน คุณสามารถใช้เพื่อเพิ่มการยืนยันตัวตนและการกำหนดสิทธิ์ให้แอปได้ ในตัวอย่างนี้ คุณจะเห็นวิธีใช้ Auth0 Login กับ Refine

[ดูคู่มือ Refine Auth0 Login เพื่ออ่านข้อมูลเพิ่มเติม →](/core/docs/advanced-tutorials/auth/auth0/)
