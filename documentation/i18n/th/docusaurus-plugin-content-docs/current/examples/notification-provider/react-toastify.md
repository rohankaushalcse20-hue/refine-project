ด้วย Refine Notification Provider คุณสามารถแสดงข้อความแจ้งเตือนในแอปพลิเคชันได้ทุกที่ ข้อความเหล่านี้อาจเป็นคำเตือนหรือข้อผิดพลาดที่แนะนำให้ดำเนินการ และช่วยให้ผู้ใช้ยังมีส่วนร่วมกับฟังก์ชันของแอป คุณสามารถใช้ notification library ใดก็ได้และจัดการด้วย hook `useNotification` ของ Refine ในตัวอย่างนี้เราใช้ไลบรารี [React Toastify](https://github.com/fkhadra/react-toastify) เพื่อแสดงการแจ้งเตือน
