Access control หมายถึงวิธีและกระบวนการที่ใช้จำกัดการเข้าถึงบางส่วนของเว็บแอปพลิเคชันหรือเว็บไซต์ตามสิทธิ์ของผู้ใช้ วิธีนี้ช่วยให้ผู้ใช้โต้ตอบได้เฉพาะเนื้อหาและฟีเจอร์ที่ได้รับอนุญาต เพิ่มทั้งความปลอดภัยและประสบการณ์ใช้งาน

ตัวอย่างนี้แสดงวิธีใช้ Refine ร่วมกับ [Permify](https://permify.co/) เพื่อทำให้การจัดการ access control ทั่วทั้งแอปพลิเคชันง่ายขึ้น
