Tutorial นี้พาคุณสร้างแอป CRUD ด้วย Refine เป็นขั้นตอนย่อย ๆ คุณจะเริ่มจากโครงสร้างโปรเจกต์ เพิ่ม resources เชื่อม data provider และทำหน้าจอ list, create, edit และ show ให้ครบ

## คุณจะได้เรียนรู้อะไร?

- วิธีสร้างแอป Refine ใหม่
- วิธีประกาศ `resources` และ route สำหรับ CRUD actions
- วิธีเชื่อม `dataProvider` เพื่ออ่านและเขียนข้อมูล
- วิธีใช้ hooks และ components เพื่อสร้าง form, table และ navigation
- วิธีเพิ่ม authentication, authorization และ i18n เมื่อจำเป็น

## วิธีใช้ tutorial

ให้เรียนตามลำดับ เพราะแต่ละส่วนต่อยอดจากส่วนก่อนหน้า เมื่อเจอ code block ให้คง package name, import path, command และ API identifier ไว้เหมือนเดิมเพื่อให้โปรเจกต์ทำงานถูกต้อง
