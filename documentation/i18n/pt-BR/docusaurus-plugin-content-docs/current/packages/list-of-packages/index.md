- `@refinedev/core` - Coleção de `hooks`, `components` e `providers` para **authentication**, **access control**, **routing**, **networking**, **state management** e **i18n**. É o ponto de partida para projetos headless.
- `@refinedev/inferencer` - Gera views para resources automaticamente com base na estrutura dos dados e reduz o trabalho manual na criação de páginas CRUD.
- `@refinedev/cli` - Ferramenta de CLI para fluxos importantes do dia a dia durante o desenvolvimento com refine.

### Pacotes de frameworks de UI

Saiba mais sobre integrações de UI no guia [UI Libraries](/core/docs/guides-concepts/ui-libraries/).

- [`@refinedev/antd`](/core/docs/ui-integrations/ant-design/introduction/) - Integração para [Ant Design](https://ant.design/).
- [`@refinedev/mui`](/core/docs/ui-integrations/material-ui/introduction/) - Integração para [Material UI](https://mui.com/material-ui/getting-started/overview/).
- [`@refinedev/mantine`](/core/docs/ui-integrations/mantine/introduction/) - Integração para [Mantine](https://mantine.dev/).
- [`@refinedev/chakra-ui`](/core/docs/ui-integrations/chakra-ui/introduction/) - Integração para [Chakra UI](https://chakra-ui.com/).
- [`@ferdiunal/refine-shadcn`](https://github.com/ferdiunal/refine-shadcn) - Componentes ShadCN UI para Refine.

### Pacotes de data provider

Mais detalhes estão na documentação de [Data Provider](/core/docs/data/data-provider/).

- [`@refinedev/simple-rest`](/core/docs/data/packages/simple-rest/) - Conecta **REST APIs** personalizadas.
- [`@refinedev/graphql`](/core/docs/data/packages/graphql/) - Conecta **GraphQL APIs** personalizadas.
- [`@refinedev/nestjsx-crud`](/core/docs/data/packages/nestjsx-crud/) - Usa **REST APIs** do **NestJs**.
- [`@refinedev/nestjs-query`](/core/docs/data/packages/nestjs-query/) - Usa **GraphQL APIs** do **Nestjs-Query**.
- [`@refinedev/strapi-v4`](/core/docs/data/packages/strapi-v4/) - Connector do Strapi para **REST API v4**.
- [`@refinedev/supabase`](/core/docs/data/packages/supabase/) - Data provider para [Supabase](https://supabase.com/) com suporte a realtime.

### Pacotes de router e live

- [`@refinedev/react-router`](/core/docs/routing/integrations/react-router/) - Router provider para React Router.
- [`@refinedev/nextjs-router`](/core/docs/routing/integrations/next-js/) - Router provider para Next.js.
- [`@refinedev/remix-router`](/core/docs/routing/integrations/remix/) - Router provider para Remix.
- `@refinedev/ably`, `@refinedev/graphql`, `@refinedev/supabase` e outros pacotes cobrem cenários de realtime ou live.

### Pacotes da comunidade

O ecossistema do Refine também inclui pacotes da comunidade para Firebase, Directus, PocketBase, JSON:API, PostgREST, Chakra UI v3 e outras integrações.
