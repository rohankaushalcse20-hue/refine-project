Uma senha de uso único (OTP) é uma senha com duas propriedades fundamentais: expira rapidamente e não pode ser reutilizada. OTPs geralmente são strings numéricas ou alfanuméricas geradas para um único procedimento de login. Este exemplo mostra como usar lógica de entrada OTP com Refine. Você pode usar senhas de uso único para acessar sua aplicação com o [AuthProvider](/core/docs/authentication/auth-provider/) do Refine.
