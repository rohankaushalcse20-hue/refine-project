Você pode usar Google Login para controlar acesso e fornecer identidade para sua aplicação. Este exemplo mostra como conectar Google Login ao seu projeto usando Refine.

:::note

Se você estiver desenvolvendo sua própria aplicação OAuth, é importante adicionar as URLs da aplicação publicada e do ambiente local de desenvolvimento à lista de origens permitidas nas configurações do app OAuth. Caso contrário, a aplicação pode falhar.

Para uma orientação mais detalhada, este [tutorial em vídeo](https://www.youtube.com/watch?v=HtJKUQXmtok) pode ajudar.

:::
