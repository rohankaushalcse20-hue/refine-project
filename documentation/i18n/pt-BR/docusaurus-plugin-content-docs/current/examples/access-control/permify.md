Controle de acesso se refere aos métodos e processos usados para restringir o acesso a certas partes de uma aplicação web ou site com base nas permissões da pessoa usuária. Ele garante que cada pessoa interaja apenas com o conteúdo e os recursos autorizados, melhorando segurança e experiência de uso.

Este exemplo demonstra como usar Refine e [Permify](https://permify.co/) para simplificar o gerenciamento de controle de acesso em toda a aplicação.

[Consulte a documentação do Refine Access Control Provider para saber mais. →](/core/docs/authorization/access-control-provider/)
