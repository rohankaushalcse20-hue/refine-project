**Refine** funciona em qualquer ambiente que execute **React**, incluindo Vite, Next.js, Remix e CRA.

Você pode instalar os pacotes manualmente, mas a forma mais rápida de começar é usar o scaffolder no navegador ou o scaffolder via CLI. Ambos ajudam a escolher framework, integração de UI, data provider, autenticação e i18n logo no início.

## Começando com a CLI

Execute `create-refine-app` para iniciar um novo projeto **Refine** rapidamente:

```sh
npm create refine-app@latest
```

Depois siga os prompts da CLI, entre no diretório gerado, instale as dependências se necessário e inicie o servidor de desenvolvimento sugerido.

## Começando pelo navegador

O scaffolder no navegador oferece as mesmas opções principais da CLI e permite visualizar o projeto antes do download.
