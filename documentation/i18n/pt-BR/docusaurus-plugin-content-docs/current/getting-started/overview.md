## O que é o Refine?

**Refine** é um meta-framework React para aplicações web com muitos fluxos de CRUD. Ele funciona bem em ferramentas internas, painéis administrativos, dashboards e produtos B2B.

Os hooks e componentes centrais do Refine aceleram o desenvolvimento com soluções consolidadas para **authentication**, **access control**, **routing**, **networking**, **state management** e **i18n**.

A arquitetura headless separa a lógica de negócio da UI e do roteamento. Isso permite combinar o Refine com design systems próprios, Tailwind CSS, Ant Design, Material UI, Mantine, Chakra UI e plataformas como Next.js, Remix, React Native ou Electron.

## Por que usar o Refine?

O Refine ocupa um ponto prático entre desenvolver tudo do zero e adotar plataformas low-code/no-code. Ele mantém a flexibilidade das tecnologias abertas, mas adiciona convenções que reduzem atraso de projeto, dívida técnica e problemas de manutenção.

Soluções low-code podem acelerar o começo, mas costumam limitar personalização, experiência de desenvolvimento e adaptação a casos complexos. O Refine preserva a produtividade sem prender a aplicação a uma arquitetura rígida.

## Casos de uso

**Refine** se destaca em aplicações orientadas a dados, como:

- Painéis administrativos.
- Dashboards operacionais.
- Ferramentas internas.
- Aplicações B2B com fluxos intensivos de CRUD.

## Principais recursos

- Devtools para inspecionar a aplicação e entender seu comportamento.
- Connectors para REST API, GraphQL, NestJS CRUD, Airtable, Strapi, Supabase, Hasura, Appwrite, Firebase, Nestjs-Query e Directus.
- SSR com Next.js e Remix.
- Geração de interfaces CRUD a partir da estrutura da API.
- Gerenciamento de estado e mutações com TanStack Query.
- Providers para autenticação, permissões, notificações, tempo real e audit logs.
