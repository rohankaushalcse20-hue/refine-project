O tutorial do Refine guia você pela construção de uma aplicação CRUD completa. Ao longo do processo, você pratica resources, providers, routing, formulários, tabelas e fluxos de autenticação.

## O que você vai aprender

- Configurar uma aplicação Refine do zero.
- Conectar um data provider a uma API.
- Definir resources e rotas.
- Criar páginas de listagem, criação, edição e visualização.
- Adicionar autenticação, autorização e i18n quando o projeto precisar.

Nomes de pacote, imports, comandos e exemplos de código permanecem em inglês para continuar alinhados com a API real. O conteúdo explicativo foi localizado para pt-BR.
