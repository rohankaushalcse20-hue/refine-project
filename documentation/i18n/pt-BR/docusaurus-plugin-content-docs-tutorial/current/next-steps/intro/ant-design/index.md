Concluímos a construção do app do zero e vimos os fundamentos do Refine, incluindo como criar uma aplicação CRUD usando seus hooks e componentes.

Agora é hora de dar uma olhada rápida no que podemos usar para melhorar a experiência de desenvolvimento com o Refine.

Nesta unidade, cobriremos os seguintes tópicos:

- Usar o pacote Inferencer do Refine para gerar views para nossos resources,
- Usar a CLI do Refine e conhecer seus recursos,
- Usar o Devtools do Refine para monitorar e depurar queries e mutations.

Esses tópicos ajudarão você a melhorar a experiência de desenvolvimento e tornar o processo mais eficiente.
