Agora já aprendemos os fundamentos de busca e manipulação de dados no Refine. Nesta unidade, veremos como adicionar autenticação à aplicação e entenderemos os conceitos essenciais de autenticação no Refine.

O Refine fornece uma interface de autenticação fácil de gerenciar, que pode ser usada com qualquer provedor de autenticação com pouco esforço.

Esta unidade cobre os seguintes tópicos:

- Aprender a interface [`AuthProvider`](/core/docs/authentication/auth-provider) criando um authentication provider,
- Usar hooks e componentes de autenticação, como os hooks [`useLogin`](/core/docs/authentication/hooks/use-login) e [`useIsAuthenticated`](/core/docs/authentication/hooks/use-is-authenticated), além do componente [`<Authenticated />`](/core/docs/authentication/components/authenticated).
- Lidar com autenticação em data providers e gerenciar erros de autenticação.

Esta unidade é independente de roteador e de UI framework. As partes de autenticação relacionadas ao roteador e ao UI framework serão abordadas nas próximas unidades.
