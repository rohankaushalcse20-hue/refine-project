Refine का `i18nProvider` आपके web application में कई languages जोड़ने की सुविधा देता है। Refine की default language English है, लेकिन आप अपनी translation files शामिल करके project को अलग-अलग locale preferences के लिए तैयार कर सकते हैं। यह example दिखाता है कि Next.js app में locale-aware routing और translated content को कैसे व्यवस्थित किया जाता है।
