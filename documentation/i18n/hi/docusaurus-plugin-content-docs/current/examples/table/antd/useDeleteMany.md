`useDeleteMany` Refine के data hooks में से एक है। यह database से एक से अधिक data items remove करता है। इस scenario में हमने table से एक से अधिक records हटाने के लिए `useDeleteMany` hook इस्तेमाल किया है। अपनी table में rows select करके और delete दबाकर आप multiple records remove कर सकते हैं। अधिक जानकारी के लिए example देखें।
