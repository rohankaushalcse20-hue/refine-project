Refine Notification Provider के साथ आप अपने application में कहीं भी notification messages दिखा सकते हैं। ये warnings या errors हो सकते हैं जो action सुझाते हैं और users को app functionality से जुड़े रहने में मदद करते हैं। आप कोई भी notification library उपयोग कर सकते हैं और उन्हें Refine के `useNotification` hook से manage कर सकते हैं! इस example में notifications दिखाने के लिए [React Toastify](https://github.com/fkhadra/react-toastify) library का उपयोग किया गया है।
