Access control उन methods और processes को कहा जाता है जिनसे किसी web application या website के कुछ हिस्सों तक access, user permissions के आधार पर सीमित किया जाता है। इससे users सिर्फ वही content और features उपयोग कर पाते हैं जिनके लिए वे authorized हैं, जिससे security और user experience बेहतर होते हैं।

यह example दिखाता है कि application में access control management को आसान बनाने के लिए Refine और [Permify](https://permify.co/) को साथ कैसे इस्तेमाल किया जा सकता है।
