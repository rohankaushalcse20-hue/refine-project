Refine के साथ बनाए गए forms में आप Ant Design [Form.Item](https://ant.design/components/form/#Form.Item) की rules property से basic validations कर सकते हैं। इसके साथ आप अपनी जरूरत के custom validations भी जोड़ सकते हैं। Form.Item rules property के अंदर validator function का उपयोग करके custom rules और validations जोड़ना आसान है। नीचे के example में custom form validation process को detail में समझाया गया है।
