आप Google Login का उपयोग करके अपने app की access control और user identity को संभाल सकते हैं। यह example दिखाता है कि Refine के साथ Google Login को project में कैसे जोड़ा जाए।

:::note

यदि आप अपनी खुद की OAuth application बना रहे हैं, तो deployed application और local development दोनों के URLs को OAuth app settings में allowed origins की सूची में जोड़ना जरूरी है। ऐसा न करने पर app सही तरह काम नहीं कर सकता।

यदि आपको step-by-step visual guidance चाहिए, तो यह [video tutorial](https://www.youtube.com/watch?v=HtJKUQXmtok) उपयोगी हो सकता है।

:::
