Refine Tutorial आपको एक पूरी CRUD application बनाने की प्रक्रिया से ले जाता है। इस दौरान आप resources, providers, routing, forms, tables और authentication flows को समझते हैं।

## आप क्या सीखेंगे

- शुरुआत से Refine app बनाना।
- API के साथ data provider जोड़ना।
- Resources और routes define करना।
- List, create, edit और show pages तैयार करना।
- ज़रूरत के अनुसार authentication, authorization और i18n जोड़ना।

Package names, imports, commands और code examples अंग्रेज़ी में ही रखे गए हैं ताकि वे वास्तविक API usage से मेल खाते रहें, जबकि व्याख्यात्मक सामग्री हिन्दी में दी गई है।
