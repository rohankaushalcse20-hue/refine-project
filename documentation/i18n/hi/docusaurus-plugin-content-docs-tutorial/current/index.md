Refine का tutorial एक पूर्ण CRUD application बनाते हुए framework की मुख्य क्षमताओं को सिखाता है। इसमें resources, providers, routing, forms, tables और authentication flows को क्रमबद्ध तरीके से समझाया जाता है।

## आप क्या सीखेंगे

- पहली Refine application तैयार करना
- data provider को API से जोड़ना
- resources और routes परिभाषित करना
- list, create, edit और show flows बनाना
- auth, notifications और UI integrations को जोड़ना

## इस localization का उपयोग कैसे करें

Packages, imports, commands और code snippets को अंग्रेज़ी में ही रखा गया है ताकि वे actual API surface से मेल खाएं। Hindi अनुवाद explanatory text, learning notes और navigation context को अधिक सुलभ बनाने के लिए जोड़ा गया है।
