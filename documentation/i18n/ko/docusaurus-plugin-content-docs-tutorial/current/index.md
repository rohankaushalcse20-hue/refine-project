Refine Tutorial은 완전한 CRUD 애플리케이션을 만드는 과정을 안내합니다. 이 과정에서 resources, providers, routing, forms, tables, authentication 흐름을 함께 이해하게 됩니다.

## 학습 내용

- 처음부터 Refine app 만들기
- API와 data provider 연결하기
- Resources와 routes 정의하기
- List, create, edit, show 페이지 구성하기
- 필요에 따라 authentication, authorization, i18n 추가하기

패키지 이름, imports, commands, code examples는 실제 API 사용과 맞도록 영어로 유지하고, 설명 텍스트는 한국어로 제공합니다.
