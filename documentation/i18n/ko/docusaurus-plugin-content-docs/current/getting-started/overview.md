## Refine란?

**Refine**은 CRUD 비중이 큰 웹 애플리케이션을 위한 React 메타 프레임워크입니다. 내부 도구, 관리자 패널, 대시보드, B2B 앱 같은 엔터프라이즈 시나리오를 빠르게 구축할 수 있도록 설계되었습니다.

핵심 `hooks`와 `components`는 **인증**, **접근 제어**, **routing**, **networking**, **state management**, **i18n** 같은 공통 과제를 표준적인 방식으로 처리할 수 있게 해 줍니다.

Refine의 headless 아키텍처는 비즈니스 로직을 UI와 라우팅에서 분리합니다. 덕분에 자체 디자인 시스템, Tailwind CSS, Ant Design, Material UI, Mantine, Chakra UI는 물론 Next.js, Remix, React Native, Electron 같은 플랫폼과도 유연하게 결합할 수 있습니다.

## Refine를 선택하는 이유

Refine는 완전히 처음부터 만드는 방식과 low-code/no-code 제품 사이의 균형점을 제공합니다. 유연성과 개방형 기술 스택은 유지하면서도 개발 지연, 기술 부채, 유지보수 부담을 줄일 수 있도록 공통 토대를 제공합니다.

low-code 제품은 초기 구축 속도를 높일 수 있지만 벤더 종속, 제한된 커스터마이징, 떨어지는 개발자 경험으로 이어질 수 있습니다. Refine는 생산성을 높이면서도 아키텍처를 고정하지 않습니다.

## 사용 사례

**Refine**은 특히 데이터 중심 애플리케이션에서 강점을 보입니다.

- 관리자 패널
- 운영 대시보드
- 내부 업무 도구
- CRUD 흐름이 많은 B2B 애플리케이션

## 주요 기능

- 애플리케이션을 더 깊이 살펴볼 수 있는 Devtools
- REST API, GraphQL, NestJS CRUD, Airtable, Strapi, Supabase, Hasura, Appwrite, Firebase, Nestjs-Query, Directus용 connectors
- Next.js와 Remix 기반 SSR 지원
- API 구조를 바탕으로 한 CRUD UI 생성
- TanStack Query 기반 상태 관리와 mutations
- 인증, 인가, 알림, 실시간, 감사 추적용 providers
