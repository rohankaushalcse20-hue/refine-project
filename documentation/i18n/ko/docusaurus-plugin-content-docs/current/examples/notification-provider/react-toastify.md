Refine Notification Provider를 사용하면 애플리케이션 어디에서나 notification message를 표시할 수 있습니다. 이 message는 action을 안내하고 app functionality에 대한 user engagement를 유지하는 warning 또는 error일 수 있습니다. 어떤 notification library든 사용할 수 있으며 Refine의 `useNotification` hook으로 관리할 수 있습니다! 이 예제에서는 notification을 표시하기 위해 [React Toastify](https://github.com/fkhadra/react-toastify) library를 사용했습니다.
