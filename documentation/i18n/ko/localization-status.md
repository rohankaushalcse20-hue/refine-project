# 한국어 로컬라이제이션 범위

이 문서는 `ko` 로컬라이제이션의 현재 범위와 이번 작업에서 추가한 슬라이스를 정리합니다.

## 포함된 내용

- Docusaurus의 `ko` locale 설정
- 테마 기본 UI 메시지
- getting started 핵심 페이지
- general concepts, routing, data fetching, authentication, authorization, forms, tables, notifications, i18n 가이드
- 튜토리얼 랜딩 페이지
- i18n examples와 Material UI template용 한국어 README
- `core`와 `simple-rest` 패키지용 한국어 요약 README
