# Nederlandse lokalisatiedekking

Dit document vat de huidige dekking voor locale `nl` samen en markeert welke localization slices in deze update zijn toegevoegd.

## Beschikbare content

- Nederlandse locale-configuratie in Docusaurus
- Nederlandse standaardberichten voor de Docusaurus theme UI
- Getting started overzicht en quickstart
- Guides voor general concepts, routing, data fetching, authentication, authorization, forms, tables, notifications en i18n
- Tutorial landingpagina en essentials intro
- Voorbeelddocumentatie voor data providers, live provider, auth providers, Ant Design forms en Ant Design tables
- Nederlandse README's voor i18n React, i18n Next.js en Material UI template voorbeelden
- Nederlandse README-samenvattingen voor `@refinedev/core` en `@refinedev/simple-rest`

## Kandidaat-slices voor vervolgwerk

- Advanced tutorial docs en aanvullende API reference pagina's
- README's voor extra UI-framework-, data-provider- en authentication-voorbeelden
- Verdere voorbeeldpagina's voor uploads, notification providers, Remix, Next.js en theming
- SEO metadata en langere pagina's controleren op natuurlijke Nederlandse formuleringen
- Een volledige docs build voor locale `nl` draaien zodra de docs dependencies beschikbaar zijn
