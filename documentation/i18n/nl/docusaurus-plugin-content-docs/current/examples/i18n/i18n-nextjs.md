Met Refine i18n Provider kun je meerdere taalkeuzes aan je webapplicatie toevoegen. De standaardtaal van Refine is Engels. Je kunt je eigen vertaling voor verschillende taalvoorkeuren in het project opnemen en gebruiken. Dit voorbeeld laat zien hoe je verschillende taalopties en vertalingen in de praktijk gebruikt.
