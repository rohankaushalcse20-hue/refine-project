`useEditableTable` bevat alle mogelijkheden van [`useTable`](/core/docs/ui-integrations/ant-design/hooks/use-table/). Naast deze voordelen kun je er ook je Table mee bewerken. De hook retourneert props voor Ant Design [Table](https://ant.design/components/table/#API) en [Form](https://ant.design/components/form/#API) componenten.
