`useDeleteMany` is een van de data hooks van Refine. De hook verwijdert meer dan een record uit de database. In dit scenario gebruiken we de `useDeleteMany` hook om meerdere records uit onze tabel te verwijderen. In je tabel kun je meerdere records verwijderen door ze te selecteren en op delete te drukken. Bekijk het voorbeeld voor meer informatie.
