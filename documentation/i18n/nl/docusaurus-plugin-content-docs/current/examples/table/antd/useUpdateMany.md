`useUpdateMany` is een van de data hooks van Refine. De hook voert het proces uit om meer dan een record bij te werken. In dit voorbeeld gebruiken we de `useUpdateMany` hook om meerdere records in de tabel te bewerken. Je kunt meer dan een record bewerken door de rijen te selecteren die je in je tabel wilt aanpassen. Bekijk het voorbeeld voor meer informatie.
