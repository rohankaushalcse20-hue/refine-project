Je kunt Google Login gebruiken om toegang te beheren en identiteit aan je app te leveren. Dit voorbeeld begeleidt je bij het verbinden van Google Login met je project via Refine.

:::note

Als je je eigen OAuth-applicatie ontwikkelt, is het belangrijk om de URL's van zowel je gedeployde applicatie als je lokale ontwikkelomgeving toe te voegen aan de lijst met toegestane origins in de instellingen van de OAuth-app. Doe je dat niet, dan kan de app falen.

Voor meer gedetailleerde begeleiding kan deze [videotutorial](https://www.youtube.com/watch?v=HtJKUQXmtok) nuttig zijn.

:::
