## Qu'est-ce que Refine ?

**Refine** est un meta-framework React pour les applications web riches en opérations CRUD. Il répond aux besoins des outils internes, panels d'administration, dashboards et applications B2B.

Ses hooks et composants principaux accélèrent le développement avec des solutions standard pour **l'authentification**, le **contrôle d'accès**, le **routing**, le **networking**, la **gestion d'état** et **l'i18n**.

L'architecture headless de Refine sépare la logique métier de l'interface et du routage. Vous pouvez donc utiliser vos propres designs, Tailwind CSS, Ant Design, Material UI, Mantine, Chakra UI, Next.js, Remix, React Native ou Electron.

## Pourquoi utiliser Refine ?

Refine se situe entre le développement entièrement from scratch et les solutions low-code/no-code. Il garde la flexibilité des technologies ouvertes tout en apportant des conventions qui réduisent les retards, la dette technique et les problèmes de maintenance.

## Cas d'usage

Refine est particulièrement adapté aux applications orientées données : panels d'administration, dashboards opérationnels, outils internes et applications B2B.

## Fonctionnalités clés

- Devtools pour inspecter l'application.
- Connecteurs REST API, GraphQL, NestJS CRUD, Airtable, Strapi, Supabase, Hasura, Appwrite, Firebase, Nestjs-Query et Directus.
- Support SSR avec Next.js et Remix.
- Génération d'interfaces CRUD depuis la structure de l'API.
- Gestion d'état et mutations avec TanStack Query.
- Providers pour auth, permissions, notifications, temps réel et audit logs.
