## Qu'est-ce que Refine ?

**Refine** est un méta-framework React pour les applications web riches en opérations CRUD. Il cible les outils internes, panels d'administration, dashboards et applications B2B.

Ses hooks et composants principaux réduisent le code répétitif en fournissant des solutions standard pour **l'authentification**, **le contrôle d'accès**, **le routing**, **le networking**, **la gestion d'état** et **l'i18n**.

L'architecture headless de Refine sépare la logique métier de l'UI et du routing. Vous pouvez donc l'associer à vos propres designs, à Tailwind CSS, Ant Design, Material UI, Mantine ou Chakra UI, ainsi qu'à Next.js, Remix, React Native ou Electron.

## Pourquoi utiliser Refine ?

Refine occupe l'espace entre un développement entièrement sur mesure et une plateforme low-code/no-code. Il conserve la flexibilité des technologies ouvertes tout en apportant des conventions qui limitent les retards, la dette technique, les problèmes de maintenance et le manque de standardisation.

Les solutions low-code peuvent accélérer certains écrans, mais elles créent souvent du verrouillage fournisseur, peu d'options de personnalisation et une expérience développeur plus faible. Refine fournit une base productive sans imposer une architecture fermée.

## Cas d'usage

**Refine** est particulièrement adapté aux applications intensives en données :

- Panels d'administration.
- Dashboards opérationnels.
- Outils internes.
- Applications B2B avec workflows CRUD.

## Fonctionnalités clés

- Devtools pour inspecter l'application et comprendre les requêtes.
- Connecteurs pour REST API, GraphQL, NestJS CRUD, Airtable, Strapi, Supabase, Hasura, Appwrite, Firebase, Nestjs-Query et Directus.
- Support SSR avec Next.js et Remix.
- Génération d'interfaces CRUD à partir de la structure de l'API.
- Gestion d'état et mutations avec TanStack Query.
- Providers pour authentification, autorisation, notifications, temps réel et audit logs.
