**Refine** fonctionne dans tout environnement capable d'exécuter **React**, notamment Vite, Next.js, Remix et CRA.

Vous pouvez installer les packages manuellement, mais la méthode recommandée est d'utiliser le scaffolder navigateur ou la CLI. Les deux permettent de choisir le framework, l'UI, le data provider, l'authentification et l'i18n.

## Utiliser la CLI

```sh
npm create refine-app@latest
```

Répondez aux questions, ouvrez le dossier généré, installez les dépendances si nécessaire et lancez le serveur de développement avec la commande indiquée.

## Utiliser le navigateur

Le scaffolder navigateur propose les mêmes décisions principales que la CLI et permet de prévisualiser le résultat avant téléchargement.
