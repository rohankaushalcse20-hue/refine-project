`useDeleteMany` est l'un des hooks de données de Refine. Il supprime plusieurs données dans la base. Dans ce scénario, nous utilisons le hook `useDeleteMany` pour supprimer plusieurs enregistrements d'une table. Vous pouvez supprimer plusieurs lignes de votre table en les sélectionnant puis en lançant la suppression. Consultez l'exemple pour en savoir plus.

[Consultez la documentation du hook de données Refine useDeleteMany pour plus d'informations. →](/core/docs/data/hooks/use-delete/)
