Vous pouvez utiliser le hook `useTable` pour traiter vos données avec des fonctionnalités compatibles avec le composant [Table](https://ant.design/components/table/) d'Ant Design. Il fournit directement le tri, le filtrage et la pagination sans nécessiter d'opérations supplémentaires.
