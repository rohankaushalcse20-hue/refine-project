`useUpdateMany` est l'un des hooks de données de Refine. Il met à jour plusieurs données. Dans cet exemple, nous utilisons le hook `useUpdateMany` pour modifier plusieurs données dans la table. Vous pouvez modifier plusieurs lignes en sélectionnant celles que vous voulez mettre à jour. Consultez l'exemple pour en savoir plus.
