Le hook `useStepsForm` vous permet de diviser votre formulaire en plusieurs sections avec un composant Ant Design [Steps](https://ant.design/components/steps/), qui peut servir à gérer le formulaire. Si votre formulaire comporte plusieurs étapes, comme dans l'exemple ci-dessous, il est simple de gérer ce flux avec le hook Refine `useStepsForm`.

[Consultez la documentation du hook Refine useStepsForm pour plus d'informations. →](/core/docs/ui-integrations/ant-design/hooks/use-steps-form/)
