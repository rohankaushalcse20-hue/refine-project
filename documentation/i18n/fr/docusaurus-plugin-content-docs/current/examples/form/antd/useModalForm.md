Avec le hook `useModalForm`, vous pouvez gérer un formulaire à l'intérieur de votre composant modal. Il renvoie les props du [Form Ant Design](https://ant.design/components/form/) et de la [Modal](https://ant.design/components/modal/). Vous pouvez examiner le code ci-dessous pour apprendre à créer et gérer des formulaires dans une modal.

[Consultez la documentation du hook Refine useModalForm pour plus d'informations. →](/core/docs/ui-integrations/ant-design/hooks/use-modal-form/)
