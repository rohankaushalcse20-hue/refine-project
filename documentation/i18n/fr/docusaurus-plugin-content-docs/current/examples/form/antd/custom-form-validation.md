Vous pouvez ajouter des validations de base aux formulaires créés avec Refine grâce à la propriété rules de [Form.Item](https://ant.design/components/form/#Form.Item) d'Ant Design. Vous pouvez aussi définir les validations personnalisées dont vous avez besoin. Il est très simple d'ajouter vos propres règles et validations avec la fonction validator dans la propriété rules de Form.Item. Dans l'exemple ci-dessous, un processus de validation personnalisée est expliqué en détail.

[Consultez la documentation Refine sur la validation de formulaire personnalisée pour plus d'informations. →](/core/docs/ui-integrations/ant-design/hooks/use-steps-form/)
