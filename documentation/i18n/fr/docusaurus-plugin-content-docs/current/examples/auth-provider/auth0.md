[Auth0](https://auth0.com/) est un service modulaire d'authentification et d'autorisation conçu API-first, que vous pouvez utiliser pour ajouter l'authentification et l'autorisation à vos applications. Dans cet exemple, vous verrez comment utiliser Auth0 Login avec Refine.

[Consultez le guide Refine Auth0 Login pour plus d'informations. →](/core/docs/advanced-tutorials/auth/auth0/)

L'exemple Auth0 ne fonctionne pas en mode d'intégration CodeSandbox. Avec [ce lien](https://cv8k99.csb.app/), vous pouvez ouvrir l'exemple dans le navigateur et l'essayer.
