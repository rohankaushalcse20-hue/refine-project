Vous pouvez utiliser Google Login pour contrôler l'accès et fournir une identité à votre application. Cet exemple vous guide dans l'intégration de Google Login à votre projet avec Refine.

:::note

Si vous développez votre propre application OAuth, il est important d'ajouter les URLs de votre application déployée et de votre environnement de développement local à la liste des origines autorisées dans les réglages de l'application OAuth. Sans cela, l'application peut échouer.

Pour des explications plus détaillées, ce [tutoriel vidéo](https://www.youtube.com/watch?v=HtJKUQXmtok) peut vous aider.

:::
