[Kinde](https://kinde.com/) est un service qui simplifie l'authentification et l'autorisation en proposant plusieurs méthodes au choix. Dans cet exemple, vous verrez comment utiliser Kinde Login avec Refine.

L'exemple Kinde ne fonctionne pas en mode d'intégration CodeSandbox, car il doit ajouter les URLs de callback à une liste blanche. Avec [ce lien](https://xnv6hq-5173.csb.app/), vous pouvez ouvrir l'exemple dans le navigateur et l'essayer.
