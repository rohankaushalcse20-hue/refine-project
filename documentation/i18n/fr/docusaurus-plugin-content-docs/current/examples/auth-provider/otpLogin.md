Un mot de passe à usage unique (OTP) possède deux propriétés fondamentales : il expire rapidement et il ne peut pas être réutilisé. Les OTP sont généralement des chaînes numériques ou alphanumériques générées pour une seule procédure de connexion. Cet exemple montre comment exploiter une logique de saisie OTP avec Refine. Vous pouvez utiliser les mots de passe à usage unique pour accéder à votre application avec Refine [AuthProvider](/core/docs/authentication/auth-provider/).
