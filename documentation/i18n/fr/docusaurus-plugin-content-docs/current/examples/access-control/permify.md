Le contrôle d'accès désigne les méthodes et processus utilisés pour restreindre l'accès à certaines parties d'une application web ou d'un site selon les permissions de l'utilisateur. Il garantit que les utilisateurs interagissent uniquement avec les contenus et fonctionnalités qu'ils sont autorisés à utiliser, ce qui renforce la sécurité et l'expérience utilisateur.

Cet exemple montre comment utiliser Refine et [Permify](https://permify.co/) pour simplifier la gestion du contrôle d'accès dans toute votre application.

[Consultez la documentation du Refine Access Control Provider pour plus d'informations. →](/core/docs/authorization/access-control-provider/)
