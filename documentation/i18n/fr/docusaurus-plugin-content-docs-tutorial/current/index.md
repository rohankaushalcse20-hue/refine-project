Le tutoriel Refine guide la construction d'une application CRUD complète. Le parcours configure les resources, providers, routes, formulaires, tables et flux d'authentification.

## Ce que vous apprendrez

- Créer une application Refine depuis une base propre.
- Connecter un data provider à une API.
- Définir resources et routes.
- Construire des pages de liste, création, édition et détail.
- Ajouter authentification, autorisation et i18n quand le projet en a besoin.

## Comment utiliser cette traduction

Les noms de packages, imports, commandes et extraits de code restent en anglais afin de correspondre à l'API réelle. Les explications et notes d'accompagnement sont localisées en français pour faciliter l'apprentissage.
