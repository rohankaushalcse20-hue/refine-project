Le tutoriel Refine accompagne la création d'une application CRUD complète. Vous y configurez resources, providers, routing, formulaires, tables et flux d'authentification.

## Ce que vous apprendrez

- Créer une application Refine depuis une base propre.
- Connecter un data provider à une API.
- Définir resources et routes.
- Construire les pages liste, création, édition et détail.
- Ajouter authentification, autorisation et i18n selon les besoins.

Les noms de packages, imports, commandes et exemples de code restent en anglais pour correspondre à l'API réelle; les explications sont localisées en français.
