**Refine** può essere eseguito in qualsiasi ambiente che supporti **React**, inclusi _Vite_, _Next.js_, _Remix_ e altri setup React.

## Usare la CLI

Il modo più veloce per iniziare è `create-refine-app`, perché prepara un nuovo progetto con le opzioni di UI framework, router e data provider di cui hai bisogno.

```sh
npm create refine-app@latest
```

Dopo il completamento del comando, entra nella cartella generata, installa le dipendenze e avvia il development server.

## Usare lo scaffolder nel browser

Se vuoi vedere le opzioni di configurazione prima di scaricare il progetto, usa lo strumento di creazione nel browser. L'esperienza è interattiva e offre opzioni simili alla CLI.

## Dopo la creazione del progetto

- Segui [Tutorials](/core/tutorial) per trasformare il progetto iniziale in un'applicazione CRUD completa.
- Leggi [General Concepts](/core/docs/guides-concepts/general-concepts/) e [Data Fetching](/core/docs/guides-concepts/data-fetching/) per capire la struttura di base.
- Esplora gli esempi pronti se vuoi partire da uno scenario vicino a un prodotto reale.
