L'access control comprende metodi e processi usati per limitare l'accesso a determinate parti di un'applicazione web o di un sito in base ai permessi dell'utente. Garantisce che gli utenti possano interagire solo con contenuti e funzionalità per cui sono autorizzati, migliorando sicurezza ed esperienza d'uso.

Questo esempio mostra come usare Refine e [Permify](https://permify.co/) per semplificare la gestione del controllo degli accessi in tutta l'applicazione.

[Consulta la documentazione di Refine Access Control Provider per maggiori informazioni. →](/core/docs/authorization/access-control-provider/)
