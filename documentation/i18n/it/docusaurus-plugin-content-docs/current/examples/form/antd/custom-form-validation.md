Puoi creare validazioni di base con la proprietà rules di Ant Design [Form.Item](https://ant.design/components/form/#Form.Item) sui form creati con Refine. Inoltre, puoi aggiungere le validazioni personalizzate che vuoi o di cui hai bisogno. È molto semplice aggiungere regole e validazioni personalizzate usando la funzione validator nella proprietà rules di Form.Item. Nell'esempio seguente viene spiegato in dettaglio un processo di validazione form personalizzato.
