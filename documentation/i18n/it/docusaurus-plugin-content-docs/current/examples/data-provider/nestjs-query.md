Il Data Provider Refine [Nestjs-Query](https://tripss.github.io/nestjs-query/) ti permette di usare i dati sul frontend collegandoti alla tua API GraphQL Nestjs-Query. Con Refine queste operazioni vengono gestite senza scrivere codice aggiuntivo per le query. Esaminando questo esempio puoi imparare a usare il Data Provider Nestjs-Query Crud.
