Una one-time password (OTP) è una password con due proprietà fondamentali: scade rapidamente e non può essere riutilizzata. Le OTP sono di solito stringhe numeriche o alfanumeriche generate per una singola procedura di login. Questo esempio mostra come usare la logica di input OTP con Refine. Puoi usare one-time passwords per accedere alla tua applicazione con Refine [AuthProvider](/core/docs/authentication/auth-provider/).
