Puoi usare Google Login per controllare l'accesso e fornire un'identità alla tua app. Questo esempio ti guiderà nel collegare Google Login al tuo progetto usando Refine.

:::note

Se stai sviluppando una tua applicazione OAuth, è importante aggiungere gli URL sia dell'applicazione distribuita sia dell'ambiente di sviluppo locale all'elenco delle origini consentite nelle impostazioni dell'app OAuth. In caso contrario l'app può non funzionare.

Per indicazioni più dettagliate, può essere utile questo [video tutorial](https://www.youtube.com/watch?v=HtJKUQXmtok).

:::
