`useUpdateMany` è uno degli hooks dati di Refine. Esegue l'aggiornamento di più record. In questo esempio abbiamo usato l'hook `useUpdateMany` per modificare più dati nella tabella. Puoi modificare più record selezionando le righe che vuoi aggiornare nella tabella. Puoi ottenere maggiori informazioni esaminando l'esempio.
