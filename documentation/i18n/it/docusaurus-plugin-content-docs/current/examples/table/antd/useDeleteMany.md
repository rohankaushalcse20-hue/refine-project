`useDeleteMany` è uno degli hooks dati di Refine. Rimuove più record dal database. In questo scenario abbiamo usato l'hook `useDeleteMany` per rimuovere più record dalla tabella. Nella tua tabella puoi eliminare più record selezionandoli e premendo delete. Puoi ottenere maggiori informazioni esaminando l'esempio.
