Il tutorial di Refine ti guida nella creazione di un'applicazione CRUD completa e mostra come resources, providers, routing, forms, tables e authentication lavorano insieme nello stesso progetto.

## Cosa imparerai?

- Creare un'applicazione Refine da zero
- Collegare un'API con un data provider
- Definire resources e routes
- Costruire pagine list, create, edit e show
- Aggiungere authentication, authorization e i18n quando necessario

Nomi di package, imports, commands e code examples restano in inglese per rimanere coerenti con l'API originale; spiegazioni e contesto didattico sono localizzati in italiano.
