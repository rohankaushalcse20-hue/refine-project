Das Refine-Tutorial fuehrt dich durch den Aufbau einer vollstaendigen CRUD-Anwendung. Dabei lernst du Resources, Provider, Routing, Formulare, Tabellen und Authentifizierungsablaeufe kennen.

## Das lernst du

- Eine Refine-App von Grund auf aufsetzen.
- Einen Data Provider mit einer API verbinden.
- Resources und Routen definieren.
- Listen-, Create-, Edit- und Show-Seiten bauen.
- Bei Bedarf Authentifizierung, Autorisierung und i18n ergaenzen.

Paketnamen, Imports, Befehle und Codebeispiele bleiben auf Englisch, damit sie mit der realen API uebereinstimmen. Die erklaerenden Inhalte sind auf Deutsch lokalisiert.
