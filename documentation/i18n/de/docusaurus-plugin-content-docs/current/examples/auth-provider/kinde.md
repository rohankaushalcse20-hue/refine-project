Das Kinde-Beispiel funktioniert nicht im eingebetteten CodeSandbox-Modus, weil Callback-URLs auf die Allowlist gesetzt werden muessen. Mit [diesem](https://xnv6hq-5173.csb.app/) Link kannst du das Beispiel im Browser oeffnen und ausprobieren.
