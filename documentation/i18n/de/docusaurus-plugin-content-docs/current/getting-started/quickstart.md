**Refine** funktioniert in jeder Umgebung, in der **React** laeuft, zum Beispiel mit Vite, Next.js, Remix oder CRA.

Du kannst die Pakete auch manuell installieren, aber fuer den Einstieg ist der Browser-Scaffolder oder der CLI-Scaffolder der schnellste Weg. Beide Varianten helfen dir dabei, Framework, UI-Integration, Data Provider, Authentifizierung und i18n passend auszuwaehlen.

## Mit der CLI starten

Fuehre `create-refine-app` aus, um schnell ein neues **Refine**-Projekt aufzusetzen:

```sh
npm create refine-app@latest
```

Folge den CLI-Prompts, wechsle danach in das erzeugte Verzeichnis, installiere bei Bedarf die Dependencies und starte den vorgeschlagenen Dev-Server.

## Mit dem Browser starten

Der Browser-Scaffolder bietet dieselben Kernoptionen wie die CLI und zeigt dir vor dem Download eine Vorschau des Projekts.
