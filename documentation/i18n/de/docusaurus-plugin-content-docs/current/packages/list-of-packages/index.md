- `@refinedev/core` - Sammlung aus `hooks`, `components` und `providers` fuer **Authentifizierung**, **Autorisierung**, **Routing**, **Networking**, **State Management** und **i18n**. Der Ausgangspunkt fuer headless Projekte.
- `@refinedev/inferencer` - Erzeugt Views fuer Resources automatisch anhand der Datenstruktur und reduziert so den manuellen Aufbau von CRUD-Seiten.
- `@refinedev/cli` - CLI-Werkzeug fuer wichtige Arbeitsablaeufe waehrend der Entwicklung mit refine.

Mehr zu UI-Integrationen findest du im Leitfaden [UI-Bibliotheken](/core/docs/guides-concepts/ui-libraries/).

- [`@refinedev/antd`](/core/docs/ui-integrations/ant-design/introduction/) - Integration fuer [Ant Design](https://ant.design/).
- [`@refinedev/mui`](/core/docs/ui-integrations/material-ui/introduction/) - Integration fuer [Material UI](https://mui.com/material-ui/getting-started/overview/).
- [`@refinedev/mantine`](/core/docs/ui-integrations/mantine/introduction/) - Integration fuer [Mantine](https://mantine.dev/).
- [`@refinedev/chakra-ui`](/core/docs/ui-integrations/chakra-ui/introduction/) - Integration fuer [Chakra UI](https://chakra-ui.com/).
- [`@ferdiunal/refine-shadcn`](https://github.com/ferdiunal/refine-shadcn) - ShadCN-UI-Komponenten fuer Refine.

### Data-Provider-Pakete

Mehr dazu steht in der Dokumentation zu [Data Provider](/core/docs/data/data-provider/).

- [`@refinedev/simple-rest`](/core/docs/data/packages/simple-rest/) - Verbindet benutzerdefinierte **REST APIs**.
- [`@refinedev/graphql`](/core/docs/data/packages/graphql/) - Verbindet benutzerdefinierte **GraphQL APIs**.
- [`@refinedev/nestjsx-crud`](/core/docs/data/packages/nestjsx-crud/) - Nutzt **REST APIs** aus **NestJs**.
- [`@refinedev/nestjs-query`](/core/docs/data/packages/nestjs-query/) - Nutzt **GraphQL APIs** aus **Nestjs-Query**.
- [`@refinedev/strapi-v4`](/core/docs/data/packages/strapi-v4/) - Strapi-Connector fuer **REST API v4**.
- [`@refinedev/supabase`](/core/docs/data/packages/supabase/) - Data Provider fuer [Supabase](https://supabase.com/) mit Realtime-Support.

### Router- und Live-Pakete

- [`@refinedev/react-router`](/core/docs/routing/integrations/react-router/) - Router Provider fuer React Router.
- [`@refinedev/nextjs-router`](/core/docs/routing/integrations/next-js/) - Router Provider fuer Next.js.
- [`@refinedev/remix-router`](/core/docs/routing/integrations/remix/) - Router Provider fuer Remix.
- `@refinedev/ably`, `@refinedev/graphql`, `@refinedev/supabase` und weitere Pakete decken Realtime- oder Live-Szenarien ab.

### Community-Pakete

Das Refine-Oekosystem enthaelt ausserdem Community-Pakete fuer Firebase, Directus, PocketBase, JSON:API, PostgREST, Chakra UI v3 und weitere Integrationen.
