Tutorial Refine prowadzi przez budowę aplikacji CRUD od podstaw. Pokazuje, jak połączyć `resources`, `dataProvider`, routing, formularze, tabele i authentication w spójny przepływ pracy.

## Dla kogo jest ten tutorial?

Ten materiał jest przydatny, jeśli:

- zaczynasz pracę z Refine i chcesz zobaczyć pełny przepływ aplikacji;
- znasz React, ale chcesz zrozumieć architekturę providerów;
- budujesz panel admin, narzędzie wewnętrzne albo dashboard;
- chcesz sprawdzić, które części Refine są headless, a które zależą od biblioteki UI.

## Jak czytać tutorial?

Najlepiej przechodzić sekcje po kolei. Każdy etap dokłada jedną warstwę: strukturę aplikacji, zasoby, pobieranie danych, widoki list, formularze, routing i obsługę użytkownika.

## Co pozostaje bez tłumaczenia?

Nazwy pakietów, importy, komendy terminala, ścieżki URL, nazwy komponentów i identyfikatory API pozostają w oryginalnej formie. Tłumaczone są objaśnienia oraz tekst widoczny dla użytkownika dokumentacji.
