W sekcji Essentials zbudujesz fundament aplikacji Refine. Celem nie jest tylko uruchomienie przykładu, ale zrozumienie, jak poszczególne kontrakty współpracują w realnym przepływie CRUD.

## Co zbudujesz?

Tutorial pokazuje aplikację z zasobami, listami, formularzami i pobieraniem danych. Po drodze zobaczysz, gdzie trafia konfiguracja `resources`, jak działa `dataProvider` i w jaki sposób Refine przekazuje dane do komponentów UI.

## Wymagania

Przyda się podstawowa znajomość React, TypeScript i pracy z terminalem. Nie musisz znać wcześniej Refine ani konkretnej biblioteki UI, ponieważ tutorial wyjaśnia rolę każdej warstwy.

## Najważniejsze pojęcia

- `Refine` to główny komponent konfigurujący aplikację.
- `resources` opisują encje domenowe i ich ścieżki.
- `dataProvider` tłumaczy operacje Refine na wywołania API.
- Hooki, takie jak `useTable` i `useForm`, łączą logikę danych z UI.

## Jak pracować z kodem?

Przepisuj komendy i fragmenty kodu bez tłumaczenia nazw pakietów, importów ani identyfikatorów. Tłumaczone są komentarze i objaśnienia, ale kod powinien pozostać zgodny z oryginalnym API Refine.

## Dalej
