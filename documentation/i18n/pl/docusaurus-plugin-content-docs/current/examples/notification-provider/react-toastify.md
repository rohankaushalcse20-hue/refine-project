Dzięki Refine Notification Provider możesz pokazywać komunikaty powiadomień w dowolnym miejscu aplikacji. Mogą to być ostrzeżenia lub błędy sugerujące działanie i pomagające utrzymać zaangażowanie użytkownika w funkcje aplikacji. Możesz użyć dowolnej biblioteki powiadomień i zarządzać nimi przez hook `useNotification` Refine. W tym przykładzie użyliśmy biblioteki [React Toastify](https://github.com/fkhadra/react-toastify) do wyświetlania powiadomień.

[Więcej informacji znajdziesz w dokumentacji Refine Notification Provider. →](/core/docs/notification/notification-provider/)
