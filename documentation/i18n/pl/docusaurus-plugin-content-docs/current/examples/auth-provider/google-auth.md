Możesz użyć Google Login, aby kontrolować dostęp i dostarczać tożsamość użytkownika w aplikacji. Ten przykład przeprowadzi Cię przez podłączenie Google Login do projektu z użyciem Refine.

:::note

Jeśli tworzysz własną aplikację OAuth, dodaj adresy URL zarówno wdrożonej aplikacji, jak i lokalnego środowiska deweloperskiego do listy dozwolonych origins w ustawieniach aplikacji OAuth. Brak tej konfiguracji może spowodować błąd działania aplikacji.

Bardziej szczegółowe wskazówki znajdziesz w tym pomocnym [wideo tutorialu](https://www.youtube.com/watch?v=HtJKUQXmtok).

:::
