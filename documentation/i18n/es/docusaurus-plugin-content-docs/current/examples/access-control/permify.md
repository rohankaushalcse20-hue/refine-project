El control de acceso se refiere a los metodos y procesos usados para restringir el acceso a ciertas partes de una aplicacion web o sitio web segun los permisos del usuario. Garantiza que los usuarios solo puedan interactuar con el contenido y las funciones para las que estan autorizados, lo que mejora la seguridad y la experiencia de usuario.

Este ejemplo muestra como usar Refine y [Permify](https://permify.co/) para simplificar la gestion del control de acceso en toda tu aplicacion.

[Consulta la documentacion de Refine Access Control Provider para mas informacion. →](/core/docs/authorization/access-control-provider/)
