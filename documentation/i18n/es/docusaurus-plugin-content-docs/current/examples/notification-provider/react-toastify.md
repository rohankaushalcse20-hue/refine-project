Con Refine Notification Provider, puedes mostrar mensajes de notificacion en cualquier parte de tu aplicacion. Pueden ser advertencias o errores que recomiendan una accion y ayudan a mantener la interaccion del usuario con la funcionalidad de la app. Puedes usar cualquier biblioteca de notificaciones y gestionarla con el hook `useNotification` de Refine. En este ejemplo usamos la biblioteca [React Toastify](https://github.com/fkhadra/react-toastify) para mostrar notificaciones.

[Consulta la documentacion de Refine Notification Provider para mas informacion. →](/core/docs/notification/notification-provider/)
