Una contrasena de un solo uso (OTP) es una contrasena con dos propiedades fundamentales: expira rapidamente y no puede reutilizarse. Las OTP suelen ser cadenas numericas o alfanumericas y se generan para un unico procedimiento de inicio de sesion. Este ejemplo muestra como utilizar logica de entrada OTP con Refine. Puedes usar contrasenas de un solo uso para acceder a tu aplicacion con Refine [AuthProvider](/core/docs/authentication/auth-provider/).
