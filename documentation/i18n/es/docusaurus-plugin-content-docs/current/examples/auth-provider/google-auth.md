Puedes usar Google Login para controlar el acceso y aportar identidad a tu aplicación. Este ejemplo te guía paso a paso para conectar Google Login a tu proyecto usando Refine.

:::note

Si estás desarrollando tu propia aplicación OAuth, es importante añadir las URL tanto de tu aplicación desplegada como de tu entorno local a la lista de orígenes permitidos en la configuración de OAuth. Si no lo haces, la aplicación puede fallar.

Si quieres una guía más detallada, este [video tutorial](https://www.youtube.com/watch?v=HtJKUQXmtok) puede resultarte útil.

:::
