El i18n Provider de Refine te permite añadir varias opciones de idioma a tu aplicación web. El idioma predeterminado de Refine es el inglés, pero puedes incluir y usar tus propias traducciones para diferentes preferencias lingüísticas. Este ejemplo muestra en la práctica cómo trabajar con varios idiomas y traducciones.

[Consulta la documentación del i18n Provider de Refine para más información. →](/core/docs/i18n/i18n-provider/)
