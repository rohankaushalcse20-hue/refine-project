El Data Provider de [Elide](https://elide.io/) te permite llamar a una API JSON de backend Elide. El data provider de Elide construye las consultas que una aplicacion Elide puede entender, asi que ya hicimos el trabajo duro por ti. Este ejemplo muestra como utilizar Refine Elide Provider en este proyecto.

[Ver el codigo fuente del ejemplo de Elide](https://github.com/chirdeeptomar/refine-elide-rest)

Elide Data Provider esta desarrollado por la comunidad. Queremos agradecer a [chirdeeptomar](https://github.com/chirdeeptomar/refine-elide-rest) por su interes y contribucion.
