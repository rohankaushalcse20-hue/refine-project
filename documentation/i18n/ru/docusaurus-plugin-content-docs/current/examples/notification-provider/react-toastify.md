С Refine Notification Provider можно показывать уведомления в любой части приложения. Это могут быть предупреждения или ошибки, которые подсказывают действие и помогают пользователю оставаться в рабочем flow приложения. Вы можете использовать любую библиотеку уведомлений и управлять ей через hook `useNotification` из Refine. В этом примере используется библиотека [React Toastify](https://github.com/fkhadra/react-toastify).

[Подробнее смотрите в документации Refine Notification Provider. →](/core/docs/notification/notification-provider/)
