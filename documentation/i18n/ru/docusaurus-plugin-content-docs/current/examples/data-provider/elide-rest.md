[Elide](https://elide.io/) Data Provider позволяет вызывать JSON API backend на Elide. Elide Data Provider строит запросы, которые понимает Elide Application, поэтому сложная часть уже сделана за вас. Этот пример показывает, как использовать Refine Elide Provider в проекте.

[Посмотреть исходный код примера Elide](https://github.com/chirdeeptomar/refine-elide-rest)
