Refine [Nestjs-Query](https://tripss.github.io/nestjs-query/) Data Provider позволяет использовать данные на frontend, подключаясь к вашему Nestjs-Query GraphQL API. С Refine эти операции выполняются без необходимости писать дополнительный код для запросов. Изучив этот пример, вы узнаете, как использовать Nestjs-Query Crud Data Provider.
