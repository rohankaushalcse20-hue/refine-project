Одноразовый пароль (OTP) имеет два ключевых свойства: он быстро истекает и не может быть использован повторно. OTP обычно представляет собой числовую или буквенно-цифровую строку и генерируется для одной процедуры входа. Этот пример показывает, как использовать логику OTP-ввода с Refine. Одноразовые пароли можно применять для доступа к приложению через Refine [AuthProvider](/core/docs/authentication/auth-provider/).
