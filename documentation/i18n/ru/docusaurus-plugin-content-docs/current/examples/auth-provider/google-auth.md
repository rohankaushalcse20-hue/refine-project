Google Login можно использовать, чтобы управлять доступом и предоставлять идентификацию в приложении. Этот пример проведет вас через подключение Google Login к проекту с помощью Refine.

:::note

Если вы разрабатываете собственное OAuth-приложение, важно добавить URL-адреса развернутого приложения и локальной среды разработки в список разрешенных origins в настройках OAuth-приложения. Иначе приложение может не запуститься.

Более подробные инструкции можно найти в этом полезном [видеоруководстве](https://www.youtube.com/watch?v=HtJKUQXmtok).

:::
