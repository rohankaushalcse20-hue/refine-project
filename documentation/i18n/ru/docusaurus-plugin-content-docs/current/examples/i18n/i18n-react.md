Refine i18n Provider позволяет добавить в web application выбор нескольких языков. Язык по умолчанию в Refine — English. Вы можете подключить собственные переводы и использовать их в проекте для разных языковых предпочтений. Этот пример показывает, как применять языковые варианты и переводы на практике.
