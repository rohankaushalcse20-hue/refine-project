يرشدك Tutorial الخاص بـ Refine خلال بناء تطبيق CRUD متكامل، مع شرح كيف تعمل resources وproviders وrouting وforms وtables وauthentication معاً داخل مشروع واحد.

## ماذا ستتعلّم؟

- إنشاء تطبيق Refine من البداية
- ربط الـ API مع data provider
- تعريف resources وroutes
- بناء صفحات list وcreate وedit وshow
- إضافة authentication وauthorization وi18n حسب الحاجة

تبقى أسماء الحزم وimports وcommands وcode examples باللغة الإنجليزية حتى تطابق الـ API الحقيقي، بينما تُرجمت الشروحات والسياقات التعليمية إلى العربية.
