## ما هو Refine؟

**Refine** هو React meta-framework للتطبيقات التي تعتمد بكثافة على CRUD. يساعد على بناء لوحات الإدارة، الأدوات الداخلية، لوحات المعلومات وتطبيقات B2B مع الحفاظ على مرونة اختيار الـ UI والـ routing.

يوفر Refine hooks وcomponents وproviders تغطي الجوانب الأساسية للمشروع مثل **authentication** و**access control** و**routing** و**networking** و**state management** و**i18n**.

## لماذا يستخدمه الفريق؟

Refine يحاول أخذ أفضل ما في التطوير التقليدي وحلول low-code/no-code من دون القيود المعتادة لكل طرف. بدلاً من إعادة بناء نفس طبقات CRUD في كل مشروع، يمكنك البدء ببنية واضحة ثم تخصيصها بحسب احتياجات المنتج.

## بنية Headless

المنصة headless بطبيعتها، لذلك تبقى منطق الأعمال منفصلة عن طبقة العرض. هذا يسمح لك باستخدام Tailwind CSS أو Ant Design أو Material UI أو Mantine أو Chakra UI أو أي design system خاص بك.

## حالات الاستخدام

Refine مناسب خصوصاً للتطبيقات الغنية بالبيانات مثل admin panels وdashboards وinternal tools، لكنه يظل مرناً بما يكفي لبناء تطبيقات موجهة للمستخدم النهائي عند الحاجة.
