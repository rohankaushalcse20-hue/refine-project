**Refine** يعمل في أي بيئة تستطيع تشغيل **React** فيها، بما يشمل _Vite_ و_Next.js_ و_Remix_ وغيرها.

## استخدام CLI

أسرع طريقة للانطلاق هي `create-refine-app`، لأنه يجهّز مشروعاً جديداً مع خيارات متعددة تناسب الـ UI framework والـ router والـ data provider الذي تحتاجه.

```sh
npm create refine-app@latest
```

## استخدام Browser-based Scaffolder

إذا كنت تفضّل معاينة الإعدادات قبل تنزيل المشروع، فيمكنك استخدام أداة الإنشاء داخل المتصفح. وهي تقدم تقريباً نفس خيارات الـ CLI مع تجربة تفاعلية أسهل للاستكشاف الأولي.

## ما الذي تفعله بعد الإنشاء؟

- راجع [Tutorials](/core/tutorial) لتحويل المشروع المبدئي إلى تطبيق CRUD كامل.
- اقرأ دليلي [General Concepts](/core/docs/guides-concepts/general-concepts/) و[Data Fetching](/core/docs/guides-concepts/data-fetching/) لفهم البنية الأساسية.
- استكشف الأمثلة الجاهزة إذا أردت البدء من سيناريو قريب من منتجك الحقيقي.
