يمكنك استخدام Google Login للتحكم في الوصول وتوفير هوية للمستخدمين داخل تطبيقك. يرشدك هذا المثال إلى كيفية ربط Google Login بمشروعك باستخدام Refine.

:::note

إذا كنت تطوّر تطبيق OAuth خاصاً بك، فمن المهم إضافة روابط تطبيقك المنشور وبيئة التطوير المحلية إلى قائمة المصادر المسموح بها في إعدادات تطبيق OAuth. عدم القيام بذلك قد يؤدي إلى فشل التطبيق.

لإرشادات أكثر تفصيلاً، قد يفيدك هذا [الفيديو التعليمي](https://www.youtube.com/watch?v=HtJKUQXmtok).

:::
