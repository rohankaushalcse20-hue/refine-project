كلمة المرور لمرة واحدة (OTP) هي كلمة مرور لها خاصيتان أساسيتان: تنتهي صلاحيتها بسرعة، ولا يمكن إعادة استخدامها. عادةً تكون OTP سلسلة رقمية أو أبجدية رقمية ويتم توليدها لإجراء تسجيل دخول واحد. يوضح هذا المثال كيفية استخدام منطق إدخال OTP مع Refine. يمكنك استخدام كلمات المرور لمرة واحدة للوصول إلى تطبيقك مع Refine [AuthProvider](/core/docs/authentication/auth-provider/).
