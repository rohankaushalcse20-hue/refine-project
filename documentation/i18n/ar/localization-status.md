# حالة التغطية المحلية للعربية

يلخّص هذا الملف ما يغطيه locale `ar` حالياً وما تمت إضافته في هذه الدفعة.

## المحتوى المتوفر

- إعداد locale العربي في Docusaurus
- رسائل واجهة الاستخدام الافتراضية
- صفحات getting started الأساسية
- أدلة general concepts وrouting وdata fetching وauthentication وauthorization وforms وtables وnotifications وi18n
- الصفحة الافتتاحية للـ tutorial ومقدمة الأساسيات
- ملفات README العربية لأمثلة i18n وMaterial UI template
- ملفات README المختصرة لحزمتي `core` و`simple-rest`
- ملفات README عربية مختصرة لحزم data providers وUI integrations وrouter/form/dev tooling الشائعة مثل `@refinedev/ably` و`@refinedev/antd` و`@refinedev/mui` و`@refinedev/react-router`
- أمثلة authentication لواجهات Ant Design وChakra UI وHeadless وMantine وMaterial UI
- أمثلة forms الخاصة بـ Ant Design: custom validation وserver-side validation وhooks `useForm` و`useDrawerForm` و`useModalForm` و`useStepsForm`
- أمثلة tables الخاصة بـ Ant Design: advanced table وtable filters وhooks `useTable` و`useEditableTable` و`useDeleteMany` و`useUpdateMany`
- أمثلة themes الخاصة بـ Ant Design وChakra UI

## الشرائح التالية المرشحة

- مزيد من أدلة المفاهيم المتقدمة وصفحات مرجع الـ API
- README لأمثلة UI frameworks وdata providers إضافية لم تُغطَّ بعد
- أمثلة themes المتبقية مثل Mantine وMaterial UI
- مراجعة عرض النصوص الطويلة في الوضع RTL داخل docs navigation
- تشغيل docs build على locale `ar` للتحقق من المسارات والتنقل
