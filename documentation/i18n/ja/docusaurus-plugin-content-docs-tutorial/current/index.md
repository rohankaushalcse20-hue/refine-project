Refine のチュートリアルでは、完全な CRUD アプリケーションを組み立てながら学習できます。進める中で resources、providers、routing、フォーム、テーブル、認証フローを順番に設定していきます。

## 学べること

- Refine アプリケーションをゼロから立ち上げる方法
- data provider を API に接続する方法
- resources と routes を定義する方法
- 一覧、作成、編集、詳細ページを組み立てる方法
- 必要に応じて認証、認可、i18n を追加する方法

## この翻訳の使い方

パッケージ名、imports、commands、コード断片は実際の API に合わせて英語のまま維持しています。解説や補足は、日本語で読みやすい形にローカライズしています。
