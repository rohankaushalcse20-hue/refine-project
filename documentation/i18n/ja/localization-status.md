# 日本語ローカライズのカバレッジ

このメモでは、`ja` ローカライズの現在の対象範囲と、今回追加したスライスをまとめています。

## 含まれる内容

- Docusaurus の `ja` locale 設定
- テーマの基本 UI メッセージ
- getting started の主要ページ
- routing、data fetching、認証、認可、フォーム、テーブル、通知、i18n に関する概念ガイド
- チュートリアルの導入ページと主要インデックス
- i18n examples と Material UI template の日本語 README
- Chakra UI、Mantine、Ant Design のフォーム、テーブル、Inferencer、import/export、サーバー側検証 examples の日本語 README
- `core` と `simple-rest` パッケージの日本語サマリー
- Refine エコシステムのパッケージ一覧ページの日本語版

## 今後の候補

- さらに多くの高度なガイドや API ページを翻訳する
- UI framework 別、backend provider 別の examples を増やす
- MUI のリダイレクト examples と blog 系 examples の README を日本語化する
- 狭い画面で長文、SEO metadata、スクリーンショットを見直す
- `ja` locale でドキュメント build を行い、サイト全体の導線を検証する
