## Refine とは

**Refine** は CRUD を多く含む Web アプリケーション向けの React メタフレームワークです。社内ツール、管理画面、ダッシュボード、B2B アプリケーションのような業務向けユースケースを想定して設計されています。

主要な `hooks` と `components` によって、**認証**、**アクセス制御**、**routing**、**networking**、**状態管理**、**i18n** のような共通課題を標準的な方法で扱えます。

Refine の headless アーキテクチャは、ビジネスロジックを UI とルーティングから切り離します。そのため、独自のデザインシステム、Tailwind CSS、Ant Design、Material UI、Mantine、Chakra UI、さらに Next.js、Remix、React Native、Electron などとも柔軟に組み合わせられます。

## Refine を使う理由

Refine は、すべてをゼロから作る方法と low-code/no-code 製品の中間に位置します。柔軟性やオープンな技術選択は維持しつつ、開発の遅延、技術的負債、保守負荷を減らすための規約と土台を提供します。

low-code 製品は初期構築を早められる一方で、ベンダーロックインやカスタマイズ性の制約、開発体験の低下につながることがあります。Refine は、生産性を高めながらもアーキテクチャを固定しません。

## ユースケース

**Refine** は、特にデータ中心のアプリケーションで力を発揮します。

- 管理画面
- 運用ダッシュボード
- 社内ツール
- CRUD フローを持つ B2B アプリケーション

## 主な機能

- アプリケーションを観察しやすくする Devtools
- REST API、GraphQL、NestJS CRUD、Airtable、Strapi、Supabase、Hasura、Appwrite、Firebase、Nestjs-Query、Directus 向けの connectors
- Next.js と Remix による SSR 対応
- API 構造をもとにした CRUD UI の生成
- TanStack Query を使った状態管理とミューテーション
- 認証、認可、通知、リアルタイム、監査向け providers
