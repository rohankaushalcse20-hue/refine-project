Trong phần Essentials, bạn sẽ xây nền tảng cho ứng dụng Refine. Mục tiêu không chỉ là chạy một ví dụ, mà còn hiểu cách các hợp đồng phối hợp trong luồng CRUD thực tế.

## Bạn sẽ xây gì?

Tutorial minh họa một ứng dụng có resources, danh sách, forms và lấy dữ liệu. Trong quá trình đó, bạn sẽ thấy cấu hình `resources` được đặt ở đâu, `dataProvider` hoạt động thế nào và Refine truyền dữ liệu vào components UI ra sao.

## Yêu cầu

Bạn nên có kiến thức cơ bản về React, TypeScript và làm việc với terminal. Không cần biết Refine hoặc một thư viện UI cụ thể từ trước, vì tutorial sẽ giải thích vai trò của từng lớp.

## Khái niệm chính

- `Refine` là component chính cấu hình ứng dụng.
- `resources` mô tả các thực thể miền nghiệp vụ và đường dẫn của chúng.
- `dataProvider` chuyển thao tác Refine thành lời gọi API.
- Hooks như `useTable` và `useForm` nối logic dữ liệu với UI.

## Làm việc với code như thế nào?

Hãy chép lệnh và đoạn code mà không dịch tên package, imports hoặc identifiers. Phần được dịch là nhận xét và giải thích; code phải giữ đúng API Refine gốc.

## Tiếp theo

Sau phần giới thiệu này, hãy chuyển sang các bước Essentials tiếp theo và xây ứng dụng từng phần nhỏ, có thể kiểm chứng.
