# Mức độ phủ bản địa hóa tiếng Việt

Tài liệu này tóm tắt mức độ phủ hiện tại của locale `vi` và các localization slice được thêm trong bản cập nhật này.

## Nội dung đã có

- Cấu hình locale tiếng Việt trong Docusaurus
- Thông báo UI mặc định cho Docusaurus theme
- Các trang getting started chính
- Guide general concepts, routing, data fetching, authentication, authorization, forms, tables, notifications và i18n
- Trang landing của tutorial và phần giới thiệu essentials
- README tiếng Việt cho ví dụ i18n và template Material UI
- Tóm tắt README tiếng Việt cho packages `core` và `simple-rest`

## Ứng viên cho slice tiếp theo

- Advanced tutorials và các trang API reference bổ sung
- README cho thêm ví dụ UI framework và data provider
- Rà soát metadata SEO và đoạn văn dài trên viewport hẹp
- Chạy docs build cho locale `vi` để xác minh routes và navigation
