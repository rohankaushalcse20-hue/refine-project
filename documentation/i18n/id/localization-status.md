# Cakupan lokalisasi Bahasa Indonesia

Dokumen ini merangkum cakupan locale `id` saat ini dan slice yang ditambahkan dalam pembaruan ini.

## Konten yang sudah tersedia

- Konfigurasi locale Bahasa Indonesia di Docusaurus
- Pesan UI default untuk theme Docusaurus
- Halaman inti getting started
- Panduan general concepts, routing, data fetching, authentication, authorization, forms, tables, notifications, dan i18n
- Halaman landing tutorial dan pendahuluan essentials
- README Bahasa Indonesia untuk contoh i18n dan template Material UI
- README ringkas Bahasa Indonesia untuk package `core` dan `simple-rest`
