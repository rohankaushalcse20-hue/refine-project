Kontrol akses merujuk pada metode dan proses yang digunakan untuk membatasi akses ke bagian tertentu dari aplikasi web atau situs web berdasarkan izin pengguna. Kontrol ini memastikan pengguna hanya dapat berinteraksi dengan konten dan fitur yang memang diizinkan untuk mereka gunakan, sehingga meningkatkan keamanan dan pengalaman pengguna.

Contoh ini menunjukkan cara menggunakan Refine dan [Permify](https://permify.co/) untuk menyederhanakan pengelolaan kontrol akses di seluruh aplikasi Anda.

[Lihat dokumentasi Refine Access Control Provider untuk informasi selengkapnya. →](/core/docs/authorization/access-control-provider/)
