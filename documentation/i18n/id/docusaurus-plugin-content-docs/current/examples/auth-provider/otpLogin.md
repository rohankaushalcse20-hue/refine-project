One-time password (OTP) adalah kata sandi yang memiliki dua sifat mendasar: cepat kedaluwarsa dan tidak dapat digunakan kembali. OTP biasanya berupa string numerik atau alfanumerik dan dibuat untuk satu prosedur login. Contoh ini menunjukkan cara memanfaatkan logika input OTP dengan Refine. Anda dapat menggunakan one-time password untuk mengakses aplikasi dengan Refine [AuthProvider](/core/docs/authentication/auth-provider/).
