Anda dapat menggunakan Google Login untuk mengontrol akses dan menyediakan identitas bagi aplikasi Anda. Contoh ini akan memandu Anda menghubungkan Google Login ke proyek menggunakan Refine.

:::note

Jika Anda mengembangkan aplikasi OAuth sendiri, penting untuk menambahkan URL aplikasi yang sudah dideploy dan URL pengembangan lokal ke daftar origin yang diizinkan di pengaturan aplikasi OAuth. Jika tidak dilakukan, aplikasi dapat gagal berjalan.

Untuk panduan yang lebih rinci, Anda mungkin terbantu oleh [video tutorial](https://www.youtube.com/watch?v=HtJKUQXmtok) ini.

:::
