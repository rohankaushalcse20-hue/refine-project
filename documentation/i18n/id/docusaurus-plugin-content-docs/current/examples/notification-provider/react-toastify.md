Dengan Refine Notification Provider, Anda dapat menampilkan pesan notifikasi di aplikasi dari mana saja. Pesan ini dapat berupa peringatan atau error yang menyarankan tindakan dan membantu menjaga keterlibatan pengguna dengan fungsionalitas aplikasi. Anda dapat menggunakan library notifikasi apa pun dan mengelolanya dengan hook `useNotification` milik Refine! Dalam contoh ini kami menggunakan library [React Toastify](https://github.com/fkhadra/react-toastify) untuk menampilkan notifikasi.

[Lihat dokumentasi Refine Notification Provider untuk informasi selengkapnya. →](/core/docs/notification/notification-provider/)
