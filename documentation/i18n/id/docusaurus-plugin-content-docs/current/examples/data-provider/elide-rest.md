[Elide](https://elide.io/) Data Provider memungkinkan Anda memanggil API JSON backend Elide. Elide data provider menyusun query yang dapat dipahami oleh Elide Application, sehingga pekerjaan beratnya sudah disiapkan untuk Anda. Contoh ini menunjukkan cara memanfaatkan Refine Elide Provider di proyek ini.
