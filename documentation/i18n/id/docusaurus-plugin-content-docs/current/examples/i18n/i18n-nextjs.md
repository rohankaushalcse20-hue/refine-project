Refine i18n Provider memungkinkan Anda menambahkan beberapa pilihan bahasa ke aplikasi web Anda. Bahasa default Refine adalah bahasa Inggris. Anda dapat menyertakan dan menggunakan terjemahan sendiri di proyek untuk preferensi bahasa yang berbeda. Contoh ini menunjukkan cara menggunakan opsi bahasa dan terjemahan yang berbeda dalam praktik.
