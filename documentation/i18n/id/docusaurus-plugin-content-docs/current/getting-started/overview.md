## Apa itu Refine?

**Refine** adalah React meta-framework untuk aplikasi yang sangat bergantung pada CRUD. Refine membantu tim membangun admin panels, internal tools, dashboards, dan aplikasi B2B sambil tetap bebas memilih UI, routing, dan backend yang sesuai.

Refine menyediakan hooks, components, dan providers untuk bagian penting aplikasi seperti **authentication**, **access control**, **routing**, **networking**, **state management**, dan **i18n**.

## Mengapa tim menggunakannya?

Refine mengambil alur kerja produktif dari pengembangan tradisional dan solusi low-code/no-code tanpa mengunci Anda pada UI atau pola data tertentu. Alih-alih menulis lapisan CRUD yang sama di setiap proyek, Anda memulai dari fondasi yang jelas lalu menyesuaikannya dengan kebutuhan produk.

## Arsitektur headless

Refine bersifat headless, sehingga logika bisnis tetap terpisah dari lapisan tampilan. Anda dapat menggunakan Tailwind CSS, Ant Design, Material UI, Mantine, Chakra UI, atau design system internal tanpa kehilangan manfaat dari `@refinedev/core`.

## Kasus penggunaan

Refine sangat cocok untuk aplikasi yang padat data seperti admin panels, dashboards, dan internal tools. Refine juga cukup fleksibel untuk membangun aplikasi yang langsung digunakan pengguna akhir ketika produk membutuhkannya.

## Langkah berikutnya

- Lanjutkan ke [panduan quickstart](/core/docs/getting-started/quickstart/) untuk membuat proyek pertama.
- Buka langsung [Tutorial](/core/tutorial) jika Anda lebih suka belajar dengan membangun aplikasi CRUD lengkap.
