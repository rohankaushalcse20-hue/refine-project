**Refine** dapat berjalan di lingkungan apa pun yang mendukung **React**, termasuk _Vite_, _Next.js_, _Remix_, dan setup React lainnya.

## Menggunakan CLI

Cara tercepat untuk mulai adalah `create-refine-app`, karena alat ini menyiapkan proyek baru dengan pilihan UI framework, router, dan data provider yang Anda butuhkan.

```sh
npm create refine-app@latest
```

## Menggunakan scaffolder berbasis browser

Jika Anda ingin melihat pilihan konfigurasi sebelum mengunduh proyek, gunakan alat pembuatan proyek di browser. Pengalamannya interaktif dan menyediakan opsi yang hampir sama dengan CLI.

## Setelah proyek dibuat

- Ikuti [Tutorials](/core/tutorial) untuk mengubah proyek awal menjadi aplikasi CRUD lengkap.
- Baca [General Concepts](/core/docs/guides-concepts/general-concepts/) dan [Data Fetching](/core/docs/guides-concepts/data-fetching/) untuk memahami struktur dasarnya.
- Jelajahi contoh siap pakai jika Anda ingin mulai dari skenario yang dekat dengan produk nyata.
