Tutorial Refine memandu Anda membangun aplikasi CRUD lengkap sambil menjelaskan bagaimana resources, providers, routing, forms, tables, dan authentication bekerja bersama dalam satu proyek.

## Apa yang akan Anda pelajari?

- Membuat aplikasi Refine dari awal
- Menghubungkan API dengan data provider
- Mendefinisikan resources dan routes
- Membangun halaman list, create, edit, dan show
- Menambahkan authentication, authorization, dan i18n sesuai kebutuhan

Nama package, imports, commands, dan code examples tetap dalam bahasa Inggris agar sesuai dengan API asli, sementara penjelasan dan konteks pembelajaran diterjemahkan ke Bahasa Indonesia.
