访问控制指的是根据用户权限限制其访问 Web 应用或网站特定区域的方法与流程。它确保用户只能使用被授权的内容和功能，从而提升安全性与用户体验。

本示例演示如何使用 Refine 和 [Permify](https://permify.co/) 简化整个应用中的访问控制管理。

[有关更多信息，请参考 Refine Access Control Provider 文档。→](/core/docs/authorization/access-control-provider/)
