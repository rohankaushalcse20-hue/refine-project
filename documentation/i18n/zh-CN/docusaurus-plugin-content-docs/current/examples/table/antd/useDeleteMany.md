`useDeleteMany` 是 Refine 的 data hooks 之一。它可以从数据库中删除多条数据。在这个场景中，我们使用 `useDeleteMany` hook 从表格中删除多条记录。在你的表格中，可以选择多条记录并点击删除。你可以通过查看示例了解更多信息。

[有关更多信息，请参考 Refine useDeleteMany data hook 文档。→](/core/docs/data/hooks/use-delete/)
