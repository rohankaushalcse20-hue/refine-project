你可以使用 `useTable` hook，以兼容 Ant Design [Table](https://ant.design/components/table/) Component 的功能来处理数据。它提供开箱即用的能力，无需为 sorting、filtering 和 pagination 额外编写处理逻辑。

[有关更多信息，请参考 Refine useTable hook 文档。→](/core/docs/ui-integrations/ant-design/hooks/use-table/)
