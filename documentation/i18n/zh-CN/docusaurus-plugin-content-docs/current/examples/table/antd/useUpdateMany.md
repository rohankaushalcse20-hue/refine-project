`useUpdateMany` 是 Refine 的 data hooks 之一。它会执行更新多条数据的流程。在本示例中，我们使用 `useUpdateMany` hook 在表格中编辑多条数据。你可以在表格中选择想要编辑的行，从而编辑多条数据。你可以通过查看示例了解更多信息。

[有关更多信息，请参考 Refine useUpdateMany data hook 文档。→](/core/docs/data/hooks/use-update/)
