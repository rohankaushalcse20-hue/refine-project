`useEditableTable` 包含 [`useTable`](/core/docs/ui-integrations/ant-design/hooks/use-table/) 的全部能力。除此之外，它还允许你编辑 Table。它会返回 Ant Design [Table](https://ant.design/components/table/#API) 和 [Form](https://ant.design/components/form/#API) components props。

[有关更多信息，请参考 Refine useEditableTable hook 文档。→](/core/docs/ui-integrations/ant-design/hooks/use-editable-table/)
