借助 Refine Notification Provider，你可以在应用的任何位置显示通知消息。这些消息可以是提示用户采取操作的警告或错误，并帮助维持用户对应用功能的参与度。你可以使用任意通知库，并通过 Refine 的 `useNotification` hook 管理它们。本示例使用 [React Toastify](https://github.com/fkhadra/react-toastify) 库显示通知。

[有关更多信息，请参考 Refine Notification Provider 文档。→](/core/docs/notification/notification-provider/)
