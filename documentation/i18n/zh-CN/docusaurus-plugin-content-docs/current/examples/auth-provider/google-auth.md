你可以使用 Google Login 控制访问权限并为应用提供身份信息。本示例将指导你如何使用 Refine 将 Google Login 接入项目。

:::note

如果你正在开发自己的 OAuth 应用，需要将已部署应用和本地开发环境的 URL 都加入 OAuth 应用设置中的 allowed origins 列表。否则应用可能无法正常运行。

如需更详细的指导，可以参考这个有帮助的[视频教程](https://www.youtube.com/watch?v=HtJKUQXmtok)。

:::
