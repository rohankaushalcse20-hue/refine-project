## 什么是 Refine？

**Refine** 是一个面向 CRUD 密集型 Web 应用的 React 元框架，适合内部工具、管理后台、仪表盘和 B2B 应用等企业级场景。

它提供的核心 `hooks` 与 `components` 能帮助你用统一方式处理 **authentication**、**access control**、**routing**、**networking**、**state management** 和 **i18n** 等常见能力。

Refine 采用 headless 架构，将业务逻辑与 UI、路由解耦，因此可以灵活接入自定义设计系统、Tailwind CSS、Ant Design、Material UI、Mantine、Chakra UI，以及 Next.js、Remix、React Native、Electron 等平台。

## 为什么选择 Refine？

Refine 处在“完全从零开发”和 low-code/no-code 产品之间的实用区间。它既保留了灵活度和开放技术栈，又减少了重复搭建基础设施带来的时间成本、技术债务和维护压力。

low-code 产品可能让起步更快，但也常伴随供应商锁定、定制空间有限和开发体验受限的问题。Refine 则在不牺牲控制权的前提下提升交付效率。

## 适用场景

**Refine** 特别适合以下数据密集型应用：

- 管理后台
- 运营仪表盘
- 内部业务系统
- CRUD 流程较多的 B2B 应用

## 关键特性

- 用于深入检查应用状态的 Devtools
- 面向 REST API、GraphQL、NestJS CRUD、Airtable、Strapi、Supabase、Hasura、Appwrite、Firebase、Nestjs-Query、Directus 等后端服务的 connectors
- 基于 Next.js 与 Remix 的 SSR 支持
- 基于 API 结构构建 CRUD UI 的能力
- 基于 TanStack Query 的状态管理与 mutations
- 用于认证、授权、通知、实时更新与审计日志的 providers
