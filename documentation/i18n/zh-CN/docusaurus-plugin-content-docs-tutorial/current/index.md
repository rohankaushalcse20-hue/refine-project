Refine Tutorial 会带你完整走一遍 CRUD 应用的搭建过程，逐步理解 resources、providers、routing、forms、tables 与 authentication 流程如何组合在一起。

## 你将学习到

- 从零开始创建 Refine app
- 连接 API 与 data provider
- 定义 resources 与 routes
- 构建 list、create、edit、show 页面
- 按需加入 authentication、authorization 与 i18n

包名、imports、commands 与 code examples 会保持英文，以确保与真实 API 使用方式一致；解释性文本则使用简体中文。
