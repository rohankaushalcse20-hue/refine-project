**Refine**, **React** destekleyen her ortamda çalışabilir; buna _Vite_, _Next.js_, _Remix_ ve diğer React kurulumları dahildir.

## CLI kullanma

Başlamanın en hızlı yolu `create-refine-app` kullanmaktır. Bu araç, ihtiyacınız olan UI framework, router ve data provider seçenekleriyle yeni projeyi hazırlar.

```sh
npm create refine-app@latest
```

## Tarayıcı tabanlı scaffolder kullanma

Projeyi indirmeden önce yapılandırma seçeneklerini görmek istiyorsanız tarayıcıdaki proje oluşturma aracını kullanın. Deneyim interaktiftir ve CLI ile neredeyse aynı seçenekleri sunar.

## Proje oluşturulduktan sonra

- Başlangıç projesini tam bir CRUD uygulamasına dönüştürmek için [Tutorials](/core/tutorial) bölümünü izleyin.
- Temel yapıyı anlamak için [General Concepts](/core/docs/guides-concepts/general-concepts/) ve [Data Fetching](/core/docs/guides-concepts/data-fetching/) sayfalarını okuyun.
- Gerçek ürüne yakın bir senaryodan başlamak istiyorsanız hazır örnekleri inceleyin.
