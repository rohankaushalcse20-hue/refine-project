Refine Tutorial, resources, providers, routing, forms, tables ve authentication kavramlarının tek bir projede birlikte nasıl çalıştığını açıklarken tam bir CRUD uygulaması geliştirmenizi sağlar.

## Ne öğreneceksiniz?

- Sıfırdan Refine uygulaması oluşturma
- API'ı data provider ile bağlama
- Resources ve routes tanımlama
- List, create, edit ve show sayfaları geliştirme
- Gerektiğinde authentication, authorization ve i18n ekleme

Package adları, imports, commands ve code examples özgün API ile uyumlu kalması için İngilizce bırakılır; açıklamalar ve öğrenme bağlamı Türkçeye çevrilir.
